# 质量验收与场景

以下为端到端验收计划。状态planned表示尚未完成该完整场景，即使已有小范围核心单元测试也不能称整个场景通过。

发布前同时记录关键遗漏、误配、误报、错误关闭及查找、录入、复核、报告和返工总时间。阈值按具体用途和风险设定，不用一个平均准确率替代。

工程检查、合成案例和获授权真实试用分开；缺模型/资料/部署授权时不能宣称完整临床试用就绪。
