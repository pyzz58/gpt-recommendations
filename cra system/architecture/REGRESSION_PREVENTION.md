# 已知错误的防复发与回归验收

2026-11-01；适用于 M01—M14 和既有工作包。本文件不新增临床操作、OCR范围或工作包编号。

## 1. 记录层级

| 位置 | 保存内容 | 更新条件 |
| --- | --- | --- |
| `theory/` | 长期业务原则、固定 CRA-R 与用户决定 | 只有业务含义改变才提高理论修订 |
| `architecture/` | 条件继承、来源沿革、撤销语义、异步恢复与能力边界 | 实现揭示契约缺口或歧义时增量补齐 |
| `AGENTS.md`、`CODEX_START_HERE.md` | 接手顺序、审核阻断与开发责任 | 工程协作要求改变 |
| 正常测试与任务 profile | 从正确临床预期出发的持续回归 | 同一修复变更交付 |
| `audit/`、`validation/`、`changes/` | 原反例、关闭依据、源码和运行版本、限制 | 追加记录，不改历史快照 |

实现错误通常是没有满足既有 CRA-R，不因此新造业务理论。审核记录不复制任务完成状态；完成状态仍只以 `plan/tasks.json` 和源码绑定证据为准。

## 3. 已知错误的最低回归

| 原发现 | 持续回归 |
| --- | --- |
| 01 | 更正后确认、再次局部更正、批量确认均保留累计有效值和原始候选 |
| 02 | 未知例外不当作无例外；缺必要单位不产生确定性数值判断 |
| 03 | 祖先 false/豁免/unknown、兄弟窗口路径、目标自身窗口、分支入口 false/unknown/true 和实际超窗经过真实 API |
| 04 | 同源中心采用日正确；独立同编号中心 SOP 与项目规则并存 |
| 05 | 普通中文段落/表格/脚注/Q&A 不静默丢失；无法结构化时保留 analysis_required |
| 06 | 数值及异常标志一致时仍独立比较参考上下限与报告元数据 |
| 07 | 页眉身份/日期复用有出处；行与页眉冲突提示；不跨患者借用 |
| 08 | 完成 job 复投不调用 provider；过期租约恢复、活跃租约保护、旧 attempt fencing |
| 09 | 锁文件与实际环境一致；重量哈希失败停止推理；固定获准模型/镜像仍由 W15 验证 |
| 10 | iPad/电脑/弱网/跨设备在 W12/W15 实机验证；任务登记不等于通过 |
| 11 | 一致异常不遗漏；跳过不重问；输入更新后旧比较不作为当前安全结论 |
| 12 | 法域和分类来自可信配置；unknown 跨模块保留；受限能力不升级 validated |
| 13 | 当前事件、重复实例和历史相关事实分别归属 |

05、07、09、10 的既定限制保持不变：本文件不授权任意中文方案完整 AST、任意医院照片、正式部署或真实资料处理。

## 4. 每次修复的最低交付

1. 从 CRA-R、项目规则或用户决定定义正确预期，不能从当前错误输出反推答案。
2. 添加对错误版本会失败、对修复版本会通过的正确行为断言。
3. 覆盖相邻边界：缺失、矛盾、否定、例外、多层条件、范围、重复、恢复和输入更新。
4. 经过真实消费者：规则/窗口走服务或公开 API，数据库用临时 PostgreSQL，队列覆盖 worker 和公开重试接口。
5. 保留邻近已正确行为，修复一项不能回退另一项。
6. 把新增用例、契约、任务规范和 profile 纳入源码绑定；记录 `test::case`、job/step、tested commit、run、预期、实际和限制。
7. 独立复核未通过时保持开放；不得删除断言、扩大 skip、改写预期或未经同意降级范围。

独立诊断脚本可以通过以证明它复现了错误；只有断言正确行为的正常产品测试通过才是修复验收。

## 5. 工程拦截

- `audit/current_findings.json` 是当前审核入口。它引用不可变原审核和复核，记录发现、影响任务、是否阻断、修复入口和关闭证据。
- `tools/next_task.py` 在推进受开放阻断项影响的任务时返回 `review_required`、发现 ID 和修复入口；无关任务不被一起冻结。
- `tools/task_evidence.py` 拒绝把仍受开放阻断项影响的任务标为 verified，并校验关闭项包含实际回归用例、专属 job 和源码/运行绑定。
- 正常产品 CI 执行正确行为回归；审核探针可以保留，但必须明确为 diagnostic。
- 工具只验证记录和证据结构，不替代业务、医学或临床用途审查。

当前防复发入口通过 `python3 tools/review_gate.py` 可单独检查。
