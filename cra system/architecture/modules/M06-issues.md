# M06 遗留问题、整改、Query与PD跟进

版本：1；状态：已设计，完整实现待工作包完成。计划代码位置：`backend/cra_app/issues/`。

## 对应理论和任务

理论：CRA-R009、CRA-R020、CRA-R021、CRA-R022、CRA-R023、CRA-R025、CRA-R026、CRA-R027、CRA-R031、CRA-R033、CRA-R041、CRA-R043。完整内容及出处见[理论清单](../../theory/REQUIREMENTS.md)与[对照表](../../traceability/INDEX.md)。

工作包：CRA-W06。验收场景：CRA-S14、CRA-S15、CRA-S16、CRA-S17。依赖模块：M01、M03、M04。

## 输入、输出和负责的数据

- 输入：核查发现、具体位置、整改建议和出处、中心回复、实际修改、CRA复核及用户已上报说明。
- 输出：稳定问题编号、分项行动状态、全部历史、下次遗留及真实超期提示。
- 负责的数据：Issue、ActionItem、IssueHistory、Verification、QueryLink、DeadlineEvidence。

## 实现方法

问题创建即允许不完整事实保存。每个行动按type决定完成方式：PD上报用户确认即完成；EDC/补件更正按实际CRA核实。中心称已改进入待核实，失败/部分完成保留原因和剩余事项。逾期计算先验证日期和时限依据。

具体服务路径和字段共同遵守[接口](../API_CONTRACTS.md)及[数据模型](../DATA_MODEL.md)。实现时本模块通过公开服务调用依赖，不直接改对方数据表。异步处理、幂等、权限、版本及历史适用共同约定。

## 工作边界

不能把一项完成扩成全部整改，不强求所有任务统一回执，不把系统草稿假装EDC已提交。相同问题跨次复用编号，处理后历史不删。

本模块验收采用场景：CRA-S14、CRA-S15、CRA-S16、CRA-S17。场景期望见[质量验收](../QUALITY.md)，实现证据在完成任务后追加；本文件存在不等于功能实现。
