# M07 EDC检验数据导入与范围

版本：2；状态：已设计，完整实现待工作包完成。计划代码位置：`backend/cra_app/edc_import/`。

## 对应理论和任务

理论：CRA-R013、CRA-R014、CRA-R015、CRA-R034。完整内容及出处见[理论清单](../../theory/REQUIREMENTS.md)与[对照表](../../traceability/INDEX.md)。

工作包：CRA-W07。验收场景：CRA-S18、CRA-S19。依赖模块：M01、M04。

## 输入、输出和负责的数据

- 输入：EDC检验Excel、导出时间与范围、字段/表单说明及用户映射。
- 输出：不可变导出快照、原始行定位、标准化检验记录和未包含范围。
- 负责的数据：EDCSnapshot、ImportMapping、ImportRow、字段状态和重复实例。

## 实现方法

先预览sheet/列/类型/实例和错误，再保存确认映射。保留原始数值、公式/缓存区别、单位、访视及日期精度；事务确认导入并以快照哈希与映射版本幂等。源表更正产生新快照，不覆盖旧记录。

具体服务路径和字段共同遵守[接口](../API_CONTRACTS.md)及[数据模型](../DATA_MODEL.md)。实现时本模块通过公开服务调用依赖，不直接改对方数据表。异步处理、幂等、权限、版本及历史适用共同约定。

## 工作边界

未提供导出范围先标不明，本次没找到不能直接判漏录。接口不写回EDC，不处理用药/样本的自动逐字段核对。
