# TECH-0006 CRA-W01 governance persistence implementation

Date: 2026-10-31.

This technical change implements the already-defined CRA-W01 data, scope,
revision, idempotency and audit foundation. It does not change the 45 fixed
business requirements or enable later clinical modules.

## Implemented boundary

- PostgreSQL 18 migration for studies, sites, memberships, append-oriented audit
  events and idempotency results.
- Composite foreign keys bind a site to its study and bind membership/audit
  center references to the same tenant and study.
- A trusted `ScopeContext` is required for reads and writes. Center-scoped users
  receive only authorized sites; study-wide and platform administration are
  explicit roles.
- Every write reserves an idempotency key scoped by actor, tenant, study/site and
  command. The request digest prevents a key from being reused for other input.
- Resource mutation, audit event and idempotency completion share one transaction.
  Concurrent revisions serialize with PostgreSQL row locks and compare
  `expected_revision`.
