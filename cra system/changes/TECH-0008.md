# TECH-0008 CRA-W03 document source foundation

Date: 2026-10-31.

Implements the existing W03 package without changing the 45 fixed clinical
requirements or starting W04/W08 output logic.

## Delivered

- PostgreSQL `0002_documents_jobs` migration for source documents, immutable
  versions, anchors, parse coverage, business jobs and transactional outbox.
- Authorized multipart upload/version APIs with type/size/hash checks, CSRF,
  idempotency, explicit source revision and duplicate-file references.
- Controlled DOCX parser for headings, content controls, tables/merged cells,
  footnotes, headers/footers, run formatting, fields and embedded-media
  coverage. Embedded content is never executed.
- pdfplumber parser for machine-readable PDF lines, page numbers, coordinates
  and table cell locations; page failures remain visible.
- Private local and boto3 S3 storage adapters. Original content is served only
  after CRA authorization and with private/no-store response semantics.
- Procrastinate queue adapter and worker. Business Job/Outbox and source version
  commit atomically; queueing locks handle relay retry. Workers reload
  authorization and input version before reading private content.
- React document workspace and locally bundled React-PDF/PDF.js worker with
  page/bbox highlighting.
- Synthetic DOCX/PDF/XLSX/TXT/PNG/template corpus with hashes, expected anchors,
  development and independent evaluation groups.
- Actual isolated PaddleOCR and Docling feasibility probes; PaddleOCR selected as
  the W08 integration candidate only. No OCR is enabled in W03 runtime.

No real clinical document, model credential or external clinical service is
used.
