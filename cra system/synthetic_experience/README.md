# 本机合成监查体验

本体验只使用仓库内纯合成资料，服务只监听 Mac 本机的
`127.0.0.1`。它不是 W15 正式部署，不是临床验证，也不会连接 EDC、
发送报告或处理真实患者资料。

## 启动

在 Finder 中双击 `cra-local.command`，或在终端运行：

```bash
cd "/Users/zz/Documents/ChatGPT/监察系统/cra system"
./cra-local.command start
```

首次启动会在仓库忽略的 `runtime/` 中下载并校验 PostgreSQL 18，
初始化私有数据库、预置合成资料并打开：

<http://127.0.0.1:15173>

如果浏览器未自动打开，点击“进入合成工作台”。项目选
`SYNTH-001 · 合成监查演示项目`，中心选 `S01`。

## 常用命令

```bash
./cra-local.command start      # 启动并打开
./cra-local.command start --no-open
./cra-local.command status     # 数据库、API、worker、网页和能力状态
./cra-local.command stop       # 停止服务，保留合成数据
./cra-local.command open       # 再打开网页
```

日志位于 `runtime/local-experience/`。停止服务不会删除数据库和已上传
资料；再次启动会接续上次状态。

## 实际启用能力

| 能力 | 本次本机状态 | 说明 |
| --- | --- | --- |
| 文字 PDF 检验读取 | 启用 | 使用 pdfplumber 读取带文字层和规则表格的合成 PDF |
| 清晰图像检验 OCR | 启用 | 清晰合成 PNG 使用隔离 Docling 进程；JPEG 同一路由，扫描 PDF 仍属受限范围 |
| 规则候选 | 受限启用 | 已有有出处规则子集；自由文本仍需人工确认 |
| 安全分析模型 | 未启用 | 保留人工记录，不生成确定性医学结论 |
| EDC Excel | 启用 | 读取合成多 sheet Excel 并保存快照 |
| DOCX/XLSX 输出 | 启用 | 使用预置合成模板及字段映射 |
| 自动发送、签名、EDC 写回 | 未启用 | 系统只生成草稿/导出，不实际提交 |

已预置一份清晰合成 PNG，用于验证“拍照式原图 → 自动候选 → 原图坐标 →
EDC 核对”。模糊、反光、透视、手写和任意医院版式仍不支持，不能把人工
补录伪装成自动识别。

## 建议体验顺序

1. **访前准备**：在完整遗留清单中勾选 `CRA-SYN-101` 和
   `LOCAL-URGENT`，保存。`CRA-SYN-103` 仍应保留。
2. **遗留整改**：进入遗留复核，展开 `LOCAL-URGENT`。先确认 PD 已上报，
   此时应显示“部分完成”；再确认数据更正，事项才会从未完列表消失。
   `CRA-SYN-101` 和 `CRA-SYN-103` 可继续保留到下一次。
3. **逐受试者核查**：进入 `SYN-EDC-001`，查看结构化的治疗/访视日期和
   检验值；分别查看文字 PDF 候选与 EDC 快照。
4. **检验核对**：选择文字 PDF 报告和对应 EDC 快照创建比较。预期可见
   字段一致、单位/范围待核实及“本次导出未见”等不同状态。不要把一致
   字段理解成临床安全结论。
5. **问题追踪**：从比较差异创建/关联 EDC 更正待办；查看问题编号、
   来源、责任动作和跨阶段保留。
6. **报告**：在报告区选择合成 report/track 模板，生成报告草稿，填写
   CRA 说明与结论，确认未核查范围后生成不可变快照并导出 track。
7. **下次接续**：建立下一次监查；未完成遗留和已签发报告应继续可见。

“安全与逻辑”页已预置一条检验安全线索：合成方案/IB 安全规则片段中的
9 条规则已经人工确认并启用，系统会展示分级、严重性、及时报告等独立维度、
待核实问题和来源。安全分析模型仍关闭，因此这是规则/人工路径，不是医学结论。

## 对应文件

体验资料和预期结果见 [manifest.json](manifest.json)。所有原件只用于上传
到本机体验；系统会将原文件复制到 `runtime/local-private/`。

## 重置

如需从头开始，先运行 `./cra-local.command stop`，再在确认无需保留本机
合成体验后删除 `runtime/local-postgres/data` 和 `runtime/local-private`。
这两个目录只含本机合成数据。不要对真实项目目录执行删除。
