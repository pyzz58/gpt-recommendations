# 新版合成工作台操作指南

入口：<http://127.0.0.1:15173>

如页面仍显示旧会话，先点击“退出”，再点击“进入合成工作台”。本机合成身份会在
重新登录后获得仅限本机合成环境的受控管理入口。

## 从空白项目开始

1. 左上角展开“新建项目”，输入项目编号和名称，点击“保存项目”。
2. 展开“新建中心”，输入中心编号和名称，点击“保存中心”；可继续建立第二个中心。
3. 在左上角项目/中心选择器切换范围。刷新后应从服务端恢复最后选择。
4. “资料与模板”中上传普通 DOCX 报告模板；模板类型和业务用途均选择“模板”。
5. 在“提取章节与问句”中确认章节、问句、条件和例外；保存后即成为可复用配置。
6. “访视前”处理上次遗留和访视范围；“本次监查”在遗留复核后进入模板逐项核查。
7. 展开核查项，选择模板，记录已核查/待核实/不适用/跳过，关联受试者、规则和问题。
8. 通过核查项内的证据工具或患者上下文，上传合成 EDC Excel 和检验原图/PDF，
   执行一致性核对。
9. “问题与报告”从同一问题、模板记录和比较结果生成草稿；检查模板回填后保存快照。
10. 开始下一次监查，重新选择同一模板配置；未完问题应继续存在，旧签发快照不变。
