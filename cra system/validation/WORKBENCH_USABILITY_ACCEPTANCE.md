## 本地实际检查

- 真实 PostgreSQL 18.6 迁移至 `0012_template_review`。
- 新增消费者与反例测试：模板提取、治理创建权限、报告回填。
- Chromium 完整路径：空库建立项目/两个中心 → 上传并确认模板 → 第一轮监查 →
  模板项记录/问题 → EDC 与源检验比较 → 报告回填 → 第二轮监查与模板复用。
- 前端单元、TypeScript、生产构建和 OpenAPI 类型漂移检查。
- 文档明确：人工记录不会冒充 OCR、模型或医学结论。

## 支持边界

- 模板提取只识别 DOCX 明确标题和问句；复杂内容控件、宏和无法稳定解析的版式保留警告。
- 模板本身不决定临床规则或医学结论；项目依据仍来自已确认规则及来源。
- 本机合成环境使用受控 `CRA_SYNTHETIC_PLATFORM_ADMIN=true`；生产身份仍为 OIDC，
  不因本机体验放松权限。
- EDC 写回、外发、电子签名和安全分析模型仍未启用。
