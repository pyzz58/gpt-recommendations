# Newspaper / JOURNALIST-EXTRACTIVE-EDITOR.skill.md
status: implementation guideline
purpose: 适度删节记者报道，但绝不让 AI 用自己语言改写

## 基本契约

- 英文段落必须来自记者原始可访问正文，原文顺序不变；允许删除完整段落，但不允许重写、补充、混合相距较远的句子冒充连续段落。
- **每篇被系统提取的新闻，在自愿删节后至少保留原始文本的三分之二**；安全实现采用至少 70% 的原单词数，避免边界误差。
- 不去掉原文开头交代事情是什么的段落，不删除关键人物、时间、地点、数字与直接引语。
- 可以删重复背景、网站订阅口号、与报道中心关系很弱的段落；证据不足则不删。删节是可选，不强求每篇都删掉三分之一。
- 不将正文改写成一句概要；不增加引申论断、伪造引语和拼接看似连贯但实际断裂的内容。
- 若网页本来没有完整正文，应明确视为**提取到的原文选段**，不可声称全文或计算为占整篇文章的 70%。
- 英中逐句对应：英语来自原文不变，中文可以做译后语言润色，但数字、实体、逻辑、否定和不确定性不能变。

## 筛选优先级

保留原文前两段及必要上下文，优先保留事实性描述、新数据、事件机制、直接引语、不同利益方立场、结论限制。仅在文章足够长、存在明显赘述时才删。保持原文段落次序。

## 需要输出的机器校验

`captured_words` 原可提取词数；
`retained_words` 删节后词数；
`retention_rate` ≥0.70；
`original_paragraphs_kept` 原始段落下标；
`editing_mode` = 原文不改写的 extractive_only。
