# Newspaper — 原文剪报与双语阅读

**当前开发分支：V0.6（PR #13，尚未合并）**。上一版 V0.5 已证明 GitHub Actions 能发送带 PDF 附件的 QQ 邮件，但其内容被错误地改写为标题与泛泛的自动化模板。本版修复该问题。

## 永久产品要求（读者优先）

1. 用户只看最终日报，不需要额外跳转到新闻网站。**任何正式读者版 PDF 与邮件都不出现原文 URL、阅读全文按钮或跳转要求。** 系统可以在后台维护 URL 供抓取、去重、来源合法性审核及错误追溯，不在前台展示。
2. 记者的优秀英文报道是内容主体，**不允许用 AI 的一两句概要代替记者文章**；同一篇报道保留原始句子和原来的段落先后顺序。
3. 英文原句一行，紧接中文译文一行，接下来是下一句英文；语法直接在英文原句内标下划线/编号，随后简短解释。不要末尾单独碎句练习附录、翻译卡片和“事实材料”工具标签。
4. 保留已获用户认可的 **A5、中文宋体风格、报刊 PDF 排版**，每天投递至已经配置的 QQ 邮箱。所有开发/测试在 GitHub 上完成，不依赖用户本地电脑。
5. 编辑可以选稿、去重、排序、排版、翻译和语法标注；全球形势评论单独写在**邮件正文**。评论必须基于当天来源进行分析，不要硬编码“后续应核对”等通用套话；没有可靠的大模型研究流程时宁可不输出假评论。

## 客观限制：原文使用范围

新闻网页可抓取，不代表可以重新汇编或翻译分发完整受保护作品；个人学习、私人阅读与对公众分发在法律上可能适用不同例外，但不能默认私用就总是允许整篇复制。当前代码对未审核再版/翻译授权的来源只使用不超过 25 个英文词的短原句（不显示原链接），**尚未实现用户追求的商业媒体全文剪报**。如需要完整篇章，优先使用明确授权的开放内容、用户依法取得可使用的稿件或具体许可。法律与技术细节保存在 [V06_ORIGINAL_CLIPPINGS.md](V06_ORIGINAL_CLIPPINGS.md)；这些信息不应反复塞进最终报纸。

## DeepSeek API 严格调用预算（2026-10-12）

在 GitHub Actions Secrets 中配置 `NEWSPAPER_LLM_API_KEY` 后，**仅主分支正式发信**使用该密钥，PR、模拟版式和 live dry-run 均不调用收费 API。

- 模型固定为 `deepseek-flash`，当前不自动升级到高价模型。
- **用户限制：单次 API 请求不超过人民币 0.20 元。** 采用 DeepSeek 官方**高峰价**作为计费上限估算，不依赖每日 07:00 的低谷价。
- 官方当前峰时价格（人民币/百万 tokens）：Flash 输入（缓存未命中）¥2、输出 ¥8；Pro 输入 ¥9、输出 ¥27。DeepSeek 允许未来调整价格，本程序无法独立替服务商冻结实际扣费。
- 每次正式运行仅发起 **1 个**模型请求（`max_tokens=2400`，非思考模式）；输入按照 UTF-8 字节长度加固定协议开销作偏保守的 token 上界。
- `llm_budget.py` 在调用前计算“全部缓存未命中、全部按峰时价”的输入最大费用+最大输出费用。预计费用达到人民币 **¥0.18** 就**直接拒绝调用**，留 ¥0.02 缓冲；即使预定时间延误到高峰也按峰值判断。
- 不自动重试，不在一个任务中调用多个模型，不自动 fallback Pro；若请求失败/超预算，PDF 照常准备和投递，邮件正文退回简短通知。
- 响应带 usage 后，再计算保守峰时实际消耗并记录日志，仅记录 RMB 估算和 tokens，**永不记录密钥、完整素材、请求头**。若 usage 异常或已达到预算，只报失败；已发生的调用无法撤回扣费。
- **重要边界**：这是客户端的*事前估算和输出上限*，不是 DeepSeek 平台侧的预付费冻结。供应商若更改价格、存在接口计费异常或其他外部因素，绝对账单金额不能由本程序 100% 保证。可在 DeepSeek 控制台自行设置账户级预算或充值限制（若平台提供）。

首次使用请先不要直接点击带 `dry_run=false` 的工作流频繁试跑：手动多次运行会产生多次独立调用。运行前请检查最新 DeepSeek 官方价格是否与上述守卫一致。

## 现有工具链

- 新闻采集：RSS + Trafilatura；候选去重/选稿：现有排名模块；断句/翻译/语法：spaCy + Argos Translate。
- PDF：WeasyPrint + GitHub Actions Ubuntu Noto CJK 字体；安全发信：QQ SMTP + GitHub Actions Secrets。
- 可进一步借鉴：Readeck（个人离线全文阅读），FreshRSS（RSS/全文扩展），GPT Researcher（跨来源调查与证据报告），STORM（多视角研究与写作）；后两者通常需要 LLM 或自托管 GPU 资源。
- 若启用 DeepSeek 云端 API：新闻原文保持原样；AI 只负责**与原文分离的独立评论和辅助翻译**。API 密钥仅可由 GitHub Secret 注入，绝不能放仓库、聊天或日志。

## 使用与安全

- PR 的 GitHub CI 跑排版回归、PDF 生成、英语原句对齐、权利边界以及没有读者可见链接的测试，绝不注入 SMTP Secrets。
- 实际日常发件仍是北京时间每日 07:00 尝试触发，GitHub 运行排队可能造成延迟。
- 上线前需要确认 PR #13 的全部 CI 通过、检查 PDF 实际呈现与真实新闻效果；不要把自动化模拟成功误说为已完成全文剪报。
