# 内参系统｜全球战略年报：从52周事实重建年度世界模型

> V4.0（2026-10-13）｜**现行正式产品：每周深度周报＋每年综合战略年报。历史“月报/MONTHLY”方案已经被用户新决定取代，归档保留但不得用于现行调度。**
>
> 年报的重要用户指示：“**年报是从周报为基础，结合新闻源出具本年度的综合性**”。因此它**同时**使用全年周报的研究、判断版本和全年原始全球新闻及专业机构数据；不能只是周报合订本，也不能只写一个综合摘要。

# 1. 年报应回答什么（而不是“这一年发生了什么”）

年度读者需要解决的七个独立问题：
1. **世界究竟发生了哪些有证据支持的结构变化？** 例如国家政策执行、企业利润池、技术成本、人口、资本配置的变量。
2. **哪些只是重大热点、却没留下持久结果？** 必须给具体后续数据，而不是凭印象评价。
3. **我们年初或年中相信的哪些判断被证实、削弱或推翻？** 找到当时旧原稿和截止时点。
4. **哪项变化可能在未来3/5/10年仍产生影响？** 只报告在明确条件下成立的观察命题，不承诺能预测十年。
5. **美股与宏观研究教会了什么？** 哪些收益来自估值重定价、盈利兑现、利率、流动性和资产风险？
6. **创业与产业真正发现了什么商业价值？** 从“某公司融资/行业热”逐步核到客户付费、毛利、资本消耗和门槛。
7. **过去一年的知识是否能帮助读者在明年的陌生事件中独立判断？** 用具体可迁移工具解释，不只是发布编辑结论。

**年报不是十二份月报或五十二份周报的拼接，也不应写成一个很长的年度新闻清单。** 需要新的纵向数据分析、跨领域因果连接、竞争解释和独立验证。

# 2. 全年研究时段、口径与三类时间

明确：
- `report_year`：自然年，如2026-01-01—2026-12-31（若最后一年数据截至12-31尚未公布，必须在附录注明修订风险）。
- `publication_cutoff_at`：实际制作年报时已知的公开信息截点；如果是次年1月发布，不能把次年新事件悄悄说成报告年内发生。
- `weekly_issue_period`与`weekly_as_of`：每份周报当时已知什么、其后哪个事实推翻了当时判断。
- `event_occurred_at`、`source_published_at`、`source_collected_at`：必须区分事件发生、公布和采集时点。

所有跨年经济数据注意官方统计后修订；对年内决策评判只能用当时可用资料，对年度事后结果可以用后来公开的数据但必须标其发布时间。

# 3. 两种输入必须独立、再融合

## A. 全年已出版周报
全部 `WEEKLY-YYYY-Www`：
- 一期的所有专题、来源ID、Theme/Thesis/MechanismCard；
- 每篇分析当时知识截点、引用的原始事实、假设、最强反方、读者学到的知识；
- 每期尚待观察的现实指标，哪项已得到新证据；
- 原稿与更正、审核和旧判断，**不能拿AI重写“以前我们想什么”**。

## B. 同年度全球新闻与原始机构研究
全年合法公开可得的原始政策、财政/央行/股票财报、银行/资管公开研报、科技论文/工程复现、临床试验与医疗监管、重大军事外交事件、社会人口数据及可信记者现场材料等：
- 与周报独立检索，专门补足周报当时没覆盖、漏判或观点被后来事实挑战的内容；
- 检索新研究时不可把后来的结论投射到年初的人的判断；
- 要追踪同一消息的原发/转载血缘和机构利益，不能因报道数量增加制造虚假确认；
- 数据授权不明确不录入全文，保留合法元数据/引用/本系统原创研究。

**两类输入交叉互证**：周报是全年研究轨迹和待检命题的重要基础，但不能替代全年独立原始来源研究；全年新增资料帮助审计周报，而不是重新叙述所有周报。

# 4. 十二道年度生产工序（每步有明确产物）

| 顺序 | 实际操作 | 明确产物 | 不能接受 |
|---|---|---|---|
| A01 | 冻结`report_year`与`as_of`，列全年的周报及缺失期次 | IssueInventory、missing_issues | 假装52期都已完整 |
| A02 | 建立当年原始新闻、机构报告/数据清单（不用只选周报引用） | AnnualSourceInventory、覆盖领域/地区 | 周报以外的新证据完全没查 |
| A03 | 提取所有Theme、ThesisVersion、观察清单及其当时证据 | AnnualThesisLedger | 不见原件只按新模型脑补 |
| A04 | 事件去重与影响链，按发生时间排列重大变化和后续结果 | AnnualEventTimeline、SourceLineage | 热搜/转载数当重大证据 |
| A05 | 校正全年数据口径/修订；识别趋势、制度变化与统计噪音 | AnnualMetricsTable、revision_notes | 年初初值和年末修订值混用 |
| A06 | 把全年新闻和周报做双向缺口分析 | CoverageGapReport、missed_signals | 只记录写过的成功故事 |
| A07 | 对重要判断逐项复盘：正确/错误/未决/不可检验 | AnnualPredictionAudit、claim_refs | 事后改写旧论断 |
| A08 | 构造跨板块因果研究：政策↔资本↔产业↔技术↔社会 | AnnualMechanismMap + evidence/alternatives | 只凭共时变化推断因果 |
| A09 | 分板块重做专业研究，美股/创业双重点、其它板块不缺位 | DomainAnnualDossiers（九栏按实际价值） | 给九栏凑篇数 |
| A10 | 教授年度“真正学到了什么”，从旧案例抽通用规律、反例与陌生情境迁移 | AnnualLearningCurriculum + concept_refs | 抄去年的顾问点评 |
| A11 | 独立事实核查、强反方和时点审核，主编重写综合年报 | ReviewDecision+AnnualEdition | 审稿自己给自己过 |
| A12 | 用户批准条件下才渲染/交付并追加历史档案、旧判断版本 | ANNUAL-YYYY + Archive + DeliveryReceipt | 自动发送、无回执称成功 |

年报是跨领域新研究，不一定一年有52期周报（尤其第一年不完整）。缺期须诚实披露，再以独立年度来源弥补，不假造既有周报。

# 5. 十一个可以独立撰写的年度研究单元（可因重要性调整）

1. **卷首《首席顾问致决策者》**：一篇新撰写的年度长文，清晰揭示全年几个最重要的机制、证据和反证，并说明哪些判断是我们的推论。自然叙事，不是套话。
2. **年度世界十大结构变化（数量仅编排候选）**：由影响和证据决定，不规定必须恰好十条；每条附“年初什么→年末什么→谁承担成本→今后验证什么”。
3. **全球权力与政治制度**：中美、其他主要区域、军事安全，分析政策从提出到实施、制度权力、利益联盟和实际结果。
4. **美国资产与资本配置**：企业真实现金流、回购与股本、估值、货币条件、债券久期/风险、科技投资资本开支和市场预期变化。
5. **全球宏观资产价格与财政货币互动**：增长、实际通胀、汇率、流动性和政策时滞的纵向数据，标修订。
6. **年度创业机会雷达**：筛真实付款需求、单位经济、客户留存、监管和小团队现实可进入性；拒绝只总结融资榜。
7. **AI及技术—能源—基础设施约束**：论文进展与真实工程、芯片/电力/制造、AI产品利润链；关注性能与商业采用背离。
8. **产业与企业的长期利润池变动**：竞争优势从谁转给谁，依据订单、市场结构、财报与资本效率，而非口号。
9. **人口、就业、教育、医疗与消费结构变化**：真实数据与文化/制度对照，避免由一个热搜推总体变化。
10. **战略判断审计：今年我们想错了什么**：旧版原文、当时证据、新资料和具体修订，必要时展示假设失效/模型偏差。
11. **未来情景与“怎样独立判断明年”**：不是给确定的股价或选举预测，而是列变量、条件、最强竞争路径、观察来源及需要读者学会的知识。

不要求每篇都相同格式，但**每项正式发表的战略推论至少有可查证事实、明确因果机制、关键反证与未来可核数据**。

# 6. 年度专题的“表象→根因→长期影响”示例

**纯假设，非现实研究**：某年AI投资额创新高，年底不少项目却因电网并网与设备工期推迟。

- **表象**：AI投资额高，投产周期反而延长。记录每家公开投资额、原计划/实际工期、数据统计口径。
- **原始事实**：企业资本支出、供电合同、区域并网队列、冷却设备订单及供应商财报，标何时披露。
- **根本机制H1**：算力设备更快到位，但电网容量/许可/变压器等成为新瓶颈。
- **强反方H2**：需求/收入兑现不足、融资变贵或土地/许可等非电力原因导致项目延迟。
- **年度检验**：选择多个项目比较是否有供电约束文字证据，分地区、时间、客户类型交叉排除其它因素。
- **投资/商业**：受益的设备/能源企业能否实际获得订单、利润和现金？市场是否早已高估其利润？
- **人性/组织**：管理者过度承诺工期也可能是资本市场激励；除非公开考核和资本开支行为支持，不能定为事实。
- **传统文化**：若用兵法“势”“虚实”启发资源瓶颈问题，必须说明是比喻而非科学证据；不相关则不引用。
- **迁移**：以后遇到新材料、太空算力、医疗AI热潮，应问“技术进步之外谁控制关键配套资源/审批/市场付款？”

这样才叫**把一年的新闻和周报积累转化成跨期世界模型**。

# 8. 年报专门QA：审稿必须逐项检查
- [ ] **取回真实全年周报清单**，缺失数量明确，没有伪造旧期次。
- [ ] **独立检索全年新闻源与专业研究**，不只是拿周报合并。
- [ ] 当年/次年数据公布与修订日期不混淆；报告期清楚。
- [ ] 每条结构判断有原始来源/反证/准确指标，而非统计热度。
- [ ] 曾经公开过的旧判断有原稿、as_of、旧反证和年末新结果。
- [ ] 至少实质讨论全年犯错或不确定的判断；若没有足够判断样本，明确“不足以评测”，不虚报准确率。
- [ ] 每栏相关学科的根源教学符合[DOMAIN_TEACHING_PROTOCOLS.md](DOMAIN_TEACHING_PROTOCOLS.md)，不是年终漂亮总结。
- [ ] 长篇文章自然中文且完整、版权许可和来源索引合格。
- [ ] 未来情景有条件、不确定性和区分指标；不做绝对预言。
- [ ] 不把年报设计自动转换成发送计划。收件人/日期/模型预算仍待单独授权。

# 9. 年报实施的最小开发步骤
1. 先用**至少若干份冻结样本周报 + 对应年度原始资料**做离线测试，不要求真的运行一年才能测数据通路。
2. 开发`build_annual_inventory`取回周报ID/原件/来源；缺失上报。
3. 开发`build_annual_event_timeline`和`build_thesis_audit`以as_of避免未来信息污染过去。
4. 开发`compare_annual_primary_sources`，核查原新闻年度变化是否被周报漏掉。
5. 加载九栏专业Skill，输出新的年度分析与学习单元，不复读旧稿。
6. 用独立审核阻断假数据/假预测/错数字/不正确文化历史引用。
7. 原稿Markdown/可选HTML/PDF只作内部预览，经用户另行批准后方可公开发送。

**年报成功的标志不是页数，而是“能说明过去一年我们的世界模型被哪些证据改变，并教读者如何独立解释这些变化”。**

## V4.3年报选材和主题文章阅读规范

年度主题同样执行[EDITORIAL_SELECTION_AND_REPORTING.md](EDITORIAL_SELECTION_AND_REPORTING.md)的正负/混合实际影响、典型性或重要突破、权威机构事实证据与报告研究方法门槛；年度主要研究不再只罗列热门事件。每个重要主题应先翔实报告**全年事实与数据（含机构、年度跨度、修订、方法与局限）**，随后给顾问判断、帝师世界知识与**年度后续推演和开放性问题**。读者不再被要求阅读一个固定“继续观察”小节；旧命题的年度审计和未来验证指标仍保存在内部研究和年报审核中，不能删除。六层杂志总标准见[MAGAZINE_ARCHITECTURE.md](MAGAZINE_ARCHITECTURE.md)。
