# 一、项目为何存在：输入、目标、输出与用户能获得什么

### 1. 根本使命

内参不是“新闻聚合+一段评论”，而是以可验证的世界事实为原材料，以记者的准确、情报研究的连续、专业机构的分析、顶级战略顾问的问题解决和优秀导师的知识传授为方法，长期培养读者对**国家、市场、企业、科技、医疗、军事、组织、人性和文化如何在真实条件下运行**的理解。

**一个完整的价值交付应满足四个不同的问题**：
1. 我没有看过原新闻，能否凭A段**真实、完整**地知道发生了什么？
2. 我能否凭B1顾问研判知道这件事影响谁、各方选择、竞争解释及哪些因素还不确定？
3. 我能否凭B2帝师释理真正理解所需学科原理、它的形成机制、何时成立及与某个陌生事件如何类比？
4. 我能否凭C段看到**条件不同导致不同后果的未来路径**，并独立尝试思考几个没有预设答案的问题？

单独满足任意一项不能宣布主文合格。

### 2. 五种研究能力具体要干什么

- **新闻机构的敏锐性**：用多语言、多区域、主流/地方媒体及官方最新发布寻找事实；报道的准确性和多方归属优先于速度及轰动。
- **情报机构的连续性**：把一周的事件与多年的人物、资金、机构、政策、会议、法条、科研里程碑和旧观点关联；保留原件、时间及判断版本，不能下一周“从零开始”。
- **投资研究机构的验证**：财报、SEC、公司IR、央行/财政/政府统计、真实成本现金流及数据期限；区分价格、价值、预期、事实和机构公开主张。
- **战略咨询的诊断能力**：先问真正的难题是什么，谁决定、谁付款、什么是瓶颈、替代策略如何表现；不给空话建议，不为每篇文章强找证券买卖方案。
- **家族办公室式长周期视角**：一年/三年/五年或更长期的机制变化、重要机会、风险和历史判断复盘；年份仅是适当的研究期限，不制造精确预测。

### 3. 三个“长期雷达”各怎么工作

**战略判断追踪器**：每次提出重要判断就写 `thesis_id`、当时`as_of`、原话、事实支撑、竞争解释、未来的验证指标/推翻条件、时限；新事实发生时写新`ThesisVersion`并链接旧版，绝不覆写当初话。年报核说对、说错、无法裁决及原因。

**全球商业机会雷达**：记录需求来自哪里、谁是使用者/付款者/风险承担者、为什么有可兑现价值、真实定价/单位经济/获客/续费、竞争与法律、技术/采购实施成本、最小成本可验证实验。融资不是订单，试点不是付费，毛利不是自由现金流，现金流利润不确定就标未知。

**世界结构变化与反常信号雷达**：不是跟随热搜，而是持续对比融资与收入、股价与盈利预期、科技实验与落地成本、政策口号与立法/拨款执行、资本流向与汇率/利率等**可能背离**。每个反常都留下需要补查的数据、共同原因与可证伪竞争解释；不是“反常=必然有阴谋”。

### 4. 读者最终拥有的长期资产

不是52篇汇总，而是：周报真实正文、全年新综合研究、原始合法来源指针和当时关键数据、主题与历史连续档案、世界机制知识卡、原样保存的旧判断及新证据纠错记录、面向陌生问题的分析路径。只有用户能实际运用知识时才可说“已掌握”；文章写完只能称“已教授”。

# 三、材料宇宙、采集事实与合法性

### 1. 允许进入发现池的材料

- 主流与区域新闻：BBC、Reuters、新华社、人民日报海外版、财经及地方媒体等**已列/拟列公开来源**，但具体某媒体是否可抓取正文取决于来源登记和许可，不把知名度当成授权。
- 公开机构报告：各国行政/立法/司法部门、财政/央行/统计局/监管机构、SEC上市披露、央行/IMF/BIS/World Bank/UN等公开材料、投行资管在**公开允许**范围的报告、咨询机构与四大公开研究。
- 创业商业：监管备案、官网产品资料（注意宣传偏差）、真实订单/客户/融资披露、公开交易与行业统计。
- 科技与医疗：论文、预印本（未同行评审必须说明）、临床试验登记/药监结果、技术实验/基准和独立复现、产业/工程/物理条件。
- 军事地缘：官宣/预算/公开资料/独立机构，严格区分交战方声称与可独立核实的伤亡、行动和实控信息。
- 代表性基层/社会议题：可核实调查、区域数据、公开司法/行政文档，不能用一人经历外推整个国家。
- 看似不热门的慢变量：人口、政策执行、跨国供应链、长期信用、能源与社会变化。

`SourceRecord`应记：来源ID、机构、具体URL/合法公开接口、媒体/官方/科研/机构类别、原文语言、可访问范围、是否付费、可研究/转载条款、合法处理状态、最后已证访问及失败记录。A/B是当前入口判断，不等于内容获得许可。

# 四、选文委员会：从“信息多”变成“什么值得写”

**新闻价值首先是人的现实、制度与历史影响，而不是点击量、国别偏好或好坏情绪。** 借鉴《半月谈内部版》公开强调的“更真、更特、更深、更高”（正反调查与问题意识），《求是》理论联系实际的编辑思路，Reuters/AP的事实/来源/纠错纪律及新闻价值研究。**这些是借鉴，不代表本刊照搬任何机构政治立场或其内部算法。**

### 1. 选文完整S0—S8九道工序（不可跳过S2硬门槛）

**S0 独立发现**：全球开放渠道主动发现政治/经济/军工/医疗/社会/科研/资本正负变化，既有重要主流队列，也有地区、非英语、非金融、低热但结构重要的探索队列。留候选URL、原发机构、时间和范围。

**S1 归并与辨认**：同一政策的各媒体版本属于一个`event_cluster`；有独立不同调查/实证结论才算另一条证据。观察当事者声明与第三方验证之间的区别，标实际哪项行为已发生。

**S2 四个不可被评分抵消的编辑门槛**：
1. 确有真实事件或正式原件，能分清发生、发表、执行时点；
2. 有明确的真实或合理潜在的重要影响、典型性或重大突破；指出涉及谁和因何重要；
3. 可以通过合法可获取的足量信息写成**翔实完整A新闻正文**，否则`RESEARCH_PENDING`，不能依标题编报道；
4. 不是整本周刊里的同一事件同一信息再次重复。

**S3 影响地图**：列正面`BENEFIT`、负面`HARM`、正负交织`MIXED`或`UNCERTAIN`；分别写已实现`OBSERVED`或潜在`POTENTIAL`、被影响群体、规模/时间/金额和可查证据。正面成果如疾病减少、治理改进、有效产业技术突破同样可成为封面，不偏好灾难。

**S4 典型与突破双轨**：代表性事件`REPRESENTATIVE`须说明为何能反映一类制度/商业/社会机制并查其它样本；重大新突破`BREAKTHROUGH`即使仅一次也可能重要，须独立核其真实完成程度。**“典型”≠“从一个例子证明全世界都如此”**。

**S5 有解释的试行100分**：影响量级和受影响者25、持续及结构15、典型或重大突破20、可核报道证据15、可教学/现实决策价值15、独立发现/全球多元/时效10。每维写具体依据；暂用`≥75`主文候选、`60—74`侧栏或继续研究、低于60通常低优先，仅用于**编辑排序实验**，不能用分数洗白真实/版权失败；影响紧迫的突发事件可标`URGENT_RESEARCH`并记录特殊理由。

**S6 整刊反茧房复审**：看是否全是美国大科技/美股/冲突，遗漏重大非金融地区、普通民生、医疗、基础科技。先核全世界的重要性，再决定最终版面；关注度权重不等于只写一两个国家。

**S7 体裁分配与报道计划**：选择`EVENT`真实事件、`REPORT`官方/机构报告、`INVESTIGATION`媒体调查成果、`DEVELOPMENT`持续新进展、`RESEARCH_FEATURE`跨期特写，列需核的法规/表决/统计/财报/论文/采购/临床证据、关键反方和不能得到的资料。非原创调查严格标记者与机构。

**S8 二次复审（必须跨层回访，不在L2初选时假称完成）**：L2先做S0—S7并初选，进入L3得到完整证据和A记者稿后，**必须将证据/方法/真实影响带回L2执行S8再决定是否准入L4**。若L4新增重要反证也需再次回访S8；研究后若发现所谓影响被夸大、样本不代表总体、报告方法或关键数据有错、新闻价值不够，编辑可以撤稿或降为事实短信、延后研究；不能因为S5已有85分就强刊。

### 2. 什么样的材料会被选中或拒稿（虚构编辑测试场景）

- **正面重大典型**：某地公开报告经独立方法证明降低真实疾病负担并可核财政、样本与地域局限。即使不热门仍可选深度主文，向其它地区迁移需要重新核基层执行/预算条件。
- **负面重大结构变化**：经法律和公开报表确认的政策失误、重大事故、战争或公司资本配置失败。核实际损失与异议，不用“谁很坏”代替报道。
- **混合后果**：产业补贴可能使本地就业或技术受益，但增加财政成本和别国贸易反应；同一决定对不同参与者影响不同。
- **重大前沿但未证实**：科技公司宣传革命性性能，仅有营销视频，没有方法/复现 → 可列线索或客观公告，但不能当已经完成的独立突破专题。
- **热搜却不重要**：公众人物口水、重复转载、无可查现实变化且缺代表性研究意义 → 不给深度主文；热度不能假装结构性影响。

# 五、顶级新闻记者正文 A：不只是“汇总”，是一篇完整的事实报道

**A的独立价值**：读者只看A而不看顾问，仍能清楚知道谁、在何时何地、发生/公布/证明了什么、已知为什么、怎样进行、对谁有何影响；了解重要背景、过程、数据、多方观点、未证事项。

### 1. 强制5W1H六要素与七种补充核验

- `Who`：具体决策/发布/研究主体，涉及公司、机构、受影响的人群，身份和职能准确。
- `What`：实际做了什么、发生了什么；声明、草案、签约、投票、法定生效、实际支付/完工**不能混写**。
- `When`：事件发生日、文书发布日期、研究数据覆盖期、当前资料截点分别说明。
- `Where`：发生地点、适用法律辖区/研究国家和样本地区；不能把城市研究称全国政策。
- `Why`：已核事实/当事者正式陈述的动因、可证历史背景；若没有证据说明私人心理，则写未知或“某方称”。
- `How`：真实实施/研究方法、动作顺序、审批/资金/实验/法庭/投票过程和重要中介条件。

**额外必须有**：①准确有效导语；②事件前后的时间线；③数字/币种/分母/可比性与来源；④各重要立场/回应的合理权重而不是机械各给50%；⑤使读者看懂的制度/经济/科学背景；⑥关键事实的可定位出处和原发血缘；⑦稿件足够详实却不重复灌水的自然中文。

**特别要求**：事实与推论分栏。即使记者报道需要解释背景，也不能把内参判断伪装为已证新闻。不伪造“记者在现场看到”“采访当事人”，如果实际仅阅读公开材料，就写“据某机构/某记者公开报告”和本刊独立核查之处；外语翻译确保原意、语气、术语、单位，不AI直译腔。未经授权不能把Reuters/BBC等原文长篇直接译贴，必须依据合法事实自写并准确归属。

### 2. 三种重要稿件的不同核实路径

**普通突发/政策新闻 EVENT**：
1. 确认发生/公告/生效状态；
2. 时间线、法源/协议/实际动作；
3. 参与方及实际影响范围；
4. 核最新是否有反转/更正；
5. 交代不同立场和不能独立验证之处。

**官方/投行/科研/医学报告 REPORT**：
1. 谁的报告、谁出资/作者、日期和利益冲突；
2. 为何研究、样本/国家/数据覆盖时间；
3. 用何方法：统计、模型、试验设计、财务口径、比较基线及局限；
4. 原文主要发现和关键图表数字是什么；
5. 结论与实际生活/市场意义在哪里，哪些只是预测或条件模拟；
6. 是否有另一机构可比研究、反例、样本偏差和独立复现。**报告的“我们认为”要归属研究机构，不能写成本刊已证事实。**

**第三方媒体调查 INVESTIGATION**：
1. 明确原调查媒体/记者/日期；
2. 哪些证据来自真实采访/文件/数据，哪些是调查者推断；
3. 被调查方回应、法律程序和事实尚未裁决部分；
4. 本刊有无另外独立公开来源的交叉核证，明确写出；
5. 不将别人的原创成果重新包装成“本刊独家”。

### 3. 完整报道不是冗长堆字

报道长度由信息密度决定：十万字政治法令可以先找核心条文和重要异议，保留影响结论的事实；极复杂战争/企业调查需要较长背景。禁止用固定100或300字模板概括复杂故事，也不强制每篇上万字。**有影响力但A证据不足，哪怕B看起来很高深仍须先补证或撤稿。**

# 六、同一联合研究工作台：顾问B1 + 帝师B2

### 1. 一个核心研究引擎的“七问、三门、两回路”

**七问**（内部思考顺序，文章不按七标题机械呈现）：
1. **问事**：已核实发生了什么、最初出处何在？
2. **问题**：从旧基线和预期看，真实难题/反常在哪里？
3. **问势**：制度、合法权限、成本/资源、科学/历史条件限制了什么？
4. **问人**：谁可选择什么，掌握何权限/资金/信息，谁承担代价？心理推断是否有真实行为证据？
5. **问因**：由事实提出多条有意义且可能共存的解释，查条件A→中介B→结果C、竞争或互补与反事实；**不预设唯一“终极规律”**。
6. **问断**：目前可有条件地下什么判断？哪项已证、待证、未知？什么时候宁愿不预测？
7. **问道**：此事**实际最值得学什么世界知识**？教正规概念→实例/计算/法定程序→反例→在陌生国家/行业重新查证。

**三道持续检查**：事实及来源门，最强反方/因果门，读者可迁移的教学门。**两条回路**：顾问发现事实缺口→退回原始研究；帝师教学发现机制/类比站不住→退回顾问分析甚至事实层。不是两个重复Agent，更不是七个独立模型。

**识因的更深入方法**：溯因提出多个合理机制，演绎写出“如果此机制真，应该观察到哪个不同证据”，归纳用可比较的多期/多地资料评估它是否持续。观察相关性不自动是已证因果；复杂系统可能有多个因果层、反馈和共同原因。

### 2. 顾问研判B1必须有实质研究，不可复述A

- 现实中什么真正变化了？至少指到A的关键事实与事前条件。
- 谁有权决定/否决、谁支付/承担风险、各利益相关者的正负变化，制度与工程/经济瓶颈在哪里？
- 比较最重要的两种或多种**有真实理由**的机制，也允许多个解释共同成立；给明确的支持/反对证据、未知。
- 若对美股、创业或实际决策有价值，分析真实现金流、价格相对预期、合法性、客户支付/成本、风险和“不做”的可行性。**不能每条国际政治新闻硬扯买哪只股票**。
- 给“在什么条件下”结论成立、哪个未来事实会使判断变化。不把道德立场、市场传言、人性猜测写成客观必然。

### 3. 帝师释理B2必须教“为什么”和“以后怎么自己看”

- 教学主题由**此事件的最佳证据机制**决定。政治新闻可能真正需要讲资源分散、科技新闻可能是采购/机构、企业财报可能讲组织委托代理，**不得因为栏目固定知识清单就强塞DCF、选举或CAC**。
- 正规学科定义：法律、会计、经济、物理、统计、组织、博弈或社会历史知识必须准确，有实际程序/公式/成本单位/必要条件，不只是术语。
- 至少一个真实可查案例（可为本事件）和一个反例/边界；若额外使用教学假设要明显标`HYPOTHETICAL`。
- 现实→先修知识→机制传导→生动易懂的例子→反例→迁移另一类现实的具体问题；通俗不是牺牲准确，严谨不是堆砌术语。
- **中国传统文化与人性**可以引入《资治通鉴》《帝鉴图说》、法家儒家及兵法作为已核原典的思想透镜，帮助提出信息、信誉、权势、制度激励问题；必须讲文本、时代局限与现代对照，不能靠一段古语证明今天人物的真实内心。
- 教完提出“如果你面对另一件陌生事，应先找哪份文件、问哪些问题、何处不能类比”，让读者获得可复用认识。若没有真实用户答题，仅记录`TAUGHT`，不能自报`MASTERED`。

### 4. 事实强于“帝师权威感”

不要假装AI拥有全部人类知识；训练内的广泛知识不等于实时资料。不要假设一切有单一根因；“本质是人性/利益/供需/资本”且没有中间机制和数据时属于失败。重要政策/临床/战争/股价解释必须有原始或可归属的正式资料；缺少证据时可以刊事实+诚实限定的解释，不得靠文采掩盖未知。

# 七、正式单篇文章：A → B1 → B2 → C（只给读者有用的结构）

**A｜新闻或机构报告的翔实报道**：独立成篇，专业标题和导语、5W1H、背景、完整重要事实、关键数据、当事人及来源、关键未知。**不能以A“概括”代替真正新闻报道**。

**B｜本刊原创深度评论**：
- **B1顾问研判**：解释此事的现实意义、主要因果/竞争机制和受益/受损主体，给具体条件与风险；
- **B2帝师释理**：以真实事实教会最值得学的制度/科学/金融/政治/社会/人性相关知识，具体讲例子、失效条件与跨领域迁移。两段来自同一个研究档案，不能每人写一遍雷同点评。

**C｜事件推演与开放性思考**：
- 以前的读者结尾“继续观察”**已经被用户明确否决**。现在基于B1/B2已讲透的条件机制，推演**至少两条实质不同的后续路径**：每条必须有“什么条件改变→谁会行动→什么中间传导→谁得到正/负影响→该情景可能为何不成立”。不机械用“乐观/中性/悲观”三空话，也不凭空给72%战争结束等数字。
- 随后建议**2—4个没有唯一预设答案的开放题**，至少分别锻炼：改变关键前提、换角色/约束、找最佳竞争解释、跨行业迁移/提出应查资料等。不是“你是否同意我们很深刻”。
- 若一篇文章证据不足，推演应更谨慎，不许用长篇预测填补事实缺口。**内部仍留证伪信号、旧Thesis和未来核验指标**，它们放档案/年报复盘，不强制占据读者C节。

**不强制把七问、S0-S8或所有审核字段逐条排印成杂志目录。** 真实成稿要像优秀记者与资深顾问合写的自然、专业、精确、详实中文文章，事实与分析分界清晰，不能靠AI腔和重复小标题冒充深度。

# 八、整本周报的阅读结构（不是九大栏目机械填空）

1. **封面**：`WEEKLY-YYYY-Www`、覆盖期、资料截点、真正重要的本期封面问题。封面议题由实证价值决定，不固定美股或政治。
2. **目录及导航**：所有正式文章题名、相应主要/跨域栏目标签、可跳转位置；短导读服务索引，不能代替正文。
3. **卷首／主编观察**：用连贯文字解释本周一至几个最重要事实如何相互影响，哪里仍有不同机制，为什么这期封面值得刊出；避免一句“风云变幻”式空话。
4. **完整主文**：依据新闻重要性与编辑阅读节奏排序。每篇严格A/B1/B2/C，新闻可以是机构报告/调查成果或阶段性真实进展。
5. **全球信号导航（可选）**：某些重要事实有提醒价值，但证据或认知深度尚不足成正式研究主文，明确列为短讯，不能伪造长篇“帝师”。
6. **历史命题纠错与跨期研究（由真实新材料触发）**：不编造进展，直接列“先前认为X、当时何资料、现在新事实Y、为什么强化/削弱/推翻”；没有更新不强填。
7. **资料、方法与更正附录**：真实引用、机构报告原址/发布时间、关键数据时点、限制、版权属性、补正记录与刊物版本。

**本期可视情况在封面、美股、创业、国际政治、社会医疗、前沿科技等栏目安排内容**；九栏目录标签存在，但可以空栏、跨栏，避免同一事件重复发3篇。最重要的稿件占篇幅而不是用文章数平均配额。不固定2万—5万字为强目标；历史讨论仅可把它当早期容量试验范围，以读者获得的事实与知识价值决定真实篇幅。

# 九、年报：一整年的世界如何改变、我们哪里判断错了

**年报需要两套独立输入，缺一不可**：
- `A`：全年实际已发行的周报原稿、当时来源和`as_of`，旧`ThesisVersion`、历史知识卡、缺期清单；
- `B`：年报制作时**独立**回查该年度的全球公开新闻、政治政策、企业披露、资本市场、金融研究、科技、军事、医学及社会统计。不能仅以52份周报作为原材料。

年报至少做以下12项可检查工作：
1. 列完整周报发行清单、各期原始时间截点与缺期；
2. 独立建立年度新闻/机构原始资料集及许可清单；
3. 形成年度时间轴：当时已知与年底所知分开；
4. 复核宏观、美股/国债/资产、全球企业和行业、创业、政策/政治、AI/医学/科技、地缘/军事、社会结构的真实可比指标和数据修订；
5. 同源/转载去重并对比全年周报是否漏掉真正有影响或典型的事件；
6. 关联跨领域因果机制，找短期变化与长期结构/反常信号；
7. 对旧判断逐条核时间、原句、当时证据、实际结果、误差原因和未决状态；
8. 对已在各期提出的创业机会/投资与战略主题，以全年兑现与失败事实重估；
9. 由年度重大正负典型案例提炼真实可迁移知识，而不是“世界很复杂”式主题词；
10. 每个重大专题写“全年事实报道→年度顾问研判→年度帝师教学→有条件的后续推演与开放问题”；
11. 事实/时间/版权/逻辑/旧判断审计和主编质量门禁；
12. 形成完整Markdown及必要排版预览、参考来源、历史新旧版本与更正日志；**真实发布与发送另需用户授权**。

**年报不可做的事**：把52份文章直接拼接；以后见之明修改年初旧观点；不独立搜全年原始资料；忽略被本刊漏掉的正面成果和重大负面事件；用年末数据假装当时就知道。

# 十、从全世界到一篇内参的唯一六层逻辑（职责与真实可测工序）

```text
全球真实开放新闻/官方报告/论文/财报/基础数据
   |
   V
L1【来源与独立发现】多语种+主流+边缘重大信号
   input: SOURCE_REGISTRY(可访问免费子集) + 新公开线索
   output: Candidate/SourceRecord/coverage+时间/版权状态
   failure: 源断流→标源不可用，不凭空生成新闻
   |
   V
L2【事件聚类、选文委员会】先执行S0—S7，L3查证后回访S8作第二次选文审查
   input: Candidate + 历史Theme/权威报告
   output: EventCluster/TopicDecision/ReportingPlan/ScoreReason
   failure: 热度高无影响、典型不足、素材不够→降级/WATCH/DROP
   |
   V
L3【专业新闻证据核查与记者报道】5W1H, REPORT方法；完成后返回L2执行S8
   input: 合规公开原件与专业数据/不同意见
   output: EvidencePacket/ClaimRegister/NewsDraftA/FactLimitations
   failure: 数字/时间/法律/方法错误→补证；侵权→BLOCK
   |
   V
L4【一套联合顾问—帝师工作台】七问三校验+互相返工
   input: EvidencePacket + 历史命题 + NewsDraftA
   output: AdvisorB1/MasterB2/ScenarioC/Counterargument/TeachingCard
   failure: 因果错、空泛、类比错误→回L3/L4修正；未知注明
   |
   V
L5【独立事实/逻辑/专业/版权审稿】可真正否决
   input: A/B1/B2/C + 原始证据与许可
   output: PASS/REVISE/BLOCK + issue/revision log
   failure: 重大错误停止出刊；修后重审
   |
   V
L6【主编、杂志生产与历史归档】WEEKLY/ANNUAL
   input: 通过审核的独立文章 + 封面与栏目 + 原始引用
   output: Edition Markdown/HTML/PDF(可选)、版本/旧判断、
           历史资料与未来验证，授权后才有交付回执
   failure: 漏章、断引用、重复文章、未授权交付→BLOCK
   |
   +---- 未来真实新材料/读者反馈/年度纠错 ----> L2/L3/L4
```

**层不是Agent数量**。L4只有一个知识研究工作台；记者/顾问/帝师/反方审核是逻辑职责，可以由一个LLM在受控阶段处理，但**重要事实独立审稿不能由自评声称通过**。无需针对九个栏目训练九个模型，也不为了复杂而强制引入GraphRAG、十几个Agent或昂贵付费数据源。

### 六层与具体交接契约

| 环节 | 前序给什么 | 本环节实际交什么 | “继续”所需条件 |
|---|---|---|---|
| L1→L2 | SourceID、链接、合法范围、语言与时间 | 可按事件聚类的Candidate | 不把主页访问当正文证据 |
| L2→L3 | 事件、S0—S7初选记录、重要性理由、报道体裁与计划 | 有证据可写的报道任务 | 通过S2四门、可撤回 |
| L3→L2(S8)→L4 | 有可引用Claim与新闻A草稿、原始资料、未决项 | **先回L2完成研究后二次选文，仍入选者才进入同一个研究案卷与完整顾问/帝师/推演** | A的六要素与报告方法准确，不把B推断偷放A；S8有明确COVER/WATCH/DROP决议 |
| L4→L5 | B1/B2/C、竞争解释、反例、开放题、旧判断 | 可逐句复查的原创分析稿 | B按七问三门；C有两条真正不同条件路径 |
| L5→L6 | 审稿决议、修订后的A/B/C、引用版权检查 | 可排版杂志原稿及审稿日志 | 所有重大BLOCK清零、完整性检查 |
| L6→下期 | 刊物版本、原件、Theme/Thesis/Concept、未决问题 | 可靠历史索引与年报输入 | 旧原件不可覆写、时间戳保真 |

# 十一、独立质量审稿：每一类错误具体怎么处理

**稿件等级**：`PASS`可交主编；`REVISE`说明缺什么证据/教学/事实并返工；`BLOCK`涉嫌核心失实、许可/法律硬冲突、伪造现场采访、严重错误因果或无权处理受限正文，未修不能出刊。

| 质量闸门 | 必须具体检查的事项 | 典型反例及处理 |
|---|---|---|
| 入选题 | 是否真正产生或可能产生重大正负影响、典型机制/突破、足够合规材料 | 只有热搜无现实影响→DROP |
| 新闻A | 5W1H、事实状态、关键时间、统计口径、背景/多方、报告样本方法 | 草案写已执行、伪“记者采访”→BLOCK |
| 顾问B1 | 真正问题、参与者权限、利益与约束、多因竞争/共同作用、事实与推论 | “因为人性复杂所以股价必涨”→REVISE/BLOCK |
| 帝师B2 | 正规学科、原因怎样发生、真实实例/数值/流程、反例、跨域迁移 | 古籍名言证明现代动机→BLOCK；只堆术语→REVISE |
| 情景C | 不同条件路径、行动/中间变量/受益损害/失效条件，2—4开放题 | “下周继续观察”、伪造72%概率→REVISE/BLOCK |
| 整刊 | 目录、章节、跨文章去重、自然中文、来源/完整性、历史版本 | 因Token截断漏掉末篇→BLOCK |
| 年报 | 年度周报及独立原始源双输入、数据修订、历史原句、漏报 | 拼贴52周报或改写当年原句→BLOCK |

**反证不可打折**：政治冲突可以有多个机制；统计相关不等于因果，哪种制度在不同国家成立应重查法源；对重要事实反方应按证据分配篇幅，不能制造虚假“五五平衡”。重大失误要发布可定位的更正记录，年报要审查自己错在哪里。

**中文写作标准**：消息事实忠实、记者段克制、顾问观点明确但标推断、帝师深入浅出；翻译需保留原文意图、专业术语、条件和证据强度，不出现“战略赋能、深刻洞察”等无法定位的空话；写长不等于有价值，篇幅动态、不能静默删重要事实。

# 十二、未来数据与版本化档案：必须存什么

**建议的最小对象**：
- `SourceRecord`：来源ID、合法范围/许可证、时间、实际可用性；未审核就标未审。
- `Candidate/EventCluster`：原始发现标题与时间，合并的事件与转载血缘、区域/语言/影响对象。
- `StorySelection`：S2硬门、S3受益/受损、S4典型/突破、S5评分及理由、S8撤稿/二审记录。
- `EvidencePacket/Claim`：事实内容、最小可定位出处、原发表时间、关键数字单位/样本/数据期、确定性/限制。
- `SharedResearchDossier`：七问、约束/人物与利益、候选机制H1/H2、反方与未来区分证据、真实知识/反例与返工历史。
- `Article`：唯一A报道、B1顾问、B2帝师、C后续推演+开放题，各有可追溯事实与编辑审核。
- `Theme/Concept/MechanismCard`：长期观察与已经讲过的正规学科知识、适用/不适用案例、跨期召回索引。
- `ThesisVersion`：永不删除的旧观点原话、当时所知、置信理由、待核验指标、后来更正/是否证实。
- `WeeklyEdition/AnnualEdition`：发行ID、内容截点、每篇引用、原稿hash/版本、出版状态、全年双输入清单。
- `Run/Audit/DeliveryReceipt`：研究和编辑门禁、预算/失败/重试；邮件状态依“生成/提交/服务商接受/实际确认”分别记录，不能自动声称已送达。

**保真原则**：以后说“把三年前那个保险合作想法拿出来”，应能取回**当时完整原件/文档与原决定**，不是AI自编摘要；相关的新变化另建立衍生记录。用户以后对本项目说“你说得对、同意、这个很好”，应定位被认可的**具体原方案、步骤、边界、例子和文件版本**，更新`ENDORSEMENT_LEDGER.md`与`DECISIONS.md`，不能只记“用户同意”。

# 十三、工程实现与运行安全：现在只留约束，不虚报成熟度

### 1. 最小必要技术块

- **发现适配器**：合法免费RSS/API/公共网页/公告索引，以SourceRecord识别权利范围和失败。
- **证据与研究管道**：真实来源回查、Claim、ReporterA、SharedResearchDossier（七问三门、顾问帝师为同一共享案卷）。
- **独立审核/主编**：审稿对象与通过/返工/阻断记录。
- **出版与档案**：统一Markdown原件、HTML/PDF可选、WEEKLY/ANNUAL以及可重放历史版本。
- **横切运行保护**：权限、Token花费、引用与版权、幂等、故障披露、备份和收件状态；失败不得伪装成功。

建议从一套Python轻量流程+JSON/Markdown/SQLite或全文索引开始。RSSHub、FreshRSS/Miniflux、trafilatura、SEC EDGAR工具、OpenBB/GPT Researcher/Open Deep Research等**都是未来候选**，需实测授权、兼容、费用和运行价值后才接入；无需一开始强制n8n、GraphRAG或九个Agent。

### 2. 明确未获授权事项

不改现有日报及其GitHub Actions/Secrets；不重新测试余下百余源；不向任何邮箱发送内参；不创建周/年定时任务；不购买API/数据库或绕付费墙；不将公开仓库放入敏感凭证和受限全文。**设计完成≠内容引擎运行≠真实刊物已出刊≠邮件已确认送达**。

# 十四、未来实施前的验收路线：用户目前只批准设计审计

1. **设计完整性审核（本轮）**：逐项核对决定/认可记录与本主规格，核新旧文档优先级，确认周报、年报、A/B1/B2/C、九栏、选文、资料权利、历史档案都写进主文档；记录缺口，不装作已建软件。
2. **用户将来明确准许做样刊后**：先拿6篇不同领域、有合法公开原始资料的真实新闻或报告（美股2、创业1、政治1、AI科技1、宏观1为历史建议，可因世界本周大事调整），为每篇留下S0-S8审核、A完整报道、B1/B2、C真实推演/开放题及独立评审记录。历史示范不得假冒新新闻。
3. **三类负面测试**：①媒体标题吸睛但实际没有影响，应淘汰；②记者A完全有据但顾问因果错误，应返工；③B有高深知识但C凭空预测或只有引导题，应退稿。
4. **周报离线样刊**：主编统一封面与目录、章目去重、链接/来源/字数及自然中文、A段不被过度缩短、单次完整生成不截断；不得暗中外发。
5. **历史召回和年报干跑**：读出真实旧案卷与旧判断版本，独立回查指定一段年度原始材料，验证未被周报捕捉的遗漏、错判与数据改动。
6. **只有质量、权限、技术预算、真实服务状态和用户另行批准后**：才考虑长期生产运行、计划时间和合法投递。
