# 案例一：两个政治人物为什么公开争吵？

## 1. 假设事件（不是现实新闻）
在一个**实行议会制、内阁依靠议会多数支持、财政拨款须经议会法律程序**的虚构国家，首相宣布未来两年扩大基础设施投资，执政党中部分议员要求优先减税；反对党领袖在议会公开指责首相不守财政纪律。双方几天来密集接受媒体采访，立场似乎越来越尖锐。

**普通新闻**会说：首相与反对党领袖争吵激烈、政治对立升温、未来计划遇阻。

**内参记者先查事实**：
1. 首相到底公布的是政治愿景、内阁批准的预算草案、已经完成立法的拨款还是实际签署合同？这些是四件事。
2. 实际可获得的议会席位、投票时间、财政部预算报告是什么？大声争论与真正失去多数票不是同一回事。
3. 议会预算程序包括哪些阶段？哪一方有提出修正、拖延、否决或要求信任投票的真实权限？
4. 执政党内部的反对人数是否足以改变关键表决？实际党纪/执政联盟安排是否限制个人投票？
5. 这轮争论的发布日期、选举日程、下次投票与财政数据发布时点分别是什么？

如果没有拿到预算文本、投票资料和制度原文，报道只能写“双方宣称”，不能写“政策必然流产”。

## 2. 第一层：政治权力不是一个人的“命令”
首相具备政治领导权，不等于能单方面调动所有财政资源。这里必须先教**国家权力分工**：

- **立法权**：通过/修改法律并监督政府。议会的预算批准和拨款程序是政策变成可支付项目的重要约束；不同国家财政发案权及表决规则不同。
- **行政权**：依据宪法、法律、预算授权执行公共政策；内阁/部委计划未必自动生效。
- **财政权**：税收与支出必须受法律和预算规则制约；“承诺支出”与“获得拨款”分开。
- **司法约束**：法院可以在法律和管辖范围内审查特定行政行为或法规，但不意味着法官可以按个人政策偏好决定预算；具体范围依国家而不同。
- **议会制与总统制**：在议会制，政府存续往往依赖议会信任；在美国总统制，行政与国会是分别产生的权力机关，不能把党鞭、倒阁和预算流程原样套用。
- **党纪/党鞭**：政党协调表决与个人议员代表选区的关系；形式党纪与实际惩罚能力未必一致。
- **选举激励**：议员同时面对本党提名、所在选区选民、捐助者、全国舆论和下一次竞选，激励不一定同向。

**费曼式解释**：一个组织的领导人可以宣布要建一栋楼，但工程是否启动还受钱是否批下、合同是否合法、施工者是否同意和监理是否批准等限制。这只帮助理解“有意愿不等于具备全部执行条件”；**国家不是企业**，法律位阶与政治合法性绝不可用公司比喻取代。

## 3. 第二层：他们为什么选择“公开争吵”？
不要先假定“他们都在演戏”。从**策略性互动**提出至少四种竞争解释：

**H1 真实政策分歧**：一方更重视基建产能，另一方更重视债务/通胀/税负。这是实质性的公共资源分配意见差异。若政治主张对应一贯投票记录、实质修正案和实际支付方案，H1更有说服力。

**H2 向选民表达立场**：政治人物希望支持者看到自己没有让步。即使最终仍会妥协，公开发言可形成“对选民的承诺”。可检查选区民调、历年表决、临近选举、地区利益分配。

**H3 谈判筹码与可信承诺**：公开要求让内部妥协成本提高，从而压迫对手改变方案；但过强表态也会导致双方失去下台阶。可查是否存在实质让步、分项预算交换、最终文本改变。

**H4 党内权力/联盟约束**：表面上两位领袖交锋，真正让政策不稳的是联盟席位、党内领袖地位或关键委员会。可查联盟协议、反对议员人数、议会日程和实际投票。

H1—H4可以同时成立，不能强迫互斥。**记者报道给事实；研究员提出假设；顾问教会用什么证据区分。**

## 4. 第三层：把“闹翻”与“政策后果”分开
假设该虚构国家议会共100席，政府联盟占54席，法定普通法案需过半数，且没有额外特别法定门槛。**仅为演示，不可跨国套用。**

- 若政府议员54人全部赞成，普通表决可能通过；
- 若其中6人反对且其他人投票不变，赞成可能变48，反对可能变52，政策通过机会明显改变；
- 但真实情况下可能有弃权、议长投票规则、联盟外合作与不同议案程序，不能只看54-6作现实预测。

**真正的变量不是谁嗓门大，而是谁拥有足以改变正式表决的否决权/票数，以及谁承受不合作的成本。**

这一简单例子也揭示博弈论的三个问题：
1. **可信承诺**：公开宣布“绝不让步”是否提高自己妥协成本？
2. **重复博弈**：本次表决得失是否影响未来若干次预算案合作？
3. **信息不对称**：各方是否清楚真正有多少议员愿意投反对票？

## 5. 第四层：宏观、市场和个人为什么在乎？
政策争论可能影响实际公共支出预期、税收路径、政府债务发行或特定行业订单。但中间至少有四道门槛：

\`\`\`text
公开争论
  → 是否改变正式议会/行政决策？
  → 正式决策是否改变实际拨款与合同？
  → 支出/税收变化是否影响真实现金流和经济活动？
  → 市场是否已经预期、是否还存在相反的利率/风险因素？
\`\`\`

不能把“新闻争吵”直接画箭头到“股市必须下跌”。市场还会因原本预期和其他变量出现反向反应。

## 6. 给最强反方公平的机会
有人主张“公开对峙主要是选举表演”，其最佳证据可能是高度重复的竞选话术、幕后具体妥协后公开不变的激烈发言、表决行为与口头立场不同。但这些只能支持部分策略性元素，不能直接证明所有参与者“假装争议”。

相反，实际预算文本是否修改、政府联盟是否丧失多数、政策是否执行可提供更有区分力的事实。

**读者应学会**：当下一次听到任何两位政治人物激烈争论时，先查该国的权力结构→实际法案或预算程序→投票/联盟与否决点→关键激励与证据→市场/社会影响链，而不是替人物写内心独白。

## 7. 一段符合刊物风格的示范文字（假设报道，不可发表为现实事实）
> 首相的基础设施承诺在议会内遇到的阻力，未必来自反对党最激烈的那几次发言，而可能来自政府对预算程序和执政多数的依赖。公众所见的是政治人物的争论，真正决定工程能否启动的，却是议会何时完成拨款、执政联盟能否守住关键表决，以及行政机关能否随后形成合法合同。
>
> 这也是理解现代政治的第一课：一个人宣布的方向，不等于国家已经具备完成它的权力与资源。不同制度把决定权分配给不同机构，使公开争论既有可能表达真实政策理念，也可能服务于选举和谈判。对投资者而言，正确的问题不是“谁赢得了这场口水仗”，而是“哪条可以依法实施的政策究竟改变了谁的现金流，以及市场此前已经预期到什么程度”。

# 案例二：一家用AI提升医院行政效率的创业公司，为什么能赚钱？

## 1. 假设事件（不是现实新闻）
一家虚构的初创公司 **ClinicFlow AI** 宣布获得融资，产品声称可以减少医院预约登记、转诊材料整理、保险理赔资料预审和病历行政录入的重复工作。它宣称某些试点单位效率提升35%。

普通新闻可能只讲融资额、创始人、产品和融资方。

**一流创业顾问首先不问“AI模型先进吗”，而是问**：
- 医院里面真正痛苦的流程在哪里？
- 对谁而言是痛苦？护士、医生、行政、IT部门还是财务负责人？
- 谁有采购权限、预算和法律责任？
- 没有这个产品时，医院用人力、现有信息系统、外包或其它软件会花多少钱？
- 宣称节省的时间能否变成真实现金节约、更多病人服务能力或更低错误成本？
- 公司每新增一个医院客户究竟赚多少钱？实施是否要大量人工服务？
- 医院愿意在试点结束后**自己续约付费**吗？

## 2. 第一性原理：商业赚钱的三个条件
**A 创造可验证价值**：减少错误、缩短流程、提高服务吞吐、改善结算，不是简单把一个表格改成聊天框。

**B 能捕获部分价值**：医院必须有预算、有采购流程，并认为付费价格低于可实现的价值；产品没有付费者就不能稳定产生营收。

**C 能持续交付且保留毛利**：模型推理、人工校验、系统集成、合规和售后成本不能长期吞噬所有订阅收入。

产品采用率、融资估值和“节省分钟数”均不是这三个条件的自动证明。

## 3. 必须先教会的八种角色/指标

| 术语 | 通俗解释 | 医院AI产品中的实际问题 |
|---|---|---|
| User使用者 | 每天点击产品的人 | 护士或行政工作人员真的愿意用吗 |
| Buyer采购者 | 有采购权/预算的人 | 医院财务、运营、信息部门谁签字 |
| Beneficiary受益者 | 得到价值的人 | 医院、病人、医保支付方是否同向受益 |
| Switching cost转换成本 | 从现有流程迁移的代价 | HIS/EHR接口、培训、停机、法律审核 |
| Gross margin毛利 | 收入减直接服务成本后的比例 | AI推理、人审、服务器和集成维护 |
| CAC获客成本 | 签下一个新付费客户平均花多少钱 | 销售人员、招投标、试点、差旅 |
| Retention留存 | 客户是否续用续付 | 3个月免费试点后是否签付费合同 |
| PMF产品市场匹配 | 需求与产品/价格/渠道真匹配 | 医院自愿续约、扩席位、推荐给他院 |

注意：以上指标的财务会计分类依合同和企业报告口径调整，不能把一次性实施费、确认收入、预收款和年度合同价值混为一谈。

## 4. 用一组清晰数字讲单位经济性（全部假设）

假设医院每月付费 **1,500美元**：
- AI推理和服务器：300美元/月/院；
- 客服与人工复核的直接服务成本：200美元/月/院；
- 实际发生的可变系统维护与接口成本：100美元/月/院；
- 因而每个客户月直接成本约600美元；
- 单客户月贡献额（简化）=1,500-600=**900美元**；
- 简化贡献率=900/1,500=**60%**。

注意900美元仍**没有扣除销售团队工资、研发、管理、税、利息、固定合规投入**。所以不能说“每医院每月净赚900美元”。

假设平均签约一个实际付费客户需要 **10,800美元**的可归属获客投入（包括招投标、售前工程、销售与试点分摊），静态获客回收期=10,800/900=**12个月**，而不是只看一次销售佣金。

假设每月付费客户流失率4%，并且非常粗略地假设无限期稳定、没有贴现、没有扩张、没有合规突发费用，那么静态LTV近似=900/0.04=**22,500美元**；LTV/CAC≈2.08。这个近似**对医院年度采购合同可能不合适**，因为合同续约是年度跳跃、流失不是均匀每月发生，且CAC/贡献额可能随客户规模改变。它只是教**指标之间的方向关系**。

三种变化足以推翻表面盈利故事：
- 因隐私审查每个医院需一次大量集成和人工核验，真实成本高于预算；
- 客户第一个年度合同后不续费，12个月获客回收刚达到就失去现金流；
- 大型医院强行降价、要求本地化部署，使边际成本大幅上升。

因此一个有专业水准的顾问不能说“订阅软件毛利高，稳赚”。

## 5. 现金价值：效率提升 ≠ 医院真实节省同额现金
假设一个试点行政团队工作日每天释放4小时，每月20天，每小时综合人工成本为30美元，那么**理论劳动时间价值**=4×20×30=**2,400美元/月**。

这个2,400美元可能表现为三种不同结果：
1. 医院真的减少外包/加班或合理减少某个费用，形成可核实现金节约；
2. 不减少员工，但病人接待能力变强，若需求存在可能增加营收或缩短等待；
3. 工作人员只是把时间转移给更复杂任务，虽然有服务质量好处但未必能直接转成现金流。

如果产品每月收费1,500美元，表面“净价值900美元”**只有在2,400美元效益能兑现且未漏算转换、培训、安全与错误成本时才成立**。读者学到的不是公式，而是**价值创造与价值变现之间的断裂**。

## 6. 谁决定购买，谁承担失败？
医疗场景必须额外拆：
- 一线使用者可能需要高可用性和更少录入；
- 医院财务可能要求可量化节约；
- IT和信息安全可能承担数据泄露或供应商集成风险；
- 医生护士对错录/假阳性承担实务负担；
- 患者承担隐私和服务体验影响；
- 监管者关注真实法定要求。

**同一产品对不同人产生不同的收益和风险**。真正困难的可能不是把LLM连接到表单，而是协调医院采购、现有信息系统、真实流程责任、隐私安全和变化管理。

隐私/医疗数据的法律要求要**按司法辖区、数据种类与具体业务**确定；不能认为美国HIPAA普遍适用所有国家，也不能自动认为所有行政AI都是受监管医疗器械。必须由法律/合规和业务事实分类。

## 7. 竞争和进入壁垒是什么？
顾问应至少比较五种替代：
1. 人工行政团队改造流程；
2. 医院现有HIS/EHR软件供应商加一个功能；
3. 大型BPO/行政外包；
4. 通用大模型工具加医院内部开发；
5. 本创业公司的专用工作流。

若医院现有供应商免费上线类似功能，公司没有客户数据许可或强渠道，技术并不构成持续壁垒。

可能成立的优势应以证据支持，例如：真实工作流集成深度、合法且可迁移的数据治理、合同续费、部署速度、验证过的错误控制、跨医院标准化能力。**不是“有AI”三个字**。

## 8. 反方研究：融资与“35%效率提升”不能当盈利证据
- 效率提升百分比的**分母和测量方法**是什么？是人工录入时间、整体行政成本还是预约周期？
- 试点样本几家医院？是否对照？医院是主动选择试点的早期热情客户吗？
- 资金来源是风险投资还是已实现的客户付费收入？融资可以补贴试点，使短期价格不反映长期成本。
- 医疗数据隐私与错误率在真实部署后是否可接受？
- 是否存在一大半“节约时间”但没有任何可以兑现的预算？

最强反方H2可能是“这是有用的效率工具，但它的经济利润主要会被已有医院软件平台捕获”。验证应比较医院采购续费、客户换平台成本、集成依赖和价格权。

## 9. 普通小团队如何低成本验证这一机会？
**不是让读者直接去医院销售一个不合规医疗AI系统**，而是教授可迁移的创业验证：
1. 先选择非诊断、低风险、合法可做的狭窄行政流程，核查合规范围；
2. 访谈至少若干目标使用者、预算拥有者和信息安全负责人，记录真实痛点/当前替代/预算，不把“大家说不错”当订单；
3. 做人工模拟或脱敏合成数据Demo（有真实数据须获明确授权与合法保障），测量准确率与净节省时间；
4. 争取付费小试点，**看真实出钱的人能否完成采购**；
5. 追踪每院实施成本、复购/续约、客户引荐与单位经济性；
6. 若成本太高、采购周期太长或合规不可承受，应诚实放弃，不把它包装成人人都能做的创业红利。

## 10. 写成内参后，真正要教会的是什么？
此例不是“医院AI创业值得投资”，而是让读者今后面对**任何**AI SaaS公司都懂得问：
**使用者是谁→采购付款者是谁→用户价值如何变为现金→单客户贡献是否覆盖获客/留存成本→为何别人不能快速复制→扩张时哪项成本/法规会恶化？**

假如把医院换成律师事务所、保险公司、学校或物流公司，这套顺序依然大致可迁移，但每个行业法规、付费方与工作流都需重新验证。

# 案例三：企业盈利大涨，股价为什么还会跌？

## 假设消息
虚构科技公司年度每股盈利增长10%，但股价在财报公布后下跌。外部标题说“利好出尽”。这不解释实际机制。

### 要先教的四层事实
1. **实际**：营收、利润、自由现金流各是多少，是否有一次性项目或股数变化？
2. **预期**：公告前分析师与市场预期是多少，估值是否已隐含更高增长？
3. **资本成本**：贴现率/长期利率/风险溢价是否改变，长期增长预期与资本开支是否改变？
4. **市场交易**：指引变化、仓位、流动性和消息时间是否引发短期波动？

如果分析师原预期为增长20%而只实现10%，较上年“增长”不等于较市场“超预期”。

### 用数值解释价值而不是把数值当现实目标价
简化假设某业务未来一年可分配自由现金流为1亿美元，永续增长率2%，折现率10%，不考虑其它复杂条件，则稳定增长永续模型：
\`估计现值 = 下一期现金流/(贴现率-长期增长率) = 1亿/(0.10-0.02)=12.5亿美元\`。
若其它条件不变，折现率升至12%，估值示意变成\`1亿/(0.12-0.02)=10亿美元\`。这证明**现金流没变、贴现率也能改变理论价值**；永续模型条件很苛刻，不是现实股票目标价，不能简单用于亏损成长企业。

### 最强反例
盈利低于预期，公司可能公布更好未来订单、现金流或市场预期而上涨；短期股价不是一个公式决定。

**迁移问题**：拿一家公司新闻，试着先分清它的业绩、公告前预期、长期现金流假设、贴现率和仓位——而不是看“利润增长百分比”就下结论。

# 案例四：AI技术突破后，为什么不一定快速商业化？

## 假设场景
一个实验室声称其新AI系统在指定测试上性能超过既有软件，但真实企业部署速度非常慢。

**第一性研究分六关**：
1. 论文的实验数据集、评分口径和基准是否公开，结果是否独立复现？
2. 技术在实验室条件下工作，真实客户数据分布、异常、延迟和安全要求是否不同？
3. 生产每任务的推理/电力/芯片/存储/人审成本是否覆盖在收费价格里？
4. 是否需要企业已有ERP/EHR/工作流集成、员工再培训和法律许可？
5. 真实采购者愿意为多大的收益付钱，新增采用是否会降低已有业务收入？
6. 竞争者是否能够用低成本替代方法达到相同用户效果？

**科学准确性、工程可靠性和商业盈利性是三道独立门槛**。一项模型基准得分超过旧模型，不等于公司收入马上超过竞争者。

### 技术反常信号举例
如果模型基准提高40%（纯假设），但企业续费和实际任务完成率没有相应改善，应检查：
- 基准是否与实际客户问题弱相关；
- 成本是否过高/部署是否慢；
- 用户体验与风险是否不被生产客户接受；
- 企业缺少采购预算、系统集成或足够流程改造激励。

**迁移问题**：以后看到太空计算、核聚变、机器人、医疗AI或新材料突破，同样分“理论上能否→实验室是否证实→规模工程是否可行→单位经济性和实际付费是否成立”。

# 每个案例的教学验收：换一个完全陌生的问题

| 已讲案例 | 用来检验迁移的新问题 | 合格的思考方式 |
|---|---|---|
| 政治争论 | 另一国城市政府说要大幅投资交通，为何未动工？ | 权限/拨款/执法/选举激励/真实资金流，不机械套议会制 |
| 医院AI创业 | 律所AI合同审查软件融资很高，如何判断盈利？ | 用户/采购者/付费/替代/单位经济性/留存/合规 |
| 利润涨股价跌 | 企业宣布扩大回购但股价仍低迷，如何分析？ | 看FCF、估值、价格预期、资本配置和资金约束 |
| 技术突破 | 电池研究电解质改进，何时可以商业化？ | 可复现、量产成本、安全、寿命、供应链、付费需求 |

**真正的教学达标不是记住上面四个故事，而是能在新问题中自己提出正确的问题。**
