# 内参系统｜深度认知学习引擎：完整目标、工作机制与可执行教学协议

> 设计版本 V3.1（2026-10-13）。**这是本项目最重要的产品能力规范之一，而不是一份“在提示词中写帝师二字”的风格宣言。** 尚未实现为生产代码。本文与[COGNITIVE_ADVISOR_SKILL.md](COGNITIVE_ADVISOR_SKILL.md)、[CASEBOOK_POLITICS_AND_STARTUP.md](CASEBOOK_POLITICS_AND_STARTUP.md)、[INTELLIGENCE_OPERATING_MODEL.md](INTELLIGENCE_OPERATING_MODEL.md)共同构成教学与研究的执行标准。
>
> 这里的“深度学习”是**读者对世界机制的深入学习**，不是指训练或微调深度神经网络。内参最终交付的不是“结论”，而是读者面对陌生问题时可独立使用的分析方法。

# 第一章：学习最终要改变什么

## 1.1 学习北极星：让读者不用内参也会思考

用户要求的“帝师”是教学效果的比喻：**宏观视野、扎实知识、善于推演、能够深入浅出教会人**。不允许用居高临下的语气、名人模拟、神秘内幕、臆测动机来代替专业能力。

一次成功学习的最低转变：

| 读前状态 | 读后最低进步 | 更高水平的迁移 |
|---|---|---|
| “政治家在吵架” | 能区分议会、行政、司法、财政、党派和选举各自能做什么 | 面对另一个国家的政治冲突，先辨认制度差异、权力程序、成本承诺和可证实证据 |
| “某公司股票涨跌” | 理解盈利实际、预期、现金流、估值、贴现率和短期资金流可能同时作用 | 用陌生公司财报提出多种假设，并找证据区分 |
| “创业公司融了很多钱” | 区分融资、用户、营收、毛利、现金流与单位经济性 | 能设计低成本付费意愿实验和客户获取测量 |
| “AI技术好厉害” | 分清实验条件、可复现性能、成本、工程约束和商业采用 | 对别的前沿技术也会问规模化、能耗、可靠性与谁付钱 |
| “权威机构说未来会怎样” | 知道资料来源、机构利益、模型假设和反对证据 | 会更新自己的判断，允许过去的意见被事实推翻 |

**目标不是掌握百科知识点，而是获得结构化世界模型**：国家（制度与权力）、社会（人口与激励）、资本（预期与现金流）、企业（客户与利润）、技术（物理与成本）通过条件链互相影响。

## 1.2 六项目标映射到教学指标

- O1 世界机制：文章必须明确解释至少一个“条件→行为→结果”的机制，而非仅有事件经过。
- O2 独立判断：必须说明竞争性解释、何种证据能让现有结论改变。
- O3 投资创业：相关题材应教会一个可检查现金流/客户需求/资本配置的分析动作，不强推投资机会。
- O4 长期累积：正确编号与引用Concept、Theme、ThesisVersion；不能把旧知识卡覆盖成新观点。
- O5 反信息茧房：对强争议给最强反方+利益位置；独立媒体及机构来源，非机械各占一半。
- O6 真实前沿：源链溯及可合法获取的原始文件、可信一线报道、财报、科学工程数据。取得什么就说取得什么。

**内容合格≠用户已掌握**。没有读者主动参与检验则记录 TAUGHT/NOT_ASSESSED，不能谎称MASTERED。

# 第二章：核心工作方式不是“新闻后加点评”

研究系统内部必须分出四种产品：
1. **事实报道 Fact Brief**：对新闻、原始材料的忠实原创转述，保留核心时间、主体、行动、数据和重要立场。
2. **研究推演 Mechanism Analysis**：拆解制度、物理、现金流、行业结构、行为激励和因果链，并标注哪段是有证据支撑的解释。
3. **教学单元 Learning Path**：只围绕理解本事件必须学的背景知识，给严格定义、生活解释、数值示例、反例与适用边界。
4. **验证和长期更新 Learning & Thesis Check**：读者可以在新情境中试用，系统追踪反证/新信号，必要时纠错。

不允许“事实只写两行、余下几千字大谈未经证实的宏观格局”。篇幅根据证据和难度决定，不要每篇按机械七段输出。

# 第三章：从一条真新闻到一堂深课的十一道内部操作

| 步骤 | 操作与具体问题 | 必须记录的中间结果 | 若失败 |
|---|---|---|---|
| L-01 事实冻结 | 哪个机构、人物在什么时间**实际做了什么**？公开言论与正式行动有何区别？ | claim_id、来源、时间、原话指针、证据性质 | 缺证据→退研究 |
| L-02 找研究问题 | 这件事到底暴露哪个机制？问题能否具体到“为什么A约束B”？ | question、why_now、不可回答问题 | 无研究价值→不深写 |
| L-03 诊断知识瓶颈 | 一个聪明但不了解制度/专业术语的读者会卡在哪里？ | prerequisite_concepts（通常2—5个，可变） | 过宽→缩小题目 |
| L-04 权力与资源盘点 | 谁可决定？谁有否决权？谁支付代价？谁获收益？谁掌握信息？ | actors, authority, incentives, constraints, information_gaps | 未证实动机→标假设 |
| L-05 第一性机制 | 最基本的制度/经济/物理/法律条件是什么？从哪条条件到哪条行为？ | mechanism_chain（分事实/推断） | 相关冒充因果→返工 |
| L-06 费曼教学 | 不懂术语能否解释？可否给可信的小数字、日常类比或流程？ | formal_definition、plain_explanation、worked_example | 类比失真→重写 |
| L-07 案例与反例 | 历史相似案例的决定性共同变量是什么？差异和反例在哪里？ | cases, counterexamples, comparability_tests | 不可比→撤销比较 |
| L-08 最强反方 | 有没有另一种也能解释事实的假设？哪种证据最有区分力？ | hypotheses、evidence_for/against、unknowns | 稻草人→重建 |
| L-09 条件情景 | 如果变量变化，机制何时成立/失效？能否给数据的边界/单位？ | conditions, observation_indicators, dates | 假概率→取消 |
| L-10 新情境迁移 | 换另一国家/公司/行业，读者会用什么三步去检查？ | transfer_rule、new_case_question、common_trap | 只能复述本篇→补课 |
| L-11 知识追踪 | 哪项知识刚讲过？与旧知识有何不同？如何在后续真实事件中复核？ | ConceptCard、ThemeRef、learning_status | 不能找原件→不算归档 |

### L-01到L-03的详细动作
- 冻结as_of时间与源发表时间，长篇引用时保留表、图、官方文件页码；不能事后拿今天信息当昨天证据。
- 将论文、社论、记者现场观察、政府公告、基金策略报告、公司自述分不同证据层级，不以“来源权威”直接替代事实验证。
- 教学问题应窄而深。例如“特朗普和议长为何吵架”太依赖实时人物；更可迁移的是“在当前制度中，行政机关要实施某政策时，立法预算与党派纪律怎样构成约束？”但必须先核实具体国家和制度。

### L-04到L-05：第一性原理的六个镜头
1. **物理与资源**：金钱、时间、能源、芯片、劳动、设备、真实需求等不能凭声明创造；
2. **正式制度**：谁有法律权力制定、执行、否决、审查、拨款？比较制度时避免混同英美；
3. **激励与代价**：获利与损失是否对称，短期选票/年度奖金与长周期结果是否冲突；
4. **信息与信念**：谈判各方是否掌握不同资料，媒体披露是否只是策略性陈述；
5. **预期与反馈**：市场会提前定价，公众/对手会反应，二阶影响可能抵消原本效果；
6. **路径依赖与非线性**：监管程序、客户习惯、政治承诺、技术累积可能造成长期锁定或突然失稳。

每个镜头只能在有事实关联时使用，禁止“万能六因模型”强套所有议题。

### L-06：费曼的三遍讲解
- **第一遍**：一句自然中文——发生的是哪种约束或矛盾？
- **第二遍**：用一个日常例子或小金额算例说明，定义术语、分母、单位。
- **第三遍**：撤掉类比，回到现实案例的真正制度/统计/竞争条件，指出类比在哪里会失效。

示例：讲政治财政权，不能仅说“总统像经理、议会像董事会”，因为具体国家的制衡、民选合法性和财政立法程序并不等同公司治理。类比仅用于引入“提议者可能不掌握全部资源”，随后必须回到该国真实制度。

### L-07到L-09：反方不是每篇一句“也可能相反”
对每项关键结论按四格审查：
- H1 当前主要解释及支持它的公开原始证据；
- H2 使强反方最成立的假设，不能挑弱观点；
- H1和H2都无法解释的观察/数据缺口；
- 最有区分力的新事实、时间、来源和阈值（只有合理依据才使用数字阈值）。

如果事件根本不存在可靠竞争解释，不能为了政治平衡发明势均力敌的反方；可以改为核查边界和测量误差。系统应允许“暂时没有足够证据”。

### L-10与L-11：读者学会一个可复用程序
每篇最终应输出一个**可迁移判断程序**，例如政治冲突：
“先查制度权限→再查各方选择集/否决点→最后用实际投票、预算和政策落实数据判断争论到底改变了什么。”
换成另一个国家，必须重新核查制度，不是照搬美国国会规则。

这比“我的结论是双方在博弈”更有价值。

# 第四章：分领域知识路径（不是无限百科）

## 4.1 政治、国家治理和军事
课程依实际新闻调用，不是所有文章都教所有知识：
- 主权、国家能力、宪制与法律位阶；行政权、立法权、司法审查、地方与中央权限；
- 议会制/总统制/半总统制差异；法案→审议→表决→实施→司法审查的真实流程，财政预算和拨款权；
- 政党与党团、党纪/党鞭、议员选区与初选/选举激励、联合政府、否决点、可信承诺；
- 国际法/条约、贸易关税与制裁的法源和执行；军事产能、后勤、成本交换、战争迷雾和各方宣传；
- 信息不对称、廉价信号与昂贵承诺、囚徒困境/协调问题、重复博弈、国内观众成本；
- 防错：必须先确认国家制度和具体法源；“大人物吵架”不必然是精心策划的戏码。

## 4.2 美股、宏观与资本配置
- 资产=未来可得现金流或风险索取权；不同工具的收益/损失结构；
- 会计利润、经营现金流、自由现金流、资本开支、股票回购/稀释、资本成本；
- 市盈率、企业价值、现金流贴现、预期差、盈利指引、利率期限结构/期限溢价；
- 市场价格可能对已知好消息无反应、对“没那么好”消息下跌；
- ETF、期权及卖Put/Call的收益与尾部风险；股息不等于额外无风险收益；
- 反例：降息不必然推高所有股票，债券利差不等于无汇率风险套利；
- 最终教学产物：给陌生财报时，能构建“实际→预期→估值→资金/政策→风险”的分析树。

## 4.3 创业、商业与企业竞争
- 价值创造：买方是谁/使用者是谁/采购者是谁/痛点有多贵；
- 价值捕获：客户最终为什么付钱，收入性质是什么，谁承担实施成本；
- CAC、LTV、毛利贡献、回收期、留存/流失、获客渠道与销售周期、现金流；
- 竞争性替代：雇员、Excel、传统软件、外包、现有工作流、AI工具；“产品有AI”不是壁垒；
- 单位经济性：从1个付费客户到100、1000个客户时，成本、服务可靠性、隐私/监管是否线性；
- 医疗等领域要拆医院采购、医保/保险支付、临床安全、EHR对接、数据权利；不能将试点当规模收入；
- 低成本商业机会验证：发现可付费痛点→访谈→付费试点→留存→单位经济性→规模化门槛。

## 4.4 科技、AI、能源与生命科学
- 技术主张→实验条件→样本/基准→独立复现→工程部署→总拥有成本→法规/市场；
- 推理延迟、可靠性、能源/热/网络/储存/施工周期和运维不能因宣传视频省略；
- 生物医药区分机制、前临床、临床各期、终点统计、真实世界数据、监管批准、可支付性；
- 一篇预印本或单项试验成功，不自动宣告技术/疗法已商业可行。

## 4.5 社会与国际比较
- 人口、出生率、劳动参与、教育/住房/医疗制度、收入分布与代际结构；
- 区分个体故事、调查、官方统计和因果研究；同名指标跨国口径可能不一致；
- 判断能否推广时必须检验法律、价格、文化、基础设施和收入差异。

# 第五章：持续学习不是“每周读完再忘”

## 5.1 三级知识档案
1. **概念卡 ConceptCard**：是什么、为什么成立、通俗例子、反例、应用条件、关联出处；
2. **机制卡 MechanismCard**：一条可条件化的因果链（例如“利率变化→贴现因子→长期现金流资产敏感性”），包括假设与反向通道；
3. **判断卡 ThesisVersion**：当时“相信/不相信”什么，证据、不同解释、何时改变看法。

研究档案/来源证据和已出版文章仍独立保存，**不能仅保留这三种压缩卡**，原件保存须遵守版权。

## 5.2 阅读反馈的可选渐进机制
- 读完当天：不强制问答，文章末可有“今天你可以带走的一个判断方法”；
- 未来1周：若出现新相关事件，自然提示“上周讲过的那个机制在这里是否仍适用？”；
- 未来1月：回到一个曾经的判断，核查新的事实是否支持/削弱它；
- 未来3—6月：拿不同制度/行业的陌生案例做迁移，检查读者是否真的能独立应用；
- 以上只是**研究/教育内容的可选节奏**，不能据此擅自创建提醒或外发消息，不得假装已持续监控。

## 5.3 知识诊断与“不会用”的处理
遇到用户“看不懂/学不会/记不住/不会用”：
- 看不懂：定位阻碍理解的具体术语/前提，补最短必要知识链；
- 学不会：重做更简单的数值/制度流程示范，不重复抽象解释；
- 记不住：通过真实事件重逢，同一机制异例连接，而不是无穷术语卡；
- 不会用：给陌生但结构类似案例，让读者自己回答三步，针对漏洞复教；
- 已学过但证据改变：明确“框架适用条件改变了”，不是简单认为读者忘记。

系统记录learning_status：
- DISCOVERED（见过概念）、TAUGHT（讲过）、PRACTICED（用户实际应用）、DEMONSTRATED（在陌生情境正确迁移）、NOT_ASSESSED（未测试）。
- 没有用户主动回答或可观察的实践结果，不得自动标DEMONSTRATED。
- 不保存敏感个人成长画像到公开GitHub；读者反馈应选择性、最少量和隐私隔离。

### 输出质量门槛
1. 重要事实均可追溯；没有研究包、不懂许可则BLOCK。
2. 必须真正教授了必要的专业知识，不只是给结论。
3. 读者可举出与本事件不同的新案例来应用；学习目标可测试。
4. 反例与最强反方有效，证据不对称不能伪平衡。
5. 报道仍有信息完整性，不能因为解释很多把时间、数字和官方内容省略。
6. 不能因为“需要有思想深度”就发明历史细节或心理动机。
7. 文章编辑自然，不露出此内部JSON模板，不机械按步骤排版。

# 第七章：建议的六案例质量试验

在六个真实可合法引用的新闻案例中（美股2、创业1、政治1、科技1、宏观1），每例：
1. 把事实包冻结；
2. 产出一篇仅有忠实报道的baseline稿；
