# 内参系统｜V4.4正式端到端工作流（六层、可返工、周报与年报）

> 用户尚在审核完整杂志设计；本文是**未来制作时必须执行的逻辑SOP**，不是已经运行的云程序。唯一现行总纲：[CANONICAL_SYSTEM_SPEC_V44.md](CANONICAL_SYSTEM_SPEC_V44.md)；稿件版式：[MAGAZINE_ARCHITECTURE.md](MAGAZINE_ARCHITECTURE.md)；本轮实质改为“**完整记者新闻A→顾问研判B1→帝师释理B2→事件推演及开放性思考C**”，取消读者版固定“继续观察”栏目。
>
> **版本口径**：只有六层研究/出版架构。内部可以细分十二项生产动作，顾问使用七问三检验，年报有另外十二项年度复查；三种“步数”属于不同层级，不能误以为都必须部署成Agent。

# 0. 永远不能违反的工作不变量

1. 只研究真实可定位的新闻/公共机构报告/财报/科学/调查成果；不能将模型记忆或媒体标题当原始证据，不能伪造本刊采访。
2. 全球发现独立于既有日报；九栏目是资源偏好和阅读导航，不是内容排除器/固定篇幅配额。
3. 选稿真正看现实正/负/混合影响、典型意义**或**重大突破、结构变化、原始证据以及教学价值；不能用阅读量或某位权贵身份洗白。
4. 一篇主文先让读者把事件读懂，再判断，再学知识，再独立思考。**A/B事实与论断不可混淆**。
5. 无任何唯一终极真理的默认假设；让事实决定是否单因、多因、竞争假说或未决。
6. 事实/因果/教育/版权由独立核查，出问题要回退研究，不能润色掩盖。
7. 周报和年报都需历史原件、当时`as_of`、修订与错误日志；用户未经另行批准前绝不启动定期外发、付费源或真实投递。

# 1. 六层任务精确交接

## L1｜公开来源发现：构造候选事实而非新闻结论

**输入**：`SOURCE_REGISTRY.json`活跃公开候选及确实新增的全球合法公开原始线索；126/124等数量必须每次从当前文件真实读取，不得凭历史数改程序；过去用户已弃用源不要重新启用。

**处理**：
1. 按地区/语言/类别取来源的合法RSS/API/网页**允许的公开字段**，记录主页与具体资源链接、发布时间、实际获取时间。
2. 除宏观/投资/创业核心关注，还开探索线索给政治、法律、军事、医疗、地方基层、科技和社会议题。
3. 发现不可访问/付费权限不明，记录`SOURCE_UNAVAILABLE`、`TERMS_PENDING`，不绕反机器人/不从私人API推断权限。
4. 对政府/企业声明、媒体记者调查、行业研报/学术研究，先记其**证据类型**及宣传/资助/立场，暂不判“权威，所以是真的”。

**输出**：`DiscoveryCandidate`（SourceID、URL、发表/事件日、地区、语言、类型、授权等级、状态）、`SourceHealth`和`CoverageMap`。**错误出口**：源故障不等于当期世界没有新闻；合法材料不足进入`NO_SOURCE_EVIDENCE`。

## L2｜事件聚类与选文委员会：先S0—S7初选；证据层之后回访S8

**输入**：发现候选、历史Theme/Thesis、对同一事实的不同公开版本。

**处理**：
1. S0记录所有重要与低热潜在重大线索；
2. S1追原发与转载：多家转同一媒体稿不能算多个独立证据；
3. S2过**四项硬门**：真实可证、现实影响或重大潜力/典型或突破、可合法取得足够翔实新闻事实、整刊不重复；
4. S3对正面/负面/混合影响逐群体、时间和实现状态记录，不能优先灾难性故事而忽略有方法证据的正面成果；
5. S4核典型性代表性与突破的真实完成状态：样本单例不能证明普遍性、Demo不等于可靠工程部署；
6. S5用试行100分（25影响+15结构/持续+20典型或突破+15证据+15知识+10原创全球/时效），每项有事实说明；**不以分数代替S2**；
7. S6全刊防信息茧房：检查国家、语言、社会/医疗/军事等非金融主题；
8. S7决定EVENT/REPORT/INVESTIGATION/DEVELOPMENT/RESEARCH_FEATURE及要查的原始资料、不同意见、是否是第三方调查；
9. **S8不是在L3之前假装执行完毕**：L2完成S0—S7初选后先送L3。**L3完成原始资料查验和翔实A稿，再带EvidencePacket返回L2，正式执行S8**。若真实影响、代表性、研究方法或数据不实，必须降级、等待或撤稿；只有S8最终`COVER`方可进入L4，重要新反证出现再次触发S8。

**输出**：第一次是`EventCluster`、`StorySelectionInitial(S0—S7)`、`ReportingPlan`和初选状态；**L3回访后的第二次**是`StorySelectionFinal(S8)`以及最终`COVER / RESEARCH_PENDING / SIGNAL / WATCH / DROP`。必须保留前后状态与变更理由，不能覆盖初选。

**错误出口**：有新闻价值但证据不够→RESEARCH_PENDING；热搜但没有实质变化→SIGNAL/DROP；全刊过度同质→补探索队列或调整稿件，不凭空编故事。

## L3｜事实研究与记者式完整报道A

**输入**：ReportingPlan、公开法源/事件、企业财报、政府/央行机构报告、正规医学/科研原始研究、可信记者调查与已有历史。

**处理**：
1. 建立`ClaimRegister`，按FACT/ATTRIBUTED_CLAIM/ANALYSIS_PENDING/UNKNOWN分级，记原始链接、时间、研究口径和法律/版权约束。
2. 独立核**5W1H六要素**：谁做了什么、何时、何地（辖区/样本国家）、已证的原因或“某方称”、动作怎样实施/怎样研究。
3. 新闻必须有准确导语、足够完整的事件经过、历史基线、关键数值单位和分母、不同立场/回应、重要的未知；不能把主文缩成短摘要。
4. `REPORT`特别查真实作者/发布机构、目的/资金利益关系、研究样本/国家/覆盖数据期、方法、结果/模型及适用边界；`INVESTIGATION`说明谁做了实地调查，本刊如仅二次核查公开材料必须如实归属。
5. 核多媒体转载血缘、原数字/法条/财务会计口径/科研复现与不确定性；翻译原意忠实、中文自然专业，不能把受限原文整段照抄/翻译转载。
6. 写一篇独立能看明白的**A journalist draft**。记者段可以解释已有来源证实的背景，但不写模型自己推断的私人动机或未经核实证券走势。

**输出**：`EvidencePacket`、`ClaimSourceMap`、`NewsReportA`、`EvidenceGaps`；**先返回L2执行S8正式复审，再进入L4**。**失败出口**：关键事实错误→BLOCK/改证；受限版权或无足够来源→不能发布完整版A；不以顾问长文补填空。

## L4｜联合顾问—帝师核心：用同一份研究案卷完成B1、B2和C

**输入**：A稿、EvidencePacket、**已经通过L2回访S8的最终选文准入记录**、真实旧Theme/Thesis资料及当前事件变化。

**七问执行顺序**（实际详细步骤和失败出口见[ADVISOR_MASTER_METHOD.md](ADVISOR_MASTER_METHOD.md)）：
- 问事：A核实事实和时间；
- 问题：旧基线与现现实的矛盾；
- 问势：法律权限、资本/物理/组织/历史的真实约束；
- 问人：实际参与者的选择、利益、信息、支付责任和否决权；不能凭古典哲学推隐秘心理；
- 问因：多个合理竞争或协同机制，逐一核条件→中介变量→结果，查最强反方与可分辨证据；
- 问断：有条件的顾问判断，现实成本/风险/不同结果，承认未知；
- 问道：选此次事实最值得教的世界知识，正规定义、真实/明确假设的具体案例与反例、陌生情境迁移。

**B1顾问输出**：直接解释事件的现实后果、决策者/资源/利益、真实核心机制、竞争解释、重要未知和条件，不复述A。

**B2帝师输出**：把本事件中最值得掌握的制度/经济/组织/博弈/工程/人性和历史学问深入浅出讲成**看完能用**的原理：解释过程→正规概念→真实实例/演算→反例/边界→跨域问题。九栏知识清单只是工具箱。

**C推演+开放题输出**：使用B1/B2中**已有的机制**，从不同条件导出至少两条真正不同的路径，逐条写谁行动、传导、正负/二阶结果及失效边界；2—4个非引导思考问题训练换位、改变关键条件、强反证和陌生案例迁移。不可编精确概率/目标价；**C不使用“继续观察”作为主文标题**。

**两条返工回路**：顾问发现关键来源/因果缺证→回L3；帝师发现真实原理与因果不符/跨国类比错误→先退顾问查机制，必要时回L3。每次保留RevisionLog；不能悄悄替换旧观点。

**输出**：`SharedResearchDossier`、`AdvisorB1`、`MasterB2`、`ScenarioC`、`Alternatives/CausalCheck`、`ThesisUpdateProposal`。**错误出口**：无实证的“大师洞见”退稿；没有唯一解释时公平列未决假说并说明未来鉴别数据。

## L5｜独立事实、专业、因果、文章完整性与版权审稿

**输入**：全文A/B1/B2/C及所有来源/后台研究、未来推演假设和旧判断。

**按顺序查**：
1. **选文仍值得写吗**？S8影响、典型、授权复核；
2. **A真是翔实可独立阅读的新闻吗**？六要素、报告方法、必要背景、多方回应及记者身份真实性；
3. **B1/B2没有复述、偏见、无据的单因或错因果吗**？可否提出最强反方；重要概念、文化引用与数据正确？
4. **C确实从B的机制推出至少不同条件的路径和开放问题吗**？没有以预测替事实、没有虚假的72%概率、没有“持续关注”套话；
5. **全部出处与版权、数据时点、外文翻译、旧Theme原件**能逐项追溯吗？
6. **长度与版面完整性**：文章与引用目录无截断、不重复，主文不是A很短B很长而看不懂原事。

**输出**：按问题严重性给`PASS / REVISE / BLOCK`、缺陷定位与复查要求。**BLOCK**须实际修正才可再次审稿，不能让模型自打95分绕过。

## L6｜主编、完整杂志制作、年度复盘与长期保真档案

**周报输入**：所有通过的主文、真实历史判断、原始来源和限制。主编设计封面、目录、卷首文章，按价值动态排文章和九栏目标签；可添加全球信号短讯（不得把短讯当深度主文）。必要时刊登旧判断纠错，资料附录保存可定位出处/更正、数据截点和版权边界。输出`WEEKLY-YYYY-Www`完整Markdown，HTML/PDF按实际未来需要生成，仔细核章目和引用，不因Token太长丢段落。

**年报输入**：全年**真实已出版周报的历史原版**＋同年度**独立检索全球重要新闻/报告/机构官方材料**。执行[ANNUAL_REPORT_SPEC.md](ANNUAL_REPORT_SPEC.md)十二项年度专门工序：年度时间线、漏报、跨域趋势、可比指标与修订、旧预测原句与时间、成功/失误/未决、商业机会和关键学习规律、未来有条件推演。绝不能简单拼52份周报，也不能用年末资料改写年初旧论断。

**长期归档**：Source、Event、Claim、Evidence、Article、Theme、Concept、ThesisVersion、Edition版本、审稿、历史更正、实际成本与交付日志。新证据另建版本，原稿/原判断不得删除或静默修改；用户明确认可的详细方案同步ENDORSEMENT_LEDGER/DECISIONS。

**发布权**：当前仅设计，**无自动排期和对外邮件授权**。将来如用户批准，发送要把“内容生成/发件排队/API已接受/确认送达”分别记状态，不能把服务商接受说成用户收到。
