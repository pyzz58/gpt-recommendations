# 内参系统｜总体蓝图与唯一产品总纲

> 版本：设计基线 V4.4（审核稿）（2026-10-13）｜状态：**详细规划与项目框架已建；研究引擎、刊物和生产调度尚未实现**。
> 正式名称：**内参系统**；英文缩写 GSI / Global Strategic Intelligence。规范路径 `newspaper/strategic-intelligence/`。**现行详细操作以[CANONICAL_SYSTEM_SPEC_V44.md](CANONICAL_SYSTEM_SPEC_V44.md)为第一权威文件**；本文件保留愿景、早期推演与长期目标供参考，具体字段及步骤由专题文件详述。
> **名词说明**：本系统不是现有的每日双语新闻早报。其独立产出是**每周战略深度内参**和**每年综合战略年报**。即使完全断开日报，也必须可以独立研究和出版。

## 0. 第一性原理：到底要建设什么

不是一套新闻爬虫、不是“从日报再过滤”的高级摘要器、不是堆砌名人观点的金融通讯，也不是搭建九个昂贵的AI Agent。

本系统是一套**事实—解释—学习—判断—再验证**的私人长期研究基础设施：
1. 从全球合法公开来源发现真正重要的信息变化，包括不符合用户既有兴趣与主流叙事的变化。
2. 尽可能贴近原始发布与真实业务现场，核实事实、时间、口径和证据来源。
3. 用一流记者的事实转述能力、一流研究员的结构性研究、一流教师/战略顾问的讲解能力揭示世界运行机制。
4. 主动构建竞争性解释和最强反方观点，降低信息茧房与模型迎合。
5. 将原始可归档证据、研究过程、历史判断与知识原理长期保存；在重大新证据出现时回看，并在年报系统审计何处曾经正确或错误。
6. 帮助个人读者形成独立判断、美股投资与小团队创业能力，能够迁移到从未见过的新事件上。

**愿景参照**：顶级财富管理家族/家族办公室的研究严谨度、世界视野、长期资本与制度理解，**不声称拥有其内部会议、特权渠道、内幕消息或不可合法取得的资料**。判断依证据，不依大机构的名气。

## 1. 六项用户长期可检验的变化（产品北极星）

| 编号 | 用户希望产生的变化 | 可检验的行为结果 | 典型失败表现 |
|---|---|---|---|
| O1 | 深度理解世界机制 | 给一条陌生新闻，能解释关键制度、资源、激励、因果链与约束 | 只会复述标题 |
| O2 | 独立判断 | 对争议命题提出强竞争解释、指认可证伪证据与信息缺口 | 被作者、市场、情绪或AI结论牵着走 |
| O3 | 提升美股与创业能力 | 能解释股价预期差、盈利质量/现金流、企业利润池、客户付费与CAC/LTV，并用于新问题 | 背术语却无法分析 |
| O4 | 跨年累积与回溯 | 几年后按关键词调出**当时完整**来源、论点、推断、版本和后来修正 | 只有AI摘要，没有旧原件 |
| O5 | 防止信息茧房 | 能发现不熟悉的地区/观点，公允理解最强反方与证据强弱 | 单一媒体转载形成“多人证明” |
| O6 | 真实、深入、一线、前沿地认识世界 | 优先原始政策、数据、企业披露、现场可信报道、科学研究与新信号；承认未验证部分 | 假装拥有独家或用前沿口号替代实际证据 |

“已发送文章”不能证明“用户已掌握”。学习能力需以抽样复述、迁移案例、反例判断和实际反馈验证，用户不需要每次考试。

## 2. 九大栏目与资源优先级

这九个栏目均存在，但**不是九条固定字数配额、九个独立模型、九个数据库或每期必须硬凑九篇**。下表是资源规划和重要性筛选的初始长期倾向，重大事件可改变。

| 栏目 | 资源倾向 | 研究范畴与最重要的判断 |
|---|---:|---|
| 美股与投资 | 25% | 公司盈利质量、预期差、估值、股债、ETF/期权、流动性和风险 |
| 全球创业与商业机会 | 25% | 小本金、小团队、SaaS/AI应用、分发获客、PMF、CAC/LTV与进入壁垒 |
| AI与前沿科技 | 12% | AI模型、算力、芯片、机器人、医疗科技、能源和太空，技术可行性与商业化 |
| 全球宏观与金融 | 10% | 美联储/央行、利率、债务、汇率、通胀、劳动力、全球流动性 |
| 中国与美国 | 10% | 中美政策、政治、经济、突发事件、制度与产业变化 |
| 全球政治与地缘战略 | 6% | 外交、战争与军事安全、贸易、国家能力、谈判与博弈 |
| 全球企业与产业竞争 | 5% | 行业结构、企业管理、并购、利润池、供应链、竞争优势 |
| 社会与消费趋势 | 4% | 人口、健康/医疗、消费者、就业、社会心理、文化与教育 |
| 战略研究室 | 3% | 跨主题机制、长周期命题、历史判断回测与战略反省 |

**美股+创业50%**：投放的研究注意力/价值导向，不是对全球候选新闻的过滤阈值。不能因此漏掉战争、政策、公共卫生、重大科技信号。金融和创业产品优先针对**普通投资者、独立创业者与小团队的可理解和可执行价值**，不将投资银行大宗并购或家族办公室特权交易作为主线。

## 3. 来源宇宙：媒体之外的权威研究

最低设计覆盖：全球主流和在地多语种新闻媒体；中国媒体（新华社、人民日报海外版等）与国际媒体（BBC、路透等）；投行与资管（摩根大通、贝莱德、先锋、道富、高盛、花旗、美银、摩根士丹利等）的**公开**研究；伯克希尔股东信；四大（PwC、德勤、安永、毕马威）；咨询公司（麦肯锡、BCG、贝恩）；创业机构与真实产品市场；监管机构、证券交易所、政府、国际组织、权威军事/安全智库、医学监管与临床试验、论文与工程实测。

**最新执行约束**：源数据库 `SOURCE_REGISTRY.json` 当前**124个活跃候选（A116+B8）**；已按用户决定放弃6个访问障碍来源，保留历史于 `SOURCE_ABANDONED_2026-10-13.json`。过去共进行了四轮专项联网源测试和**一次随机4源抽样（全部HTTP200，但有1个仅API文档）**。无需为余下约120源做本阶段全量网络测试，也不保证124源全部能稳定自动获取。来源目录下一阶段再扩充或审计；**当前阶段停止来源测试，专注系统设计和样刊质量**。

低成本原则：广覆盖元数据/Feed优先，少量高价值议题才投入检索、PDF分析与深推理；优先官方免费RSS/API、公开报告和必要的合规抓取。站点免费可见≠可自动抓取、可发给LLM或可全文再发布。所有假定的工具许可必须按具体用途审核。

## 4. V4.4唯一现行六层架构（概念分工，不是六位独立Agent）

```text
L1 全球独立公开信息发现（免费合法来源，主流＋跨地区非热点）
    ↓
L2 事件血缘聚类＋选文委员会S0—S8
    （现实正面/负面/混合影响、典型性/重大突破、原始资料硬门槛）
    ↓
L3 证据查验＋顶级记者式事实报道A
    （5W1H、真实历史背景/机构报告方法与局限、事实归属）
    ↓
L4 一套联合顾问—帝师研究工作台
    （七问三检验、B1顾问/B2帝师/C情景与开放问题，
     因果/教学有漏洞回退L3或L4）
    ↓
L5 独立事实/专业/逻辑/版权审稿（PASS/REVISE/BLOCK）
    ↓
L6 主编整本周报/年报＋长期可回查事实、机制与判断档案
    ↑ 新事实/历史核错/读者自愿反馈循环回L2—L4
```

**编辑版单篇主文**：A完整独立可读的**记者式新闻/机构原始报告报道** → B1顾问现实研判 → B2帝师机制与知识教学 → C**事件推演及开放性问题**；原先“C继续观察”被用户否决，未来可证伪变量留内部Thesis资料。具体[杂志结构](MAGAZINE_ARCHITECTURE.md)、[选文与记者标准](EDITORIAL_SELECTION_AND_REPORTING.md)、[情景与开放题](SCENARIOS_AND_OPEN_QUESTIONS.md)。

**研究思路**：古代帝师历史材料与现代智囊/咨询方法综合出的[七问三检验](ADVISOR_MASTER_METHOD.md)是主法；旧12步世界发现库只是扩展专业工具。事实可由多机制协同或竞争解释，不保证存在唯一终极原因。

## 6. 两个出版产品

### 6.1 每周《全球战略情报周刊》
- 核心任务：本周哪些世界变化**值得投入研究、真正理解并长期记住**？不是把七份日报拼接。
- 编辑表现：高信息密度的忠实报道 + 由事实推动的一流顾问详细讲解，包含基础知识、机制、案例、反例、竞争性解释、失效条件、未来观察点。
- 栏目可以跨界；适当将中国和美国的政策、政治、经济及突发事件集中成专题板块。
- 每篇深度L1/L2/L3动态；不能强制全文机械七小节、机械规定统一长度、出现无来源“内幕解读”。

### 6.2 每年《全球战略综合年报》
- 核心任务：不只是“发生了什么”，还要回答“**我对世界的哪些判断改变了？哪些没有改变？过去错在哪里？未来从何种证据继续验证？**”
- 必有跨领域原创综合分析、阶段性美股/创业研究、长期命题回顾、预测/失误审计及主编式连续文章《首席顾问致决策者》。
- 年报必须由全年周报与全年独立新闻及机构研究源共同构成新综合，绝不能把周报简单合订；需要形成新的比较、实证结论、约束条件、机会风险及修正。

**发布时间未最终批准**：周报与年报的实际日期均尚未批准。日报的北京时间07:00已有约定，但属于另一个系统，不授权改动。邮件投递新报刊收件地址和时间同样尚待单独确认。

## 7. 首席认知与战略顾问＝教学能力而不是人格演戏

四类互补方法：**第一性原理**找基础约束；**费曼教学**用简洁类比/算例讲明白而不牺牲准确；**苏格拉底式质疑**找替代解释；**历史案例和反例**校验适用边界。对政治博弈可使用博弈论、制度激励、谈判，但不得武断把争论说成“都在演戏”。对创业要讲业务单位经济性和普通人进入约束；对股市要讲“盈利vs预期vs折现率vs资金”。

顾问的最终目标是**提高读者独立思考的能力**，不是提供必须服从的预测和股票买卖指令。详细规范见 [ADVISOR_PEDAGOGY.md](ADVISOR_PEDAGOGY.md) 和 [COGNITIVE_ADVISOR_SKILL.md](COGNITIVE_ADVISOR_SKILL.md)。

## 8. 反信息茧房不是政治立场均匀分配

- 发现端不依赖日报、美国报道或金融热点；核心队列之外保留探索队列。
- 对重大争议建立最强反方（steelman）和竞争性解释；识别转载链不独立、数据口径不同与机构利益。
- 用独立原始事实裁判分歧，**不得制造虚假对等**；证据强弱不对称时必须据实表示。
- 追踪无意忽视的地区、语言、产业、反例和“当初最自信、后来最错误”的判断；年报集中审计，周报按新证据增量修正。

## 9. 资料与产品的关系

- 资料链：注册来源 → 发现候选 → 原始/合法存档片段 → claim证据 → 事件/主体 → 长期主题 → 历史判断版本 → 刊物 → 知识卡。
- 历史来源和当时个人讨论不许被AI摘要替代；归档须可精确检索，受限全文仅存链接/授权短摘/许可证可保存的部分。
- 关注 **event_time / published_at / collected_at / as_of** 四种时间，避免拿未来数据支持过去判断。
- 个别知识卡片记录“已讲授”和“已实际掌握”两种不同状态，不强制给用户做题。

## 10. 首版技术边界与预算边界

| 方面 | 初期选择 | 不做什么 |
|---|---|---|
| 架构 | 一个Python可重试管道、结构化数据校验、Markdown版本记录 | 九个分离Agent、庞大微服务 |
| 数据 | Markdown/JSON最小归档；需求成熟时PostgreSQL | 未评测即引入复杂GraphRAG |
| 发现 | 合法公开RSS/API/机构网站；索引作线索 | 付费墙突破、无限制抓取 |
| LLM | 按L1/L2/L3研究预算、缓存、重试、硬上限和人工门禁 | 为凑字数无限消耗Token |
| 出版 | Markdown主稿→HTML/邮件/PDF；可审计状态 | 未批准就定时发送或宣称送达 |
| 成本 | 按刊次记录真实Token/数据/工具费用再定上限 | 把早报既有成本预算自动套用于内参 |
| 研发 | 先六份真案例证明深度质量，再建周报与年报 | 先造大型软件平台再找用途 |

GPT Researcher、OpenBB、pgvector、Langfuse、RSSHub、Trafilatura等仅候选，是否采用以可复测的质量/成本收益决定；优先用成熟工具而不是复制其全部功能。

## 13. V3.1正式补充：五种长期研究机构能力不是华丽类比

过去经用户明确认可的愿景是**新闻机构的敏锐度＋情报机构的连续性＋投资机构的量化研究＋战略咨询的机制/商业分析＋家族办公室的长周期视野**。它们必须落在不同的可查证输出上：事件原件/时间、跨期人物与机构关系、财报与宏观数据、机制与强竞争解释、3/5/10年研究命题和纠错。完整交接契约见[INTELLIGENCE_OPERATING_MODEL.md](INTELLIGENCE_OPERATING_MODEL.md)。长期研究还包括**战略判断追踪器、全球商业机会雷达、世界结构变化与反常信号雷达**。

最重要的教学要求：**“借真实新闻，把世界运行的底层规律教给读者”**，不满足于提到第一性原理/费曼法。实际每篇先冻结事实，再识别制度、资源、谁有决定与否决权、经济激励和成本，构建有事实与推断分层的因果链；用严格概念、通俗例子、案例与反例讲授；最后拿陌生问题验证能否独立应用。政治要讲议会/行政/司法/财政、党纪/选举、否决点；创业要教客户/买方/价值兑现/CAC/LTV/毛利/采购/法规；美股与科技同样按专业知识路径。可逐步执行的十一道工序见[DEEP_LEARNING_ENGINE.md](DEEP_LEARNING_ENGINE.md)，完整政治、医疗AI创业、股市和科技假设教学范例见[CASEBOOK_POLITICS_AND_STARTUP.md](CASEBOOK_POLITICS_AND_STARTUP.md)。**用户“帝师”比喻指教学深度而非神秘身份或高人语气**。

深度学习的终点不是模型生成出一篇漂亮报告，而是读者在其他事件中可以自问：谁有权、谁付钱、哪些约束不能改变、哪里是假设、最强反方为何成立、新证据会改变什么。不能验证读者掌握时只记“已讲授”，不假称“已学会”。系统架构仍保持统一研究引擎、逻辑角色分工和独立否决式审查，不先强装十几个独立Agent。

## 15. V4.1深度教学目标的根本修正：栏目是入口，世界规律是目标

**用户新增的根本要求**：把真实世界现象作为起点，顾问查现实的真实约束、决定者与竞争解释，导师借此教授相应的制度、经济、技术、社会、人类行为、历史或中国传统文化等知识，教会读者**面对下一件表象完全不同但机制可能相似的事件也会独立判断**。不能被本栏目旧“必教知识清单”限制。

**新增逻辑中枢**：[OPEN_ENDED_WORLD_MODEL.md](OPEN_ENDED_WORLD_MODEL.md)M01—M12，先从现实证据、反常、资源/权力/信息与因果候选识别真正有解释力的机制，之后再选择教学学科、费曼示例、反例和迁移方法。如讲解发现机制不符事实，导师需退回顾问/事实研究重新核查；不能“研究一次、撰稿一次、审稿一次”即视为认知教学合格。

**完整架构审计**：[ARCHITECTURE_LOGIC_AUDIT_V41.md](ARCHITECTURE_LOGIC_AUDIT_V41.md)，明确七层、15工序、断点、当前实现状态与下一阶段验收；九栏目与权重仅管研究资源分配，不规定读者认知必须学到哪个固定理论。本次仍只完成设计规范，并未实测研究质量或部署运行系统。

## 16. V4.2定型：一个顾问—帝师核心，一本新闻在前、评论在后的杂志

历史研究结合张居正《帝鉴图说》的正反史鉴、司马光《资治通鉴》的时间与史论分层、吴兢《贞观政要》中的君臣政务议论，与RAND独立质量、Heuer竞争解释、麦肯锡问题拆解、Rumelt诊断/行动及英国财政部的因果评价。并**不声称这些主体原本使用相同规则**。本项目综合建立了[ADVISOR_MASTER_METHOD.md](ADVISOR_MASTER_METHOD.md)的七问三检验和双向返工：由事实决定该教哪种跨学科规律，多个机制可以共存且须诚实说明未知。

原“机制发现”和“顾问＋帝师”在产品架构中合并为**一个联合认知研究工作台**，只在工序内有互相检查，不作为两个需要额外Agent的重复部门。整套六层逻辑与整本刊物、每篇A完整新闻/机构报告+B1顾问研判+B2帝师释理+C事件推演和开放性问题的正式阅读顺序，均以[MAGAZINE_ARCHITECTURE.md](MAGAZINE_ARCHITECTURE.md)为准。
