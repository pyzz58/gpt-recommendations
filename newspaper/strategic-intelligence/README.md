## 已确定的产品与施工主线

从本周真实有意义的全球事件和高质量原作出发，优先发现机构研报、政治报告、政策、财报与原始研究，同时覆盖可信的原创新闻和调查。L1 建合规轻量候选索引，L2 按 S0—S7 严选，L3 精选原作、查证据与逐件许可，A 按权限呈现原文、英文中文译文或原站直达加中文导读，再由 L2 S8 研究后复选；L4 的顾问 B1 如专业幕僚作独立研判，帝师 B2 用通俗语言先讲明白再介绍术语，C 作有条件推演；L5 独立审稿，L6 出刊与归档。六层是职责，不是六套 Agent。完整收录与翻译须各有具体使用权，不因免费浏览或个人阅读自动获得。

系统**只服务用户本人**，交付供其阅读、自行思考的杂志式文档；不开发答题、讨论或读者学习追踪。每篇重要主文要让读者比阅读前多理解一项真实世界的运行机制及其边界。六项长期目标包括广泛认识世界、独立判断、美股与创业能力、跨年复盘、摆脱信息茧房、基于公开原件和可信原创报道的深度前沿认知。九领域进入发现和选材时有同等初始机会，按现实价值动态分配篇幅。正式产品只有独立于日报的周报和以实际全年周报为主干、独立回查全年资料的年报。旧判断和知识卡保存原话、证据、版本；不推定用户已经掌握。

**唯一四阶段施工顺序**见[V5 §19.2](CANONICAL_SYSTEM_SPEC_V5.md)：①编辑体系先交真实完整的高质量周报样刊；②研究体系证明跨周资料与判断可复盘、完成六份真实跨域案例；③专业能力用来源可查的深专题验证专业资料与多 Agent 审稿增益；④生产体系验证连续离线出刊、年报回放、故障与恢复。正式邮件、部署、收费、订阅或改动既有日报需要相应明确授权。

## 当前实施状态

设计说明书已经归档，真实周报样刊、六例、L1—L6 软件回放、长期历史查询、连续离线刊物、年度回放与来源许可都尚未验收；用户掌握程度不在系统内测量。`SOURCE_REGISTRY.json` 中的来源只是候选，须逐源核可用性、模型处理、留存、全文复制、翻译及私刊交付许可。接手者只需按[V5 §20—21](CANONICAL_SYSTEM_SPEC_V5.md)维护这份唯一说明书并完成交接演练；有实质新决定时直接更新说明书所有受影响的章节。
