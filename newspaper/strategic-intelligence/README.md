## 已确认的产品主线

从本周真实变化与优秀原作发现值得解释的问题。一份报告可支持多个主题，多份新闻、报告、研究、政策可共同支持一篇专题。深度文章以有依据、有边界的结论开篇，随后通过相关事实和分论点展开，再深入研判、教学与推演；研究过程先取证再结论，禁止为了预设观点挑正例。

长报告按主题选重点、保留必要语境，英文入选部分提供准确中文辅助，末尾附原文链接与页段；不强制全文复制、全译或全部放附件。原作精选、进展更正与深度主题采用不同处理强度。顾问重核验、澄清、比较、连接与判断，不强求新观点；帝师教机制及辨别竞争解释的方法。具体规范见V5 §5—13。

六层仍为L1发现、L2筛选、L3取证/重点制作、L4顾问帝师、L5独立审稿、L6出版归档。S8前完成选题所需阅读核查，入选后制作重点译文。§8.2—8.3规定逐层研究与理论依据核验；政治学、博弈论、历史与思想著作是按题调用的方法资源，须核具体出处、适用条件和本题证据。§10.6知识地图只记录刊物内容，不记录读者表现。

只服务本人，交付私人周报与年报；九领域同等初始机会，世界认知居中心，日报完全独立。年报以真实周刊为主干并独立补漏、复核旧判断；保留原话、当时依据及版本，不倒填后见材料。使命、质量与可校准参数在同一V5内分层。
