## 已确定的产品与施工主线

从本周真实有意义的全球事件和报告中，L1 建合规轻量候选索引，L2 按 S0—S7 严选，L3 核原件写独立可读的记者 A，再由 L2 S8 研究后复选；L4 共享案卷中的顾问 B1 分析现实机制、帝师 B2 教授可迁移知识、C 有条件推演；L5 独立审稿，L6 完整出刊与归档。六层是职责，不是六套 Agent。

系统**只服务用户本人**，交付供其阅读、自行思考的杂志式文档；不开发答题、讨论或读者学习追踪。每篇重要主文要让读者比阅读前多理解一项真实世界的运行机制及其边界。六项长期目标包括广泛认识世界、独立判断、美股与创业能力、跨年复盘、摆脱信息茧房、基于公开原件和可信原创报道的深度前沿认知。九领域进入发现和选材时有同等初始机会，按现实价值动态分配篇幅。正式产品只有独立于日报的周报和以实际全年周报为主干、独立回查全年资料的年报。旧判断和知识卡保存原话、证据、版本；不推定用户已经掌握。

**唯一四阶段施工顺序**见[V5 §19.2](CANONICAL_SYSTEM_SPEC_V5.md)：①编辑体系先交真实完整的高质量周报样刊；②研究体系证明跨周资料与判断可复盘、完成六份真实跨域案例；③专业能力用来源可查的深专题验证专业资料与多 Agent 审稿增益；④生产体系验证连续离线出刊、年报回放、故障与恢复。正式邮件、部署、收费、订阅或改动既有日报需要相应明确授权。
