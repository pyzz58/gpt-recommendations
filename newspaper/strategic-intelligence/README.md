# 内参系统｜V5 唯一入口

> 2026-10-14：用户已确认 V5 产品与架构基线。**这是一套设计规范，并非已开发、已验收或已上线的生产系统。**正式产品为独立于既有日报的周报与年报。

**先完整阅读 [《内参系统 V5｜唯一现行完整架构基线》](CANONICAL_SYSTEM_SPEC_V5.md)。**未来换电脑、对话框或模型时，从本入口开始，以 V5 的具体流程、硬门、失败分支、验收和变更程序执行。用户之后的明确新决定按 V5 §20 完整归档并修订基线后生效；不能选择一份旧文档自行拼成另一套现行规则。

## 已确定的主线

以本周真实、有意义的全球新闻、事件和报告为材料，独立全球发现 → L1 轻量候选索引 → L2 S0—S7 初选 → L3 取证并写完整记者式事实报道 A → 返回 L2 完成 S8 复选 → L4 一套联合顾问 B1、帝师 B2、事件条件推演与开放题 C → L5 独立审稿 → L6 周刊出版和历史归档。教会读者用事实、专业知识、竞争解释和反例形成对世界的独立认识；六层是职责而非六个 Agent。具体输入、输出、准入、返工和阻断只以 V5 §4—19 为准。

年报以全年**实际周报的重新筛选与汇编为主干**，独立回查全年原始新闻、报告及数据以补漏纠错，再作年度顾问/帝师新综合及未来一年有条件推演；不可拼接 52 期。连续情报只服务于周报和年报所需历史资料，不作为独立产品或必建基础设施。九个领域有同等初始选题机会，创业和美股没有旧版 25% 的特殊资源配额，广泛认识世界是中心。
