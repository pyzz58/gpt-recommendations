## 项目简介

计算机辅助设计与制图软件，是 AutoCAD 风格的 clean-room 重实现，纯 Rust 编写。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

CAD 属于专业垂直领域，开源可用的替代品极少，这个项目的定位相当少见。当前 1,786 star。

## 我能怎么用

二维制图与工程设计草图的绘制、查看与导出。
