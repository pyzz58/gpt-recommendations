## 项目简介

演示文稿与幻灯片软件，是 Microsoft PowerPoint 的 clean-room 重实现，纯 Rust 编写。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

演示文稿是工作高频产出，而开源替代品长期稀缺，这个方向值得跟踪。当前 1,366 star。

## 我能怎么用

制作与编辑幻灯片；用 CLI 做模板化批量生成。
