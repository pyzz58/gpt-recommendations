## 项目简介

页面版式与出版软件，是 Adobe InDesign 的 clean-room 重实现，纯 Rust 编写。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

排版是自动化链路上最容易被忽略的一环，它能让「内容 → 成稿」全流程摆脱 Adobe 订阅。当前 2,516 star。

## 我能怎么用

制作海报、画册与长文档排版并导出；用 CLI 做模板化批量生成。
