## 项目简介

视频剪辑软件，是 Adobe Premiere Pro 的 clean-room 重实现，纯 Rust 编写，覆盖剪辑、调色与声音处理。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

视频剪辑是 Adobe 全家桶里最吃性能的一环，纯 Rust 方案如果跑得动，对短视频工作流的价值很大。当前 8,495 star。

## 我能怎么用

本地做剪辑与调色；用 CLI 接入自动化流水线，做转码、拼接与批量处理。
