## 项目简介

电子表格与数据计算软件，是 Microsoft Excel 的 clean-room 重实现，纯 Rust 编写。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

安装包只有 19.4 MB，是家族里最轻的一个，适合用最低成本快速验证这类 Rust 应用的实际体验。当前 1,761 star。

## 我能怎么用

做数据表格、公式计算与整理；用 CLI 做批量数据格式转换。
