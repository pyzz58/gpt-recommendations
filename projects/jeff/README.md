## 项目简介

小型、本地运行、速度很快的分类和决策模型。

## 为什么推荐

适合做信息分类、Agent 路由、信号评级和工具选择。

## 我能怎么用

在本地做批量分类、打标与评级，替代昂贵的 LLM 调用完成初筛。

## 后续研究

- 与 CLM 对比评测后选型。
- 评估在信息分类 / 信号评级流程中的接入方式。
