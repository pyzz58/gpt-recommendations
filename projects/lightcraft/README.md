## 项目简介

相片库管理与 RAW 显影软件，是 Adobe Lightroom 的 clean-room 重实现，纯 Rust 编写。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

RAW 显影涉及解码与色彩管理，是检验这套 Rust 技术栈深度的关键项目；它也是家族里安装包最大的一个（94.6 MB）。当前 8,898 star，在非 Photoshop 的几款里热度最高。

## 我能怎么用

整理相片库、批量调色与导出；处理相机 RAW 文件。
