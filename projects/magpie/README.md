# magpie

## 原项目

- 项目名称：magpie
- GitHub 原始地址：<https://github.com/yetone/magpie>
- 作者：yetone

## 项目简介

统一管理 Codex、Claude Code、Gemini CLI、OpenCode 等 AI Agent 使用的模型和 Provider。

## 为什么推荐

我的 Codex 使用 DeepSeek，并且以前遇到过 model 和 model_provider 配置不一致的问题，这个项目正好可以解决这类配置统一问题。

## 我能怎么用

集中维护各个 CLI Agent 的模型与 Provider 配置，避免在每个工具里分别手改配置文件造成不一致。

## 后续研究

- 验证与 Codex + DeepSeek 配置的兼容性。
