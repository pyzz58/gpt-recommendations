## 项目简介

PDF 阅读、整理与保护工具，是 Adobe Acrobat 的 clean-room 重实现，纯 Rust 编写。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

替代 Acrobat 的需求面最广、最日常（合并、拆分、加密、签名），也是全家桶里最容易直接替代的一类工具。当前 7,813 star。

## 我能怎么用

日常 PDF 阅读与整理；用 CLI 做批量合并、拆分、加水印与加密。
