## 项目简介

音频录制与编辑软件，是 Avid Pro Tools 的 clean-room 重实现，纯 Rust 编写。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

音频是和视频配套的必需环节，它补齐了「视频 + 音频」的完整链路。当前 1,272 star，安装包仅 19.3 MB。

## 我能怎么用

录音、剪辑与音频修整；配合视频项目做配音与配乐处理。
