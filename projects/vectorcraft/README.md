## 项目简介

矢量插画与图形设计软件，是 Adobe Illustrator 的 clean-room 重实现，纯 Rust 编写。跨平台原生运行，另有浏览器版本与 CLI 工具。

## 为什么推荐

矢量工具是 Adobe 订阅体系里最难替代的部分之一，直接用 Rust 自研渲染管线的路线值得研究。当前 6,058 star。

## 我能怎么用

制作 Logo、图标与插画等矢量图；用 CLI 做批量转换与导出。

## 后续研究

- 检查导出格式支持（SVG、PDF、EPS 等）与路径编辑能力。
- 评估与现有矢量工作流的衔接成本。
