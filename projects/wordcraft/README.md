## 项目简介

文字处理与文档编辑软件，是 Microsoft Word 的 clean-room 重实现，纯 Rust 编写。跨平台原生，另有浏览器版本与 CLI。

## 为什么推荐

它证明这套 Rust 路线不只针对 Adobe，通用办公软件同样可以重写，是观察「桌面软件整体开源化」的好样本。当前 3,054 star。

## 我能怎么用

日常文档撰写与编辑；用 CLI 做文档批量转换与处理。
