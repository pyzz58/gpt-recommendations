# 共和国 / Republic — 极简 AI 元首文字游戏

**状态：可运行的静态 HTML 原型 v0.1 · 完全虚构 · 仅作制度体验**

> **与研究报告的关系：** 本游戏根据《AI 元治理国家》制度研究报告中的“人类专业机构提出方案、AI 元首审核、独立审计纠偏”机制设计。欢迎所有人体验、提出反例、提交新剧情或改进交互。游戏结果仅是预设叙事，不代表现实政策预测。

## 怎么玩

**无需下载安装的网页入口（需先启用 GitHub Pages）：** https://pyzz58.github.io/gpt-recommendations/republic-game/

GitHub 当前尚未确认该网页已启用。仓库管理员需先前往 **Settings → Pages → Build and deployment → Source → GitHub Actions**，再在 **Actions** 中运行 `Republic – publish game and research landing` 工作流。网页部署成功之前，请使用以下本地方法体验。



1. 在 GitHub 打开 **[index.html](index.html)**，点击 **Raw**，将页面保存为 `共和国.html`（确保文件扩展名为 `.html`）。
2. 双击本地 HTML 文件，用任意现代浏览器打开；不需要安装软件、登录、API 密钥或网络连接。
3. 你扮演一个假想共和国的 **AI 元首**：收到专业部门奏报，可以先点击 **调取独立审计材料**，再从三项裁决中选择一项。
4. 查看下属后续反馈和四项游戏指标（民生、财政、廉洁、制度信任），继续下一轮；五轮后生成任期摘要，可以重新开始。

**注意：** GitHub 的普通代码预览页不会执行 HTML 游戏。应将 Raw 文件下载到电脑后打开；尚未设置 GitHub Pages 在线托管地址。

## 极简规则

- 五轮议事：关键高级岗位、公交通勤预算、数字公共服务、采购审计、机构重组。
- 每轮三种决策，可选查看第三方审计材料（不查看也可以直接决定，但游戏会扣除少量制度信任）。
- 选择会影响四项虚构指标，并展示专业部门的结果反馈。
- 无后端、无存档、无用户追踪、不联网、无真实政治数据。
- 数值规则均为**原创叙事机制**，不代表现实经济、政策或人才评价的准确模型。
- 所有案例为原创、虚构、跨法域中性情景，不使用私人讨论中的具体历史、地域或人物例子。

## 设计边界

本原型主要让玩家体验 **专业部门提供方案 → 独立审计可调取 → AI 元首只处理关键决策 → 回传执行反馈**。它并不是通用政治模拟器，不模拟真实民主授权、法律完整体系或国家经济，也不证明模型可以安全行使国家主权。
