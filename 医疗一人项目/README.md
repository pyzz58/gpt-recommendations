# 医疗一人项目

**以一名发起人、具有明确分工的AI团队，以及现实中的科学家和外部研发机构，探索可逐步验证的药物研发组织模式。**

当前阶段：**理论整理与需求讨论**。本目录首先保存整个项目的核心理论源头；目前不以软件实现、药物开发或商业模式已经成熟为前提。

保存位置：GitHub 仓库 `pyzz58/gpt-recommendations` 下的 `医疗一人项目/`。沿用现有仓库，不另建独立仓库。现有仓库为公开仓库，本目录仅记录项目相关理论与公开来源。

初始方向：将已有药物开发用于宠物。前期总预算设想为人民币1—2万元，按证据逐步决定后续投入。

## 当前明确的设计方向

- 完整考虑科学判断、研发运营和外部研发执行统筹，并设置独立审核。
- 不将组织架构固定压缩为三个Agent。低成本通过单项目、小任务范围、按需调用和分阶段投入实现。
- 每个专业Agent应有明确职责、输入、输出、资料范围、权限、汇报对象、交接条件和异常处理规则。
- AI可以承担日常研究分析和组织工作；其实际科学判断能力须通过具体任务和外部证据检验。
- 真实实验由具备条件的现实机构执行。AI负责形成需求、组织资料、跟踪合作和分析已收到的结果。
- 首先把理论讲清楚；具体技术选择、岗位数量和软件实现尚待讨论。
