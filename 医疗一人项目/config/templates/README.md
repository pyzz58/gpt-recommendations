# 导出模板目录

`catalog.yaml`是W14固定版本内置模板目录。每个受支持格式必须恰有一个默认模板；
模板标识、版本、格式和必需章节在启动时由Pydantic校验。

当前模板：

- `research-report.docx` v1：可编辑Word研究报告；
- `research-brief.pptx` v1：16:9可编辑摘要演示；
- `analysis-workbook.xlsx` v1：原始分析值、结果、公式重算与来源核对；
- `research-report.pdf` v1：带页码的只读报告。

修改模板必须同步版本、导出校验、测试、技术主文件和追踪基线。不得在目录中放入
来源或再分发权限不明的第三方模板。模板通过校验或文件可打开，均不证明内容、
版式质量或科学结论有效。
