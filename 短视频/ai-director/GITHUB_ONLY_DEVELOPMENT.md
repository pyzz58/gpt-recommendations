# GitHub 专属开发阶段与 Mac 轻量化部署准则

## 当前执行状态（用户于 2026-10-11 明确决定）

**当前只开发 GitHub 上的源码；暂不下载、同步、安装或运行到用户 Mac。** 后续任何任务默认遵循此状态，直到用户明确说“可以在电脑上运行/部署”。

- 远程源码：`pyzz58/gpt-recommendations/短视频/ai-director/`，由 GitHub 提交记录保存版本。
- Mac 上原有历史副本（原下载目录）留在原位：**不覆盖、不删除、不迁移、不执行，也不要求用户清理**。历史本地 jobs 为私有资料，不能上传到公开 GitHub。
- 可以：读取第三方仓库的公开源码/文档、比较技术与许可证、在远程仓库修订源码和合成测试、审查 API 设计、运行允许的无付费隔离环境单元测试。必须标注测试实际运行环境，不把云端源码提交当成在 Mac 测试成功。
- 不可以：提示用户执行 `git pull`、`pip install`、`brew`、`npm`、`git clone`、下载 ZIP/权重，或者让本地 Codex 执行修稿。禁止自动开机启动、守护进程、登录项、系统级配置、全局环境或其他本机安装操作。
- 不能调用付费 DeepSeek/视频服务、不能提高或复用历史测试费用授权、不能触发可能付费的 CI 作业、不能发布或上传私人作品及密钥。

## 离线多 Agent 执行层检查（2026-10-11）

[AGENT_EXECUTION_LAYER.md](AGENT_EXECUTION_LAYER.md) 和 `agent_executor.py` 已实现有限步的模拟岗位任务流水线，仅能消费明确预写的 JSON fixtures。执行器通过类型检查拒绝一切非 FixtureOnlyAdapter、不会启动进程/网络/模型/后台监控，也不会改动用户 Mac。私有源文案可在未来批准的私有执行环境仅以内存方式用于角色输入验证，**不得上传公开 GitHub 或运行在未获许可的云端模型**。GitHub CI 离线测试成功记录见文档；没有做过私有数据或真实模型测试。

## 为避免电脑变慢而固定的技术要求

1. **无后台驻留**：将来交付的软件默认不设开机自启、不装常驻 agent/daemon、不扫描整个硬盘、不监控键盘、不自动打开浏览器或多个服务器。需要时由用户手动启动，关闭后应停止它启动的进程。
2. **尽量少依赖**：优先标准库；成熟开源项目以模块化、可选依赖或独立适配器方式引入，避免整仓复制、大量安装及系统级依赖。对新增依赖记录用途、许可、体积、运行时 CPU/内存目标及卸载办法。
3. **集中单目录**：等部署获批后只准备一个明确的正式版本和一个数据目录，不制造带时间戳的多个试运行克隆。源码、私有 `jobs/`、缓存、日志及临时输出分开管理。
4. **缓存可控**：预览、帧、音视频缓存有明确目录、磁盘用量查询和手动清理选项；提供只列清单、不直接删除的 dry-run 模式；删除数据必须得到用户明确指令。不得清理其他软件缓存。
5. **隔离环境和可回滚**：如果必须安装依赖，使用项目级虚拟环境而非系统 Python；锁定版本、提供卸载步骤；更新失败允许切换上一版，不编辑全局 Codex/DeepSeek 设置。
6. **分阶段验收**：远程逻辑/单元测试 → 手工复核依赖/安全 → 用户批准本机部署 → 验证启动、退出、CPU/内存/磁盘开销 → 视频小样测试（若明确批准供应商/成本）。**未经本机资源测量不能声称“不会卡”。**
7. **版本状态透明**：区分 GitHub 已提交、隔离环境已通过、用户 Mac 已部署、真实模型已验证；未发生的环节一律不标通过。

## 现有 Mac 打字偶尔卡顿的说明

现有少量 .py/.md/.json 文本源码通常只占磁盘，不会因为“文件多”而持续占 CPU。卡顿更常见于活跃进程、内存压力、浏览器页面、输入法、同步服务或磁盘空间不足；**目前没有用户电脑的性能数据，不能判定原因或归责于本项目**。

未经用户专门要求，不远程清理、不指导执行删除命令、不安装监控工具。若用户日后要求诊断，可先用 macOS 自带「活动监视器」与「系统设置→通用→登录项与扩展」，在不改变设置的前提下观察负载，基于实际证据给出可逆方案。

## 准备本机部署时的交付闸门

只有用户明确批准，才制作一次性部署方案。先核对 GitHub 版本、许可证、依赖和隐私/缓存目录；检查当前 Mac 是否已有旧项目且存在私人资料；制定不覆盖、不丢失、不重复安装的迁移方案。优先只下载最终审核版源代码，在项目隔离环境运行。未经确认不删除历史临时目录或用户生成作品。

此约定的优先级高于此前 README 中的 Mac 使用示例；旧示例只供将来运行参考。
