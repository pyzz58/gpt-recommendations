# AI 短视频导演中转站

**输入一篇文案，交付一整套可以指导 AI 视频与后期制作的导演方案。** 包括故事取舍、逐镜动作、表演、摄影、场景、台词/旁白、声音、动画、剪辑及候选制作提示词。

## 先看实际交付

[《门后的信》：60 秒、8 镜头完整导演交付书](examples/door-letter-review/director_workbook.md)

这是一份当前会话助手编写、使用现有程序离线校验的审阅候选。原文来自仓库既有公开虚构故事。没有新增 DeepSeek 调用，没有运行十岗位真实模型流水线，没有生成图片/视频，尚未获得用户审片批准。本片采用无对白悬念叙事，声音设计仍完整保留。

## 已有能力与未验证部分

现有编译器可以整理结构化镜头、专业方向、候选 Wan/Seedance 提示词、后期制作单和跨镜剪辑时间线；专业团队接口与安全检查也已存在。

**还不能据此认定“任意文案都能自动产生优秀导演方案”。** 完整十岗位真实创作质量、对白/口型、多人物调度和实际视频效果仍需验证。私人持久托管、身份与供应商账单验收仍未完成；这些继续阻断真实付费生产，不阻断公开虚构文案的文字方案开发。

截至本轮开始的工程基线：累计 25 项，12 项有回归修复证据、4 项已确认未解决、6 项待调查、3 项需真实媒体验证。最近已验证代码基线为 571 项测试通过、受测模块覆盖率 85%，见 [既有 CI](https://github.com/pyzz58/gpt-recommendations/actions/runs/38121233769)。这些数字衡量程序回归，不能代替导演质量。
