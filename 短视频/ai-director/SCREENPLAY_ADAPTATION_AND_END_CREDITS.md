# 剧本结构改编与末镜依据页（2026-10-13）

## 本轮变更

旧流程把原稿拆成镜头后，仅在固定旁白、顺序和时长上进行动作与画面润色，不足以完成小说/散文→影视剧本的专业改编。本轮新增 screenplay_adaptation.py，且不替换原有多岗位导演团队。

### 1. 剧本编辑层

- build_editor_request：组装未发送给模型的剧本结构改编任务；要求戏剧问题、转折、收束及场次设计。
- validate_proposal：支持 keep、compress、expand、split、merge、reorder；新节拍绑定旧镜头 source IDs；删掉的原稿必须列明原因；错误重复引用直接拒绝。
- 新台词与旁白修订记录为拟改动，不宣称取得作者许可；标为原文台词的内容必须真实存在于该集源文本。
- compile_reviewable_shot_plan：把经过结构校验的合并/拆分/重排节拍重新编译为新的、时间连续且可追溯原镜头 ID 的 v0.1 文字分镜预览；它强制保持 text_card 占位，不冒充能立即生成真人画面的专业镜头。已按来源合并原人物 ID 与 claim ID。
- build_review_packet：Fountain 剧本草稿、上述重编译分镜预览、原稿版本摘要、改编提案摘要及改动账本；默认 pending_author_adaptation_review，禁止自动发布或调用模型。
- render_fountain：导出标准 INT./EXT. 场景标题、动作、角色台词及旁白，供作者审稿。

注意：这一层已经能重编排 **基础镜头时间线**，但尚未完成演员角色形象、机位、美术、声音/口型与已批准版本的真正专业导演重编译，也未将新版分镜接入已锁定的十岗位生产链。它是可检查的中间剧本，不是成片。

### 2. 统一末镜依据页

新增 closing_evidence_card.py，并接入 production_delivery._make_bundle：

- 有事实或参考出处的非虚构片末附一页独立静态依据卡，置于最后一个故事镜头之后；固定 1.8 秒，9:16，电影职员表式静态排版，无滚动、无旁白、无额外来源页。
- 由后期离线产生 SVG 素材，不向 Seedance 等视频模型请求生成精确汉字。故事镜头长度和最终合成长度分别记账。
- 一项 claim 对应一行精简出处；完整文献、来源链接与未核验状态保存在发布说明的辅助结构，不虚构论文。
- 引文超过七行或长度超限时，不偷删、不假装能在 1.8 秒读完；片尾自动版面进入人工重排阻断。
- 对纯虚构情节不强加科学文献结尾；对医学、法律、财经等事实稿继续保持真实性核查和发布许可门禁。
- 资料来源元数据或 claim 的 verified 状态不能独立证明论文支持某种论断，实际发布需要另外核查。

## 状态与优先修复

本轮主线：原文（仅私有）→ 保守来源草稿 → 可重组剧本提案 → 作者审查 → [尚待实现：新版分镜经作者许可转成专业可生成镜头并重启团队] → 各部门导演生产方案 → 单镜候选制作 → 后期末镜依据页 → [尚未完成真实多镜合成]。

下轮第一优先是将已重排的基础分镜完善为专业可生成的动作/摄影/声音/口型计划，并在可信作者审批后重新启动十岗位团队；第二优先是可播放的两个镜头加 1.8 秒片尾图卡的真实离线合成与审片。缺少真人审核与付费授权时必须停留在设计阶段。

所有自动化测试是合成/公共虚构数据，不能证明剧本艺术质量、真实成片、真实引用或片尾可读性。不上传私人原文、不在用户电脑操作、不调用付费 API。
