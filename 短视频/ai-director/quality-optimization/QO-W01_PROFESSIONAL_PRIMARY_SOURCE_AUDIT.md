## 1. 职业编剧原始资料的真正启示（非关键词摘抄）

### 1.1 Tony Gilroy：重要的是抓住作品内核，并选择电影化形式

- Gilroy 回忆《Dolores Claiborne》改编：**结构和叙述方法明显改变，却依旧抓住了原著人物和世界**。因此「保留每个原文单元」不是忠实改编的定义，真正要问**什么改变会毁掉作品的特性**。
- 他早期创作从具体而微小的可拍事件/人物出发，不先拼出空泛“大主题”；在大量草稿/大纲中探索后，必须反问“我们到底在拍哪一部电影”，才选择能承托作品的结构。
- 他将笔下角色行为的可信度看得非常重要；最终剧本逐轮删掉不必要台词和描写，**舍弃本来喜欢的段落**也可能让影片更好。
- 他自己的讲座主要讨论原创剧本；其具体两小时长片排期、剧情压力曲线**不可复制**到短视频纪录/哲学散文。
- **转译到 W01**：改编前必须有可讨论的「创作内核/创作角度/具体可表现的瞬间」，并允许大量有理由的删改。追溯表应该服务创作，不该成为逐句复述机器。

### 1.2 John August / Craig Mazin：小说和电影的叙事发动机不同

- 《Scriptnotes》Ep.124 完整问答：改编原著时要尊重作者为何写书，同时思考其特定语言能否在电影中成立。能保留的语言保留；不能靠硬塞原文叙述假装忠诚。编剧必须为**电影这个媒介**重写。
- Ep.216：Mazin 明确提出先问「原著什么令我着迷？什么虽然精彩但不适合影片？是否要改变结局？如何让它与开端呼应？」也就是**有选择地重新创作**，不是给每一段设置“critical”。
- Ep.536 / Ep.673：小说允许大量内心、空间和时间；电影以行动、画面和声画推进，改编需要不同的驱动机制。更改情节次序/删去某段不天然意味着差的改编。
- Ep.403：Mazin 认为良好的结构来自人物面对中心论辩时发生的变化，反对填鸭式三幕/固定页码；但他本人也特别指出主要是在讨论**传统好莱坞叙事电影**。我们应吸收「变化源于作品内部的因果」，不能把「必须有人物反主题、信念反转」强加给介绍图灵的思想史短片。
- **转译到 W01**：先写「书/文案为什么成立」与「**屏幕上**让它成立的是什么」，给出几个改编方向及取舍，再选方向写 treatment、场次。核心不总是人物，可能是观众的**认知轨迹**。

### 1.3 WGA／Academy：选材与剧本质量不仅是覆盖率

- WGA 的对应手册明确认为源作品的独特选择、组合、重新安排属于有实质意义的编剧创作。**来源 ID 与逐条保留率不是写作水准指标**；应观察最终材料选择是否有独创性、是否服务电影叙事。
- Academy Nicholl 的评分问题包括：观众是否被带入一段旅程、故事是否有鲜明声音、能否唤起情感，作品是否有难以简单量化的特质。**字段正确、结构对称、来源完整都不是这些问题的答案**。这只是长片竞赛评鉴视角，不能当官方 AI 视频评级方案。
- **转译到 W01**：独立审核必须先看故事/信息旅程和改编是否有创意，而不是把机械验证放到审稿判断之前。数据追溯是 QA 的下限，不是创作的上限。

### 1.4 Sundance：好的剧本重写有步骤，不是一次模型调用和一次 JSON 审核

公开课程**完整大纲**强调：重写计划与核心问题 → 人物/世界（适用时） → 结构及结局 → 真实性与研究 → 场景中的行为/次文本/对白 → 审读体验与精修 → 个人反馈。短片课程亦讨论不同体裁、视觉叙事、开头结尾和反复修订。**仅能从公开课程大纲确认此教学顺序，不能声称已阅读付费课程的具体练习全文。**

- **转译到 W01**：创作意向/方案/treatment 与剧本**必须分开评审**；先判断“这值得拍什么”，否则再高级的文案追溯器也只能给平庸影片贴满正确标签。

### 1.5 纪录片伦理：有创意地浓缩事实，不等于可以把疑问写成证实的结论

IDA 关于纪录片创作的专业讨论承认：剪辑与叙事必然经过选择和建构，同时要避免事实、受访者意思、时空关联的误导。对于**作者原稿**和**历史类/真实人物题材**，事实属性与创作自由的边界要比虚构剧情更严格。
- **转译到 W01**：要区分「硬约束」：时间、人名、已给原始引用、不把开放问题改成确定事实、不能编造历史对话；与「可重新创作的表现方式」：开头、顺序、场次组合、视觉情境、旁白句型等。
- 用户已明确：原文有资料/论证材料才使用；**没有就不强行补充资料或参考文献页**。这与是否要求内部真实性核查是两件不同事。

## 3. 为 AI 短视频量身设计的 **真正创作流程**（建议方案，尚未编码）

### 阶段 S0｜阅读全文，不写镜头

给编剧全文或明确选中的完整章节。读后形成「作品创作诊断」：
- **这是一个什么作品？** fiction / documentary / essay / hybrid；作者希望观众最终明白/感受到什么？
- **内核与原文特性**：fiction 的人物关系/抉择/代价，essay 的提问/论证链，documentary 的事实/来源与未确定部分；哪个原始质感不能损坏？
- **创作自由边界**：原始材料硬事实、用户特别保护的结局/人物/论点、仍有争议或无法确认之处；合理可删的铺垫/细节/重复。**核心清单是经编辑审查的初步判断，不是不可变的 AI 真理。**
- 预期短视频观看长度的范围由内容/目标平台/用户意图决定，不被单个生成模型的 4/8/10 秒 clip 反向强制。

### 阶段 S1｜编剧提出 2–3 个影视化「Take」并比较取舍

每个 take 必须有：
1. 一句话的**影视创作命题**（观众会经历怎样的感受/认知转变）；
2. 开场情境、关键变化、结尾回响；
3. 采用的实际影视表达：行为/旁白/反差/示意/真实素材/后期精准文字（**不设计景别、焦距或生成 API**）；
4. 从原稿删了什么、挪了什么、为什么电影/短视频这样更成立；
5. 删改的代价，是否越过用户保护边界，有无新增未经证实事实；
6. 概略长度、AI 短片制作压力提示；具体 shot/clip 拆解留给导演与技术岗位。

**选择方案应由编剧说明理由 + 独立编辑评议 + 用户对重大取舍决定**，不是由程序给最高“保留率”的方案自动加冕。

### 阶段 S2｜写 treatment，再写剧本

先以短 treatment 把每一场的「观众当前理解/人物状态 → 出现的新行动/信息 → 产生的变化」写透。小说不要求旁白逐句重述内心；观点短片不要求硬造主人公。然后才写完整的动作、对白、旁白、沉默与具体结尾。

**剧本必须为导演留下摄影自由，但不是把关键叙事行为留白给导演重编。**

### 阶段 S3｜两种不同的独立审查

- **专业改编审核**：不看源 ID 数量先独立阅读原稿，再看 take、treatment、成稿。回答：是否还像原作品、重点是否放对、是否产生新影视价值、删改是创意还是歪曲？
- **戏剧/信息旅程审核**：剧本单独阅读。作品是否有鲜明创作声音、是否有必要的场景、每场是否让观众认识/情绪有变化、收束是否完成或有意义地保留疑问？
- 然后才运行 source IDs、版本/授权/时长等确定性结构检查，确保**没有偷偷遗漏或历史失真**。三类检查互不替代。

### 阶段 S4｜定点返修与版本审核

优先修错读原稿和方向性缺陷 → 再修场次与镜头化表达 → 最后润色句子。改稿前能说清“为什么、改哪里、预计对观众有什么效果”；比较 v1/v2，不自动覆盖。用户对重大设定/结局/事实的修改可审阅；普通表达性变化不必机械要求每一句都点击接受。交付已通过审阅的**完整剧本**，而不是一个只是形式正确的 proposal。

## 4. 用于校准审稿的公开样稿设计

### 科学史/思想类（案例取材于用户此前展示的图灵主题，仅**此处记录抽象问题，不复制私人文案**）

- **源作者的真实推进**：牛顿与爱因斯坦的思想跃迁作为对比 → 早期计算机器的实体限制 → 图灵/计算与智能的联系 → 最后提出「智能是什么、能否机械描述、机器能否具有智能」的开放问题。
- **失败的 take**：把图灵作品变成 ENIAC 历史年表、添加原稿没有的技术数字、用 AI 已经具备意识来回答未回答的问题；虽每段都能映射 source ID，但偏离核心哲学追问。
- **较有潜力的 take**：先从「机器能迅速计算，但那是否等于思考？」的可观看对照切入，再逐步让观众理解为何早期计算机先驱会问出原稿结尾的问题。可为纪录式旁白+示意，而非必须给图灵写对白。
- **预期对标**：内容没有无授权的新依据；场次从能力→界限→哲学问题递进，结尾保持问题开放，导演接过后不需要重新写哲学论证。

### 小说类

同一段具有人物内心、对话与关键选择的公开虚构文本：一版逐句搬运内心旁白；一版把人物选择写成可见行动，保留情绪内核却压缩原文非视觉段落。专业盲审需证明后者更接近可看可感的场次，而不是来源映射更多。

### 纪录类

带有时间/身份/事实边界的公开合成访谈：一个版本只重新组织材料；另一个版本将未经核实的推测改为确定事实。独立审核必须抓住第二种失真，同时不能给前者的正当剪辑自动扣分。

### 长篇无标题素材

按连续章节/片段完成全文（或明确生产范围）素材摄入。语义质量审读“原文前置伏笔与结尾兑现”能否被合理缩短，不以占满长视频或逐句直译为奖项。

## 5. 分层验收，而不是「一个模型给 90 分」

1. **L0 完整摄入/权利与来源**：源文件/范围哈希与作者保护项可信；缺失明显来源标记、偷偷改硬事实要阻断。该项代码可验证。
2. **L1 改编决策质量**：至少 2 个具有实质差异的 take，解释保留/删减、主体内核、场次方向和局限；独立审稿者认为其确实是不同的电影化方案，而非同一摘要换说法。需要真人或经标注的开放基准评议。
3. **L2 作品质量**：独立盲读 v1/v2，以人物行动/概念递进、原创声音、场景必要性、结尾兑现判定优劣，并记录错改或正当删减的反例与误报率。
4. **L3 交给导演**：总导演根据完整剧本能够直接构想镜头/行动/声音，不必另写核心故事和论证；景别、分镜数、实际生成 clip 仍由导演和技术岗位选择。
5. **L4 AI 视频现实性**：编剧可以交付一段跨多镜的场次，不能被目标模型单次 clip 的时长强制删掉核心。具体供应商能力及真实片段效果在 QO-D04/D11 评审。

**关闭 QO-W01 的实际条件**：职业原始资料审计入库；编剧真正完成「原文诊断→差异化 take→treatment→剧本」的至少三文体公开案例；专业独立审阅能辨认「正当创造性压缩」与「真正扭曲」；在用户认可的真实（私有）稿件或可信的额外公开样稿上进行盲评，明确实测/未实测，并把对应记录、GitHub PR 和测试写入总账。缺上述任一关键条件只能 \`partially_addressed/in_progress\`，不得标 complete。
