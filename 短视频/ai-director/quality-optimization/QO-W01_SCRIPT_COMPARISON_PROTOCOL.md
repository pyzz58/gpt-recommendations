# QO-W01｜职业编剧作品对照测试：公开方法学与私稿保护

> 测试日期：2026-10-13。继 [国际职业编剧一手资料深度审计](QO-W01_PROFESSIONAL_PRIMARY_SOURCE_AUDIT.md) 和 [创作开发模块实施](QO-W01_CREATIVE_DEVELOPMENT_IMPLEMENTATION.md) 之后，本轮开始**实际比较文字剧本**，而不仅增加合同与门禁。
>
> **重要隐私边界**：用户真实原稿、旧版完整剧本、新版完整剧本、评审过程数据及匿名包只存在用户本次私有交付，不上传公共仓库。本文件不包含私人源文案或剧本原句，不代表用户授权公开。

## 阶段1：已完成的「人工文字级」对照

- **同一用户原稿、同一主题**：复核以前完整人工编剧旧稿，另依据职业原著诊断与改编方案的工序人工撰写一份新稿；客观比较场次、叙事推进、旁白语言密度、原稿事实新增、来源卡遵循及导演交接边界。
- **旧版**：8 场，叙事预计 106 秒，另有以当时新增资料为依据的 1.8 秒片尾卡，后来用户已澄清「原文无资料不强行加片尾资料页」。
- **新版人工 V1**：6 场，最初约 98 秒；作者自审发现两场旁白过密且提问方式不够准确。已实施一次**针对性旁白修改**，保存为约 99 秒的 V1.1。没有加来源页，示意与史实边界明确。
- **事实判断**：长度、场次、VO 字符和原文外事实数量可部分机械核查；影视感染力、人物/思想可信度、观众体验和所谓「是否一流」只能经独立作品审读与最终媒体试验评价。
- **当前审阅状态：内部写作者复审，非独立盲评**。由于样稿由同一模型创作/审核，不能作为「专业盲评改善」的证据，更不能用 V1.1 写得更短来推断电影质量更好。
- **结果**：新版初步方向强调减少素材年表式罗列、使场次的画面动作与原稿问题关联更强。但仍有思想展示抽象、概念场景易用纸张/示意图重复、历史演绎真实性和核心哲学体验弱的风险。编剧还不能声称已完成 QO-W01。

## 阶段2：真正合格的旧流程 vs 新流程实验（待执行）

| 控制变量/步骤 | 必须如何执行 | 什么算有证据 |
| --- | --- | --- |
| 输入相同 | 同一篇原文、相同可用篇幅/预期视频时长/事实边界；记录原始 sha 在**私有**测试存储 | 原文可追溯，未上传公开仓库 |
| 模型/预算一致 | 用同一授权 LLM 与等价调用预算执行「旧一步写剧本」与「新版诊断→2–3 takes→treatment→写剧本」；记录成本和每次输出 | 确实发生的 API 请求/响应回执；**没有授权就不发请求** |
| 草稿的公平性 | 新版可因多阶段消耗更多 tokens，报告必须分别比较固定成本和不固定成本两个条件 | 不把多调用成本隐藏在效果收益后面 |
| 匿名 | 删除版本/提示词/作者标记，由第三人生成随机代号并保管密钥 | 外部评审不知哪个是新流程、哪个是旧流程 |
| 职业改编审读 | 审稿者独立阅读原稿后，再看两版剧本。逐项指出原著内核、正当电影化删改、错读事实、影视叙事变化 | 逐场、逐句可回查的问题/修改，而非只有分数 |
| 剧本单独盲读 | 第二组审稿者不看提示词或开发流程，只看成稿文本是否引人、声音鲜明、场次有必要、能交付导演 | 具体批注、偏好或并列结论 |
| AI短片技术复核 | 导演评估可见行为与旁白、人物/场景复杂度、可能的视觉假象、后期字幕的必要性；明确不承担剧本重写 | 风险记录，不以未生成视频宣称可拍成功 |
| 迭代与复测 | 每份稿子的最高优先级缺陷由编剧定点修订，保留初稿/二稿及问题是否解决 | 真人/独立样本复核，不把自己给自己的好评算盲评 |
| 多文体 | 小说（内心→可演行动）、纪实（事实/演绎）、思想文章（认识变化）、较长无标题材料 | 每题材至少一个**实际完整剧本**，有可比评论 |

## 匿名评审维度

1. **核心忠实**：原作作者声音、思想或人物关系得到保留；合理剪去不适合影像的段落不得简单判为错误。
2. **真实电影化**：观众的变化是否通过行动/声画关系体验到，还是原文被旁白重说一次。
3. **结构与节拍**：场次存在理由、起承转换、开场钩子与结尾兑现。
4. **自然表达**：对白/旁白密度、重复、套话、潜台词（只适用于有角色的作品）、沉默与声音的作用。
5. **事实诚信**：原文已有数据与论据保留或清楚说明删改；**原文没有，就不得把新资料伪装成原文证据**。片尾证据页有原文资料才可选用、放最后 1–2 秒。
6. **导演交接**：总导演能直接构思镜头、演员、摄影、声音和剪辑，不必自行发明故事、人物对白或观点。
7. **AI视频现实性**：脚本时长 ≠ 镜头时长 ≠ 模型一次生成 clip 长度；不能将 AI 模型每片数秒的限制硬塞给编剧。

**允许反对票**：可判断两个版本都不及格、两者各有长处、同一场难以断定。严禁预写新版必须获胜的评审结论、直接给“世界一流”虚假徽章或把 CI 通过当作品获奖。
