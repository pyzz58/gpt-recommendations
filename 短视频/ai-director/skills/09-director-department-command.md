# Skill 09｜职业总导演的跨部门指挥、详细制作会与实际验收

> 基于 [QO-D15 国际一手资料专业审计](../quality-optimization/QO-D15_DIRECTOR_DEPARTMENT_COMMAND_AUDIT.md)；与 Skill 08（全剧本创意剪辑）和 Skill 03（逐镜头技术导演）配合。**这是本项目的制作方法，非 DGA 官方认证。**

## 一、总导演首先要亲自明确这部片子要发生什么

任何部门开工前，导演必须在已审的剧本/分集基础上回答，而不是写「大气、感人、流畅」：

- **观众的经历**：观众在开头知道/相信什么？第几次可见行为或信息改变这种状态？结尾发生了什么决定或留下什么开放问题？
- **为何值得被拍**：哪些场次最不可替代？哪项具体人物处境、动作、反差或思想震荡承载整片核心？不能以普通漂亮 B-roll 遮蔽抽象、无效的场次。
- **影片的视听母题**：为什么要重复某个具体物件/动作/构图/声音？每次出现又有什么新的意义？如果随意换成普通风景还一样，说明母题没有成立。
- **全片的节奏**：哪几秒必须允许观众感受沉默，哪几秒因观众已明白而应切换？不允许机械固定三秒一切或规定所有镜头必须运动。
- **事实与伦理边界**：原文开放问题不得替换成确定结论；历史概念演绎与实拍证据必须明确区分；不能伪造原稿证据。
- **AI 视频制作边界**：单集≤90秒；每个AI clip 与单集总时长不同，字幕与精确图表优先后期，跨镜角色/道具/空间必须保持连续；供应商具体能力先由技术岗位核实。

每一项都要**引用剧本真正发生的内容和本集真实shot IDs**，而不是泛化。

## 二、总导演召开一次完整的“制作会议”

导演先完成现有 `director_brief`、前置剧本连续性检查 `script_edit`、和 `director_lock`。然后调用 `director_department_command.command_request`，以已锁定的导演 vision、每镜情绪及可见转折为依据形成每个专业的详细工单。

每个部门收到七项全局说明：
`specific_assignment`、`why_audience_needs_this`、`concrete_execution`、`creative_boundaries`、`needed_from_upstream`、`deliver_to_downstream`、`failed_result_and_recovery`。

**每个真实镜头独立收到**：
`dramatic_beat`、`desired_viewer_effect`、`department_execution`、`sync_with_other_departments`、`observable_acceptance`。

另有两项以上本专业实际**可检查的验收条件**，并对跨部门真实素材、时码和状态的7个关键接口写出交接内容和冲突仲裁方式。不能只有一句「摄影负责精美画面，剪辑负责流畅」。

## 三、给每个专业的指导应如何详尽且不越权

| 专业岗位 | 总导演**必须讲透的艺术目标** | 本岗位应交付的**真实专业细节** | 必须协作 |
| --- | --- | --- | --- |
| **表演 / 动作** | 人物在具体触发下为什么选择，观众要看到哪次犹豫、勇气、抗拒或认识变化 | 站位、视线、手部与道具位置、面部/身体微动作、动作前后状态、可拍性与失败备用方案 | 摄影空间关系、剪辑真实切点、声效同步；如人物要改变剧情→编剧 |
| **摄影 / 美术** | 为什么在这场看这个人或物，不看另一个；光源/色彩为何支持作品思想 | 景别和视角、镜头运动起止、物理光源、空间轴线、环境/道具材质、角色连续参考 | 表演 blocking、美术道具、剪辑前后画面锚点 |
| **声音 / 台词** | 是沉默更能打动，还是某个声音必须打断观众期待？音乐为什么出现而非无理由铺满？ | 旁白/对白逐字和时间码、环境声、拟音、音乐进出点、J/L 声音桥、字幕声画协调 | 演员动作、剪辑音画拼接、技术口型/配音 |
| **剪辑 / 动画** | 观众刚从上一镜得到什么新信息，下一镜应解答什么；为什么现在切、不再拖延？ | 镜头衔接、节奏、声画桥、叠化或跳切的必要性、动画图层/速度/后期精确文字 | 表演、摄影、声音的真实帧/动作状态，交 AI 技术 |
| **AI 视频技术** | 模型选择服务导演的**镜头目的**，不能拿模型默认美观模板掩盖创意 | clip/静态/合成/实拍路线，明确参考素材、生成提示词、能力限制、成本前核查、局部失败替代、后期任务 | 摄影/剪辑/声音的已认可工作单；不能自行杜撰新故事 |
| **独立场记 QA** | 哪个错误会使本片观众误读角色、事实或哲学结论？ | 镜头/声音/角色/道具状态检查、逐项 blocker、责任岗、可复现修复办法、真人媒体盲审标记 | 逐部门所有已完成工作；只有审核权，无自动剧本重写 |
| **总导演终审** | 全片是否真正实现了事先确定的观众体验、人物/思想及结尾余韵？ | 跨岗矛盾选择、重大风险、哪镜返工、谁负责、用户需审什么、是否值得进入真人评审 | 专业 QA、剪辑对照版本、原文事实与艺术完整性 |

专业自主性：导演必须说明**艺术原因和必须达到的效果**，不应把摄影、表演、声音的全部微观专业选择擅自写死；最终创作一致性由导演负责。

## 四、责任链与闭环

`导演 vision → 全部门会议 → 各岗岗位模型真实请求 → 岗位自己的结构化交付 → 前后镜/跨专业交接 → 独立场记QA → 总导演返工选择 / 交用户审阅`。

跨部门接口至少覆盖：
1. 表演 → 摄影：角色动作与镜头/空间轴线；
2. 表演 → 剪辑：真实动作结束姿势与切点；
3. 摄影 → 剪辑：画面锚点、运动方向、前后镜光源；
4. 声音 → 剪辑：声轨/对白时间码与音画桥；
5. 剪辑 → AI技术：真实镜头制作路线和后期文字/特效；
6. AI技术 → QA：已生成/未生成证据、待验证资产与模型风险；
7. QA → 总导演：有责任归属的 blockers 和观众体验警告。

遇到冲突不能互相覆盖 JSON：若演员动作用右手拿信，但摄影画面阻挡右手，摄影先反馈导演调整景别/角度，必要时演员调整 blocking，剪辑重新确认时间；如果涉及原作者剧情/对白改写，则回原编剧审核。**部门问题返工要精准到镜头与责任专业，而不是让所有 Agent 从头来一次**。

# base：这集经过审核的权威导演底稿；state：原10岗位team ledger

request = director_command.command_request(base, state, source_text=script)

receipt = director_command.validate_command(base, state, command_candidate)

旧版兼容任务可能无强制开会标记，不能把它宣称成新专业导演流程。来源、导演锁稿及任务版本发生改变时，旧会议作废，必须重新生成，不能照搬上轮。

## 六、世界级质量最终验收尚需的证据

- 真实电影/纪录/科学观点短片至少三种样稿，依次由新流程给各部门详尽指导，独立专业人士确认创意可执行且能共同实现导演 vision；
- 对照旧版通用岗位 prompt 的场次/观众理解改善，而不是只比较工单的字数；
- 各部门出现真实冲突后的返工闭环、有实际镜头/音轨/剪辑成品证据；真实可生成镜头仍须获取授权；
