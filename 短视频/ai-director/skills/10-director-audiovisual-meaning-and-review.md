# Skill 10｜总导演的思想与情绪视听表达，以及部门交付审片与返工

> 基于 [QO-D03/D16 一手访谈与既有代码深度审计](../quality-optimization/QO-D03_D16_AUDIOVISUAL_CRAFT_AND_DELIVERY_AUDIT.md)，补强 Skill 08（导演决定故事内容）→ Skill 09（向各部门下达详细制作工单）→ Skill 03（具体专业镜头）之间最容易缺失的两种能力。**不是另造一位导演，也不是“漂亮镜头生成器”。**

## 1. 先建立独一无二的导演表达，而非调用现成镜头配方

每位导演面对剧本都应独立回答：

- **作品最重要的矛盾**究竟发生在人与人之间、人的选择中、知识概念的冲突中，还是观众原有信念被推翻的过程中？
- **镜头里发生什么，才使观众改变认识？** 具体哪只手、哪件道具、哪次拒绝、哪片空白、哪个声音让故事朝下一状态移动？
- **镜头应该站在哪种感情立场上？** 可以与角色同知，可以让观众先知道危险，可以刻意保留信息；决定的后果必须清楚，不为“悬念”欺骗。
- **为什么使用静止/移动、远景/近景、前景遮挡/留白、冷暖/光源、自然音/沉默、继续留住/切走？** 对每一项至少能说出一个可观察的情绪或思想效果。
- **视听母题要发展**：同一个物品或构图第二次出现，意义与观众理解至少有所变化；重复一个漂亮镜头不构成母题。
- **哪种表达不应该出现**：例如将未验证科技假说用确定的演绎场景拍成历史事实；用无关高速 B-roll 掩盖人物没有行动；反复使用“震撼背景音乐”代替冲突。

职业资料可用来启发互不相同的选择：斯科塞斯有时明确拒绝摄影机移动，Schepisi 有时用缓慢、不同心的空间运动制造关系不安，Carrière 用画面揭示顺序和沉默改变观众所知，Carpenter 反对无内容场景靠技巧抢戏。**不要规定“一流导演一定会运镜/一定不会运镜”**。

## 2. 具体到每个镜头与两个镜头之间

每镜真实输出 `director_visual_language` 下列信息；不能为空话：

| 字段 | 必须说清 | 哪种答案算失败 |
| --- | --- | --- |
| `incoming_viewer_belief` | 观众入镜前真正知道/以为/担忧什么 | “观众期待新内容” |
| `observable_screen_event` | 镜头内哪个真实可见事件改变了这一点 | “营造丰富情绪的电影感” |
| `viewer_belief_after` | 镜头后观众具体理解/情感改变 | 复制入镜前状态 |
| `visual_emphasis_and_reason` | 人、物、景深、遮挡、位置关系为什么该被看见 | “电影级景深+光影” |
| `mise_en_scene_and_performance` | 演员如何动作、谁回应、道具处于什么状态 | “演员演得高级” |
| `framing_movement_or_stillness` | 必须运动吗？如果不动有什么理由？ | “每镜缓缓推近” |
| `sound_or_silence_contribution` | 具体音乐/声音/安静改变什么、在哪里介入 | “背景音乐舒缓自然” |
| `cut_or_hold_causal_reason` | 切点与观众当下知道的信息、动作/反应之间的因果 | “动作结束后自然切镜” |
| `counterfactual_if_generic_coverage` | 改成普通素材或切早一秒会损失什么 | “画面冲击力变差” |
| `ai_fallback_without_story_loss` | 模型做不到，什么低风险制作路线还能保住意义 | “重新生成到满意” |

相邻两镜再记录 **上镜留下的观众问题、下镜所提供的新信息或情绪、视线/动作/形状/声音锚点、为什么这时切**。节拍和时码来自**经审查后的导演分镜底稿**，不可藉导演感想暗改权威剧本。可有意义地打破空间连续性，前提是说明观看效果而非机械禁用跳切。

## 3. 制作会必须真正驱动各部门

具体导演声画 plan 必须进入实际各部门模型的用户消息，而不只是存于导演报告：

- **表演/动作**：导演说明关键动作背后的动机和感情代价；专业岗位细化目光、手与物体接触的物理状态；其他岗位不得代写人物动机。
- **摄影/美术**：导演讲清为何要让观众看到某个人与另一个人的空间距离，或为何用静止而不是运镜；摄影师自己挑可实施景别、灯光、镜头角度、角色与道具方位。
- **声音/台词**：导演规定情绪与信息的进入时机，以及静默为什么必要；声音师落实真实语言、房间声、音画桥、音量与时间窗，而不是拿默认 BGM 蒙混。
- **剪辑/动画**：导演规定观众何时才应获得关键事实、何时等人物反应、何时过渡到下一节；剪辑师落实切点、声画互相领先/延后、动态图层、必要时间码。
- **AI 视频技术**：技术顾问检查模型实际能否执行复杂动作、双人对视、手部道具连续性；提出后期合成/静帧/替代机位而不能私自删除叙事核心。
- **独立质量审核**：先确认导演意图，再查实际设计是否可能令观众误读、是否失去人物/事实/概念边界；真实媒体没看见就不可自称审片。
- **总导演最终审稿**：导演必须统筹以上冲突，决定谁返工、返工到哪个镜头、需要哪个专业协同、为何这样才能实现最初创意。

使用 `director_visual_language.request` 形成独立 plan，校验后经 `agent_role_contracts.build_role_messages(..., department_command=meeting, audiovisual_plan=plan)` 注入**真实模型可见**的专业用户消息。这是对 Skill 09 已存在的制作会的进一步具体化。

## 4. 导演收回各部门的工作并做创作性验收

**不准**只核对七份工单齐全。真正的导演需要重新查看专业成果与目标之间的差距：

1. 确认此部门**是否真的提交了设计成果**。未提交直接标“无法评价”，不能假装模型已经做完。
2. 对每个已提交的部门/镜头分别回答“这个实际提交的动作/画面/声音/剪辑时间会使观众产生预期变化吗”，引用岗位输出的具体做法，并指出缺失会造成什么观感。
3. **跨部门冲突**要具体到镜头和状态。例如演员导演安排右手停在信封上方，而摄影让右手被前景桌面完全遮挡；导演必须决定改表演位置或改机位，剪辑再核查动作接续，而不是同时要求各部门“优化细节”。
4. **具体返工单**：镜头 `S01`，负责 `acting`，症状是手未停住，观众因此认为人物只是普通拿信；请调整动作，`camera_art` 与 `editing_animation` 协作，重新验收停顿与拆封的连续关系。
5. **版本变化后重评**。返工通过原 `agent_team.request_revision` 提交，已有下游依赖自动失效。旧导演评语随真实交付版本变化作废，避免一次审过的报告被无限复用。
6. 需要返工的任务不能在同一时刻自动全部发起；每个精确改动都由导演决定，防止循环生成与成本泄露。
7. 如果角色、重要台词、原稿事实、论证或人物抉择有改变，必须返回编剧改稿和专业审阅，不能用导演“艺术自由”掩盖违背事实。

## 5. 真实案例：同一个信封，普通制作和电影语言制作的差别

**主题**：不是信封里有什么，而是角色是否愿意面对未知。

- **S01**：角色的手在封口之前停住。摄影静止，让封口和手同时被观众看到；身体紧绷但不夸张；只保留极轻的衣物声，避免观众被配乐直接告知“他害怕”。**切太早，观众没有体验到犹豫。**
- **S02**：同一只手终于撕开封口，声音中只有真实纸张破裂的瞬间。保留人物放下手后的一小段停顿。**过早展示信中内容，主题就由“承担未知”被错误地改成“揭秘答案”。**
- 这两个镜头不需要昂贵运镜，也不需要每秒塞满复杂动作。导演应指挥表演、摄影、声音、剪辑各专业，共同让这次人物态度改变真正可感。
- AI 模型若无法持续生成真实手/封口状态，技术部门可做局部定帧/后期音效；**不该为了避开手部技术难题就删除决定的关键动作**。

## 6. 适配用户的 AI 短视频系统

- **导演可以质疑编剧剧本无聊，提出10分钟故事压缩成3集**，但结构性删改仍需编剧返修和必要的审核。此权力归 Skill 08。
- **正式每集≤90秒**，含实际片头、过渡、回顾、尾页。AI模型单次生成 clip 的几秒钟属于下一层技术约束，不得挟持导演的情绪节奏。
- 竖屏9:16 要看清人物眼神、关键手部、表演关系、文本安全区，空镜与沉默只在有明确创作目的时保留。
- 真实声音和后期字幕/数字必须与画面形成可验证关联；历史科学演绎不得冒充原稿有证据。
- **最终审片严格分层**：静态设计稿合同校验 → 实际生成素材的物理可行与声画连续性 → 真正观众是否感受到思想与情绪 → 作者/有权方终审。任何一步不自动代表下一步。
