# 第20号导演专业规范｜QO-D05 与 QO-D07：跨镜视觉世界、场记与导演镜头语言

**版本**：director-visual-continuity-v1  
**模块**：`director_visual_continuity.py`  
**统一入口**：`director_creative_integration.postproduction_assessment`、`final_director_role_gate`、原 `agent_role_contracts` 的 `director_final` 请求与交稿复验。

**用户限制**：继续先开发不测试。本轮不运行单元或媒体测试、不用收费视频服务、不上传用户私人文案、不合并未经验证的PR。不能声称真实演员身份、摄影光线、机位轴线或电影观感已经合格。

## 一、不要把三个不同问题混为一谈

1. **电影世界事实状态**，由原 `film_continuity.inspect_tracks` 执行离线结构检查：同一人、道具身份ID，以及每镜的起始/结束 `position/appearance/condition/holder`，时码内有因果的状态变化、画外转移/跳时的声明。这个程序可以发现道具瞬移和服装变更，但不能从文本证明真人脸或动作真实性。
2. **导演的叙事/视听语言**，由原 `director_visual_language.validate` 实现：某镜头改变观众什么认识，人物的可见事件、运动/静止、声音或沉默、跨镜引导和视觉母题。只验证导演确实设计了并有源锁理由，不能把文字较长当优秀镜头。
3. **实际镜头拼接后的观众体验**，本轮新增 `director_visual_continuity`：复核实际演员、摄影、美术、剪辑三个岗位交稿，与第1和第2层对照，评价切镜是否破坏人物的选择、空间方向、眼神逻辑、动作和道具权属、光源、情绪与视觉象征，以及什么时候应该让观众故意迷失方向。

只将三者按相同剧本、导演锁、同一个镜头序列合并，**不重写已有场记或镜头语言模块**。

## 二、真正的导演要保住哪些关系

**人物与演员**：同一个 `character_id` 不等于同一张脸；服装、妆容、身体相对站位、人物间视线、谁先做动作、情绪是否真正转变，都由演员/摄影协同决定。镜头反打时，摄影机可跳到另一侧，但导演必须说出观众如何仍然知道人物各自的位置与心理关系。

**道具**：道具ID一样不等于物理连续。尤其交接、握持、手机屏幕方向、信封是否被打开、打开前后的形态，必须在相邻镜头中有明确 `start_state`、`end_state` 和实际发生时间/原因。**不能以新镜中道具“又出现了”代替真实动作因果**。

**空间与轴线**：参考固定的门、桌、道路运动方向等画面锚点；依据行动线和视线关系设计正反打。故意越轴、极端跳切、抽象蒙太奇并非自动错误，但必须写清情绪和信息意图，指出如何重新给观众定位（景别/视线/声音/位置的变化）。

**光与世界观**：光源位置、光质与色温必须有时空/美术因果；情绪型色彩突变需要叙事理由。不能要求所有片段统一滤镜导致失去真实纪录证据或本来需要的荒诞断裂。

**节奏与切点**：导演应判断切到下一镜之前，观众有没有真正看见人物选择。长静止可以是人物心理空间；快剪可以是为了感知加速；不能因为视频模型只能出4秒，就无理由剪掉关键停顿。

**视觉母题**：重复的构图、道具、颜色必须产生意义上的变化。每一个镜头都可以采用不同的摄影手法，但整片应有导演的视觉逻辑，而不是“每镜都美、整片没有思想”。

## 三、真实专业输入与严格来源

`request(base,state,meeting,audiovisual,...)` 只构造离线、未派发的 **同一个总导演** 跨镜专业复审请求。所要求的实际前置状态：

- 至少两镜；原 `agent_team` 中 `acting`、`camera_art`、`editing_animation` 已提交 `completed` 的真实逐镜专业交付，所有镜头ID覆盖；
- `director_department_command.validate_command` 与 `director_visual_language.validate` 对同一权威 `base/state` 校验通过；
- 重新调用 `film_continuity.inventory(base, source_digest=...)`，读取已有角色、道具和场景ID；
- 如果所有镜头中有明确的完整 `entity_tracks`，则复用原 `film_continuity.inspect_tracks` 重建静态风险报告，并将真实报告摘要一起绑定；
- 若**同一个已声明人物/道具跨越相邻镜头**，但缺少完整结构化状态记录，则 `missing_required_track_report=true`，不许称跨镜规划完全有效；如果全片没有跨镜实体，仍保留真人视频未检的事实。

源哈希、base哈希、导演锁、制作会、视听语言、镜头顺序、三真实专业修订号和交付hash均在快照中。岗位返工或编剧/导演改稿后旧复审必过期，**不能用更新文件名或手工复制字段规避**。

## 四、每一组相邻镜头需要审查8个维度

| 维度 | 总导演必须核查的专业问题 |
|---|---|
| identity | 人物外形/服装/同场出场关系在相邻镜头有没有叙事原因支持 |
| hand/prop | 哪只手持物、道具从谁手上变到谁手上，是否看见这个动作发生 |
| geometry | 场景的门/桌/运动方向及行动路线是否构成可理解的空间 |
| eyeline/axis | 人物看向谁、同一对话/行动的摄影轴线，是否越轴或有意迷失 |
| framing | 构图重心、静止或运动如何显露人物的心理/认知变化 |
| light | 实际美术设定里的光源、昼夜/色温、环境空间如何连贯 |
| motif | 色彩、材质、构图或道具母题是否产生新的意义 |
| edit | 切口前后观众能否发现真实行为和因果，是否有充分理由断裂 |

**总计 `8 × (shot_count-1)` 项**，每条必须绑定：相邻镜头ID、`audiovisual.shots` 中该镜头实际存在的导演原句、真实演员和摄影交付的原句（剪辑交付也可带入）、前后观众理解的状态、镜头/状态/光线/视线的具体问题、是否应该保留的有意破坏连续性、两种不同影视手段及艺术损失、负责返工的既有岗位、需要真实视频核验的事项。

**证据不是填满一个表**：引用必须是该镜头/部门真实交付中的字符串值而非JSON字段名。相邻镜头的镜头/部门归属不对就拒绝。无法凭文字验证实片人物、光源和口型时必须用 `unverifiable_without_real_media`，而非伪造“已看视频”。

## 五、四种判断与后续工作

- `continuity_supported_by_text_design`：表示纸面上的导演和专业方案未看见明确矛盾，**不表示真实视频已合格**。
- `deliberate_discontinuity_requires_review`：比如闪回、荒诞跳轴或有意切断时空观众信息，保留其艺术理由，但真人媒体审片时必须观察是否真正引发预期效果。
- `revision_required`：指定谁修正；可以是原总导演锁稿、演员、摄影/美术、剪辑/动效，不允许通过此接口改人物命运或事实。
- `unverifiable_without_real_media`：例如两次生成演员眼神和服装是否真的一致，不能仅凭两段文字下“通过”结论。

`propose_rework(...)` 把一条明确 `revision_required` 的跨镜问题转成原QO-D12 `lineage.request` 未派发修订建议，绑定这两个受影响镜头。导演变更根本创作方案必须走原锁稿级返修；技术动作只走正确的专业岗；原编剧故事改变需另提编剧审稿请求。此处**不修改任务表、不发模型请求、不授权支付**。

## 六、与已有融合入口的关系

- `director_creative_integration.postproduction_assessment(...,visual_continuity_review=...)` 汇总此项复核与QO-D10整片思想、QO-D06真实动作风险、QO-D16实际专业交付及艺术冲突仲裁。
- 如果多镜却没有交视觉连续性复核，结果明确为 `complete_cross_shot_visual_continuity_review`，不能把空字段当作零问题。
- 有明确实际动作/道具状态阻断或导演判定需要返工，则进入 `resolve_visual_continuity_and_axis_light_blockers`，不能据此输出就绪。
- 在严格 `director_integrated_creative_mode` 下，`final_director_role_gate` 在 `shot_count>=2` 时必须收到 `visual_continuity_review`；同时 `agent_role_contracts.build_role_messages`、`validate_role_output`、`submit_role_output` 的原 `director_final` 接口一致要求传入并复核。这一新增要求不影响未启用严格模式的历史项目；单镜没有相邻切口，免除这张跨镜表，其他艺术/动作/部门审核仍保持。
- 即使到达人类审阅候选，不表示成片能发布：真实音画、镜头视觉识别、用户签字、素材肖像与来源权、付费生成许可全属于独立门禁。

## 七、待用户允许后的分项验收

1. 公开**双人物+手机/门**虚构双镜头：前镜手机在甲右手，后镜乙左手持手机而无转移事件 → 必须阻断；补上合法时码与事件说明后旧“无转移”阻断不再存在，但仍等待真人动作影像验证。
2. 同场人物站位与反打视线走向冲突 → 定点摄影/表演返工；刻意越轴则要求强审美理由、人物重新定位和媒体人工审看。
3. 前镜光从左打、下一镜相同空间突然光从右打 → 非故意变化须定位摄影/美术负责人；另一个镜头的观众体验不能被假冒通过。
4. 人物或道具ID相同，交稿版本不同、实际演员外观不同 → 旧复审过期；仅在真实视频中可检验外貌。
5. 1镜、多镜和无人物纯论说场景须分别表现正确的门槛，不因缺人物强迫设计无谓的人物交接。
6. 原作允许人物关系的象征性跳切/闪回/荒诞喜剧 → 不被机械连续性规则强行删掉，专业导演可以保护非模板表达并记录观众引导理由。
7. 所有真实视频/版权/演员授权需以后独立核验；未授权绝不自动生成实际片段。

**状态：** QO-D05 与 QO-D07 仍仅为 `in_progress` 的开发中候选；不得声称已经通过上述场景或真人盲审。
