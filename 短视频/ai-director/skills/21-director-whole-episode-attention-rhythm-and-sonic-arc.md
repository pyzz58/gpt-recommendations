# 第21号导演专业规范：整集节奏、观众注意力与声画情绪弧线（QO-D03 × QO-D09）

**模块：** `director_episode_rhythm.py`。**专业总原则：** 唯一总导演负责“什么时候让观众知道、看见、听见及感受什么”，原声音/剪辑/摄影/演员岗位负责具体执行。该模块不是剪辑引擎、不是第二位导演，也不是以镜头长短计算艺术质量的评分器。

**开发状态（2026-10-20）：** 只做源代码及文档开发、静态接口核对。遵从用户此前的“先不测试”：没有主动运行单元、CI、FFmpeg、OTIO、AI视频或真人盲评，也没有提交付费API请求、上传用户私有文案或合并main。缺乏真实媒体与独立观众评议，不得标记本质量项为完成。

## 一、为何已有剪辑模块还需一个导演的节奏判断

现有：
- `director_visual_language`：解释每镜头的视听理由、观众认识变化及画面/声音与主题关系；
- `director_editorial_montage`：根据完整权威剧本与拍摄覆盖，约束多镜蒙太奇、时序与跨镜来源；
- `director_montage_editor_conform`：在保留90秒与片头/片尾/可选证据页预算的前提下形成按帧对齐的离线剪辑工单；
- `director_media_otio_export`：对使用者私有真实媒资独立校验后导出非渲染OTIO预览，不冒称真的完成NLE导入或真人看片；
- `director_narrative_bridges`：读取已写好的相邻镜头剪口设计，指出缺失或矛盾；
- `director_delivery_review` / `director_creative_integration`：对实际专业交付评估与要求返工。

**缺口**不是“缺时间码或转场字段”，而是一个真正的导演是否能判断：原稿的转折是否太早暴露、人物痛苦的停顿该长还是短、笑点应该是留白后的突切还是提前配乐泄题、是否依靠沉默产生信息，整部影片的镜头/音轨节奏是否有自己的思想逻辑，而非机械三秒一剪。

新增模块**只负责导演层**的整集注意力/信息/情绪节奏合同和对专业真实设计的艺术审查，**不直接更改任何既有工单与媒体**。

## 二、两个阶段（与已有QO-D06/D10保持一致）

### 制作前 `before_specialists`

总导演已有真实锁定的 `state/base`、`director_department_command` 及 `director_visual_language`，可选择已有 `director_artistic_methods`。输出包括：

- **开头“为何值得看”**：观众在最初看到的信息、疑问及其后兑现路径；不强制固定“前3秒大字快闪”或套路式钩子；
- **整集信息/情绪线路**：哪些信息隐藏、何时露出、何时让观众先于人物知道，何时人物表演改变观众判断；
- **声音与沉默的戏剧功能**：何时让对白退后、环境音持续、音乐入场、声画冲突、声音先行（J-cut候选）或声音延后（L-cut候选）；
- **母题回环与结尾兑现**：最后一个人物选择、论述落点、情绪回响如何与开场相呼应，不让无意义快速集锦抢走结尾；
- **拒绝的平庸剪法**：例如“每3秒切一个漂亮空镜、用音乐把所有情绪拍平”，说明会破坏具体什么人物/事实认识。

**制作前快照不得依赖未来声音/剪辑正常交付的revision或deliverable摘要**，否则正常下游工作会使导演原本批准的艺术方案假性过期。

### 专业交稿后 `after_sound_and_edit_design`

必须读取既有 `state.tasks.sound` 和 `state.tasks.editing_animation` **真正 completed 的逐镜提交**，绑定revision及完整实际交付摘要；再将观众情绪节奏与各镜真实声、剪设计互相对照。

不能用字段名、程序描述或导演虚构引号替代声音与剪辑的真实文字内容。专业交付一更新，旧节奏复审必须失效。此阶段仍然是纸面声音/剪辑设计评议，不是波形、口型、声压、真实混音或实际画面验收。

## 三、每镜的时间与人物行动必须具有具体意义

每镜完全保留已锁定 `source_start_s`、`source_duration_s`、`source_end_s`。导演最多划分6段“观众注意力节拍”，每段必须有准确的**镜头局部**起止秒数、观众认识/情绪变化、可见事件或表演、声音/音乐/沉默设计和为什么这一段需要这些秒数。

时间连续覆盖该镜头的原时长，不能有空档、重叠、延长、隐蔽移动剧本的情节时码。可选节拍功能包括：
- `information_arrives`：观众获得一个确切事实或关键线索；
- `performance_or_observation`：演员用眼神、身体行为或镜头观察呈现心理变化；
- `emotional_delay`：动作尚未完成的等待，使观众形成预期；
- `visual_or_acoustic_revelation`：新镜头/新声源使原理解发生质变；
- `earned_silence`：有剧本因果的沉默，而不是单纯为凑时长。

导演每镜必须给：观众入镜之前相信什么、离开这一镜后相信什么、视听母题如何变化、为何改成普通B-roll会失败、为什么不是“镜头越短越好或越长越高级”、如果实片无法支持这个情绪假设如何推翻/重作。

若要增删时间、调整原故事事实或对白，必须标 `director_redesign_required` 或 `screenwriter_change_required`，从原QO-D12版本治理提出变更；不得直接在当前受锁定的base内覆盖。原剧本90秒上限、额外轨道与最后引用页仍由既有权威时间线负责。

## 四、每一真实剪口只产生一次导演艺术裁决

一对相邻 `shot_id` 对应**一条**真实剪口，沿用 `base.shots.start+duration` 的绝对边界，必须解释：

1. 剪口前观众还等待的信息/动作，和剪口后观众的理解变化；
2. 当前演员行为是否需要被完整观看，剪去这一秒是否会破坏其决定；
3. 图像和画外声音的关系，是否有必要借音乐、对白、环境声或沉默跨过剪口；
4. 视觉母题、朝向、情绪如何递进；何时有理由突然反转或刻意不连续；
5. **两套实质不同的剪法**及每种获得、牺牲的观众理解，不允许方案A/B只有文字措辞不同；
6. 真实音轨、转场把柄、生成片段等是否存在；没有则必须明确“待实片验证”。

剪口候选包括硬切、匹配动作/视线/形状、声音主导、J/L声桥、必要的保持/故意跳切等。**J/L只是候选**，不能以“文本写了”就宣称音频帧已重叠；真实媒体帧及剪切把柄由原剪辑工单/OTIO验证后才能执行。

制作后每个剪口至少需要一个声音及一个剪辑部门**真实交付原句**。导演可对专业方案提出精确返修，但不可让声音或剪辑修改权威台词、事件结果或剧情顺序。

## 五、实际专业入口与版本保护

原 `agent_role_contracts.build_role_messages`、`validate_role_output`、`submit_role_output` 新增兼容参数：
- `rhythm_pre_plan` 只在现有 `sound`、`editing_animation` 岗位使用；实际message会注入同一导演的整集节奏和逐镜剪口方案。
- `rhythm_post_plan` 只在现有 `director_final` 岗位使用，必须由真实声音与剪辑交稿支撑并通过版本校验，不能替代QO-D10/D06或原QO-D16审查。
- 只有新base显式声明以下严格模式才强制：
```json
{
  "director_integrated_creative_mode": {
    "kind": "director_integrated_creative_review_required",
    "before_specialists": true
  },
  "director_rhythm_mode": {
    "kind": "director_episode_rhythm_required",
    "before_sound_and_edit": true
  }
}
```
- 严格模式下，缺制作前节奏方案不得向声音/剪辑派发或接受其输出；已判定必须改导演/编剧方案时也不能继续派发；缺真实声音/剪辑版号复审不能进入最终导演完整终审。
- 旧base未设置该节奏标记时，原专业交付合同保持兼容，不强迫为已发布的旧模块补填新字段。
- `director_creative_integration.postproduction_assessment` 汇总真实声音/剪辑节奏审查与整片艺术/动作/跨镜视觉/部门冲突，把已知返工与“只有真实媒体才能知道”的开放问题分开。真实返工阻断最终 `ready_for_user_review` 候选，纯媒体问题不伪装为已看真片或正式发布许可。

## 六、实际剪辑仍必须走原可靠工程

本模块**不修改**：`director_editorial_montage`、`director_montage_editor_conform`、`director_media_otio_export`、`director_timeline` 或原演员、剪辑、声轨字段。帧率、源镜可用把柄、FFprobe真实媒资长度、OTIO读回、声音/字幕同步和片尾证据页预算继续由原有专业工程执行和验收。

如果导演判断须增减时间，只提交`director_episode_rhythm.propose_rework()`的未派发QO-D12变更提议；编剧权威内容仍需重新审稿、旧导演锁与旧剪辑工单失效。不能仅靠文本评分改时间，也不能自动换用另一个take然后声称原视频已替换。

## 七、独立艺术验收清单（本轮不执行）

- 同一个公开虚构剧本：比较“机械3秒剪切版”“人物动机驱动版”“声音先行版”，由独立审片人员评估人物决策是否可见、节奏是否真正产生情绪；
- 音乐提前泄露悬念、缺一段人物犹豫、过长静态但无观众信息变化，导演能明确指出并提出有不同艺术成本的修订；
- 伪造音轨重叠、J/L-cut无媒资把柄、尾页被移到结尾之前、超过90秒、局部时间出现空档/重叠及源台词缺失，必须阻断或定位给原专业流水线；
- 制作前正常声音/剪辑交稿，不会使制作前导演节奏决定错误失效；制作后改一次声音/剪辑交付，旧复审失效；
- 总导演重新安排镜头、改原剧本，必须经过原QO-D12合规修订，不存在静默覆盖旧工单；
- 真正用户文案、真实Seedance/第三方模型、公开发行许可及真人影像审美评价均需要独立授权与核实。

**质量状态：** QO-D03、QO-D09最多保持 `in_progress`，既有QO-D09公开合成FFmpeg/OTIO CI历史成果不被本模块抹掉；本轮新增的导演艺术方案没有经过任何这类验证。
