# 第23号导演专业规范｜QO-D01 正式剧本唯一剧情权威 × QO-D02 场次/节拍/物理镜头分层

**统一目标：** 完整文学/事实输入经过职业编剧改编为详细、可理解的正式剧本后，**总导演拥有视听表达的创作权、制作组织权与技术方案否决权，但没有默改正式文本、人物抉择或事实的权限**。导演可以在一句台词上切多个镜头，也可以在一个物理镜头里连续涵盖同一场景多个节拍；镜头的增减不等于正式剧本的增删。

**开发状态（2026-10-21）：** 第一版代码修复与专业规范，统一 Draft PR #67；用户此前要求“先不要测试”，因此本阶段未主动运行单元/CI、真实模型或真人审片，不合并主分支。任何静态验证不意味着真正的作品质量已达到电影节/一流导演标准。

## 一、三层权威必须同时存在

**第一层：原稿及编剧完成的权威剧本**。由原 `screenplay_adaptation` 和 `screenplay_director_handoff` 以来源hash、逐场逐beat解释、角色/对白身份与结构化作者审稿协议建立（**结构审稿通过≠真实审稿人身份或版权授权**）。允许原编剧按总导演意见提出**新版本完整剧本**，但不得直接修改已经锁定的旧文本。

**第二层：总导演的分镜覆盖方案**。原 `director_shot_coverage` 能自由为一个无对白beat切多镜、把同一场连续的数个beat合镜、或在具有真正逐字逐句cue时跨物理镜头保持原对白只播放一次。每一镜必须说明：观众对角色的认识怎样改变、表演/景别/运动/情绪的确切效果、剪口为何必要、空间和道具连续性、声音/静默的设计，以及AI生成不稳定时怎样降级。一个物理镜头**不能伪装成同时跨越两个不同场景**，跨场景的视觉叠置属于原 `director_editorial_montage` 的**多个镜头剪辑关系**，而不是在单一物理镜头中改变角色时空。

**第三层：实际10专业生产任务**。重分镜改变物理shot ID与镜头数量，就使用原 `agent_team.start` 启动**干净、全pending**新团队，重做导演锁稿、演员、摄影、美术、声音、剪辑与技术方案。不能沿用旧镜头已提交的专业成果、声口同步或旧审片签核来声称新版本完成。

## 二、发现并修复的合镜生产数据丢失问题

旧版 `director_shot_coverage.reblock_episode` 已重建每镜的 `character_ids` 和 `claim_ids`，也校验原旁白和原对白的完整顺序，但合镜**没有把被合并的每个源beat的 `prop_ids` 一起带入**，`source_adaptation.speaker_character_ids` 还沿用第一段beat，容易使后续表演/摄影/道具/声画部门错误理解另一人物如何出现、第二道具从何而来或真实说话人属于谁。

现在：
- 合镜的物理shot从覆盖的**所有源beat**汇总角色ID、道具ID、事实/论点引用ID；对于同一人物只去重，不会丢掉第二beat首次出现的道具。
- 汇总各beat `speaker_character_ids`，如果同一说话人被冲突映射到不同角色ID则阻断；原对白的speaker必须能找到合法的角色绑定。
- 新物理shot的 `source_adaptation.covered_beat_source_records` 按顺序包含**每一原始beat的不可偷偷替换的来源对象、原角色/道具/论点引用**；`covered_beat_ids` 和这个来源数组必须可互相核实。再不把「源第1段的数据」冒充整个合镜的故事事实。
- 在重建新crew之前重新核查所有片段的道具/人物/论点引用合集、原beat来源记录、原旁白和每句原对白顺序，一旦丢失立即阻断；如同一源beat被分到多个物理镜头，图像可重复引用该实体，但原对白只归属一个合法音频位置，不能多次配音。
- 重分镜后的表演、摄影、声音、剪辑专业工作人员必须根据**新的物理shot**重新设计。原文学beat ID 与实际物理shot ID 永远分开，不要求一个beat只给一个镜头。

**仍未解决、不能冒称完成：** 有对话人物的反打和跨镜对白需要原 `director_speech_cues` 有准确逐句音频cue、字幕cue、剪口和口型权属；没有实际cue和实媒资，就不允许仅按文本比例虚构音频时间码。即使新镜头来源合法，具体新演员外观、手/道具接触、轴线和真实口型仍需真片核验。

## 三、QO-D01新增实际检查：可解释的自由与不可改的来源

新增 `director_screenplay_authority.py`：

1. 在`screenplay_handoff_mode`存在时，检查剧本source SHA-256与原 `agent_team` 的source digest一致、`base_digest`未变、`no_silent_story_or_dialogue_rewrite=true`且reviewer身份未冒充已认证。
2. 向十专业的**真实role-facing私有请求**中加入来源锁定的编剧权威摘要（包含每镜对应的原始beat、角色/道具/论点ID，以及原对白、旁白digest）。来源hash是**防串稿与改稿来源版本的工具**，不是证明真的懂原文的艺术评价。
3. 在`agent_role_contracts.validate_role_output` 的**实际岗位结果接收处**针对全部专业拒绝`replacement_screenplay`、`rewritten_dialogue`、`approved_story_changes`等显式越权键，不让它们通过泛用嵌套对象偷偷变成已批准剧情修改。
4. 对真实 `sound.speech.dialogue` 校验与相应正式剧本逐段**文字完全一致、speaker完全一致、原句顺序不变**。允许一句原对白作为多个真正时间cue分割，前提是其拼接后的文本无新增、无遗漏、无改字；没有原对白时不得无来源添加新台词。原`sound.speech.voiceover.text`仍由既有`agent_role_contracts`与`agent_handoff_audit`逐字校验source narration。
5. **不扫描所有专业自由文本并宣称能证明语义忠实**：导演可能以自己的语言解释情绪、人物选择、摄影隐喻；对这类正当创意无法简单用原文字符串比对。相反，导演若在这些自由文字中隐蔽改写人物命运或事实，仍需QO-D10/QO-D16真实内容评议及编剧人工反审，不能因为hash匹配就声称完全无偏差。

**实际权限表：**

| 修改事项 | 可提出 | 谁改正式源 | 是否重启原十岗 |
|---|---|---|---|
| 机位、轴线、演员动作呈现、无剧本事实变更的镜头增减 | 总导演 | 不改源，导演重新分镜 | 重分镜后是 |
| 声音停顿、混音、剪口及原对白精确cue | 导演/声剪专业提出 | 原正式台词不变 | 同版定点返工视变更范围 |
| 新事件、角色决策、原对白、事实断言的修改 | 总导演可以建议 | 编剧重写全稿、经独立审稿/作者确认 | **必须用新稿重新建团队** |
| 角色/道具身份变更、已给出的论点和出处替换 | 总导演可以标缺口 | 权威新剧本与明确人物/事实审校 | 是 |
| 实际媒体AI模型为拍摄方便要求删角色或改故事 | 技术专业只能报告失败和替代方案 | 不得擅改，需编导演重新审定 | 按新权威剧本决定 |

## 四、与已有总导演模块的统一闭环

```text
文学/事实原稿 → 编剧改编完整剧本与作者逐项审稿记录
     ↓ 原剧本source digest，编剧逐场逐beat说明
QO-D13 自主分集与90秒硬门禁
     ↓
QO-D02 导演镜头覆盖、真实镜头数量与cue源权属
     ↓ QO-D01 保留原对白/角色/道具/事实完整来源，不改剧情
     ↓ 重新建立唯一的原10部门任务表并导演锁稿
QO-D15专业制作会 + QO-D03/17导演的独特视听技能
     ↓ QO-D10整片自审 + QO-D06复杂动作设计
演员 / 摄影美术 / 声音 / 剪辑 / AI技术 / 质量QA
     ↓ 实际交付相互核实
QO-D05/07跨镜、QO-D09整集节奏、QO-D16专业冲突审片
     ↓ 总导演最终判断
发现需改剧本 → QO-D12 返编剧新稿 → QO-D14真正剪辑版本重审
```

正当的导演专业创造，不因为“没有原稿里的摄影运动词语”而被错误阻断。**严格校验明确的文本、对象和版本，不假装能通过JSON字段自动分辨一个好导演。**

## 五、待获准集中测试与客观验收

- 一场对话戏含两beat、两名角色和不同道具，导演合成一个镜头后同时保留两beat全部演员与道具；任何speaker映射冲突不得被模糊化。
- 同一beat被拆成多个视听反打时，原台词与旁白只播放一次；无精确cue不允许“按照画面比例猜时间码”。
- 允许合理有来源的特写、反打与有原因的空镜，但任一镜头的来源跨度总时长不得暗改；逐镜原beat时段连续不缺失。
- 原编剧一句完整对白被声音部门切为两cue，拼接必须逐字等于原句；错字、串speaker、额外一句台词必须阻断。
- 专业岗位私自提交`approved_story_changes`或把旧script hash应用于新拍摄稿须拒绝；原 `script_edit.source_change_proposals` 的`approved=false`仍保留。
- 真人专业检查合法分镜是否真的使人物选择更清楚，实际AI生成模型是否能按手部/服装/光源连续执行；独立导演审片必须解释艺术取舍，不使用简单“镜头多=好/短=好”打分。
